# Archived Documentation

Thư mục này chứa tài liệu đã đóng: kế hoạch đã triển khai, spec phase cũ, hoặc tài liệu đã bị nguồn mới thay thế.

- Không xóa để vẫn giữ lịch sử quyết định.
- Không cập nhật thường xuyên.
- Không xem là nguồn yêu cầu hiện hành.
- Khi cần khôi phục một kế hoạch, chuyển nó về `docs/main` hoặc `docs/reference` và cập nhật `docs/README.md`.
