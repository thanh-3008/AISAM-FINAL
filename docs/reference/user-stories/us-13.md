# US-13 Frontend Detail - Xem danh sach va chon business profile

## 1. User story

La nguoi dung da dang nhap, toi muon xem danh sach business profile cua minh va chon profile dang hoat dong de tiep tuc su dung he thong.

## 2. Muc tieu frontend

- Hien danh sach profile cua user dang dang nhap.
- Cho phep chon active profile tren frontend.
- Chuan bi context cho cac module sau dung `X-Profile-Id`.

## 3. Can cu backend va scope hien tai

### Requirement lien quan

- `docs/main/requirements.md` muc `6.3` yeu cau ho tro nhieu business profile tren cung mot tai khoan.

### Backend plan lien quan

- `docs/archive/plans/backend-code-plan.md` Phase 4 xac dinh profile list da active.
- `CODEBASE_UPDATE.md` xac nhan profile la module foundation da co.

### Backend implementation thuc te

- Endpoint list: `GET /api/profiles/user/{userId}`
- Query params ho tro:
  - `search`
  - `isDeleted`
- Authorization: bat buoc
- Response: `GenericResponse<IEnumerable<ProfileResponseDto>>`

### Hanh vi backend can frontend phai follow

- Route `userId` phai trung voi JWT user, neu khong:
  - `403 Forbidden`
- Danh sach profile hien tai la profile so huu boi user; chua co shared/team profile trong active codebase
- Muon xem profile da soft delete, frontend co the gui `isDeleted=true`

## 4. Pham vi frontend

### Trong pham vi

- Trang `/profiles`
- Fetch profile list theo current user
- Search local/backend query
- Chon active profile
- Dieu huong sau khi chon

### Ngoai pham vi

- Team/shared profile
- Role membership nang cao

## 5. API contract can dung

### Request

`GET /api/profiles/user/{userId}?search=&isDeleted=`

Header:

```http
Authorization: Bearer <accessToken>
```

### Success response

HTTP: `200 OK`

```json
{
  "success": true,
  "message": "Profiles retrieved successfully",
  "statusCode": 200,
  "data": [
    {
      "id": "guid",
      "userId": "guid",
      "name": "My Business",
      "profileType": 0,
      "subscriptionId": null,
      "companyName": "My Company",
      "bio": "Short bio",
      "avatarUrl": null,
      "status": 1,
      "createdAt": "2026-06-01T00:00:00Z",
      "updatedAt": "2026-06-02T00:00:00Z",

  ],
  "error": null
```

### Error response

- `401` neu chua dang nhap
- `403` neu route userId sai
- `500` neu loi he thong

## 6. UI/UX spec

### Route

- `/profiles`

### Thanh phan can co

- Danh sach card/table profile
- Search input
- Nut `Create profile`
- Nut `Open` / `Select` cho tung profile
- Co the co tab/filter:
  - active profiles
  - deleted profiles

### Empty state

- Chua co profile:
  - message
  - CTA `Create profile`

## 7. Validation frontend

- Khong co form validation phuc tap
- Khong duoc lay `userId` tu input tay; phai lay tu auth store

## 8. Data flow frontend

1. User vao `/profiles`
2. Frontend lay `user.id` tu auth session
3. Goi `GET /api/profiles/user/{userId}`
4. Render danh sach
5. Khi user chon mot profile:
   - luu vao `profile-store`
   - co the persist local
   - redirect `/dashboard`

## 9. State can xu ly

### Loading state

- skeleton list

### Empty state

- chua co profile

### Error state

- fetch fail
- `403` neu route mismatch do state sai

## 10. Auth/session impact

- Khong doi auth session
- Cap nhat active profile state
- Active profile duoc dung cho modules sau gan `X-Profile-Id`

## 11. Dieu huong sau khi chon profile

- Redirect `/dashboard`

## 12. Acceptance criteria

### AC-01

Frontend goi dung endpoint list profile theo `user.id` dang dang nhap.

### AC-02

Trang `/profiles` hien danh sach profile cua user.

### AC-03

Khi user chon mot profile, frontend luu active profile va redirect `/dashboard`.

### AC-04

Khi user chua co profile, frontend hien empty state va CTA tao profile.

## 13. Test cases frontend

### FE-01

Fetch danh sach profile thanh cong va render cards/list.

### FE-02

Empty list hien CTA `Create profile`.

### FE-03

Select profile cap nhat `profile-store` va redirect `/dashboard`.

### FE-04

Search query goi lai list voi tham so `search` neu UX yeu cau backend search.

## 14. Ghi chu implementation

- Backend chua co active profile server-side trong auth token; active profile chi la state phia frontend o giai doan nay.
- Cac module sau yeu cau `X-Profile-Id`; story nay la diem tao state do.
- `memberRole` hien tai co the null trong active codebase, frontend khong nen dua no thanh field bat buoc.
