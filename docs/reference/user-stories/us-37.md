# US-37 - Xem danh sách và chi tiết thông báo

## 1. User Story

**Là** người dùng,
**tôi muốn** xem các thông báo đã nhận để theo dõi sự kiện quan trọng,
**để** có thể kiểm tra chi tiết nội dung thông báo và điều hướng đến resource liên quan.

---

## 2. Mục tiêu

Cung cấp trang `/notifications` hiển thị danh sách đầy đủ tất cả notifications của profile đang active, hỗ trợ phân trang, filter theo type, xem chi tiết notification qua modal/sheet, và điều hướng đến resource liên quan (content, post, schedule) khi notification có `TargetId`/`TargetType`.

---

## 3. Phạm vi

### Trong phạm vi

- Trang `/notifications` với danh sách tất cả notifications (paged, 20 items/page).
- Mỗi notification item hiển thị: type icon, title, message, relative time, read/unread badge.
- Filter tabs/categories theo notification type (All, ApprovalNeeded, PostScheduled, PerformanceAlert, AiSuggestion, SystemUpdate).
- Phân trang: page number buttons + prev/next.
- Click notification → mở detail modal/sheet với nội dung đầy đủ.
- Detail modal hiển thị: type icon, title, message (full), thời gian tạo (absolute format), trạng thái read/unread.
- Detail modal có action: "Mark as read" (nếu chưa đọc) và "View related resource" (nếu có TargetId/TargetType).
- View related resource navigate đến trang tương ứng:
  - Content: `/content/{targetId}`.
  - Post: `/posts/{targetId}`.
  - Schedule: `/schedules/{targetId}`.
- Pull-to-refresh hoặc refresh button.
- Loading skeleton, empty state, error state.

### Ngoài phạm vi

- Mark read actions (trang này chỉ hiển thị, US-38 xử lý mark read).
- Notification bell + dropdown (US-36).
- Realtime push notification (WebSocket).
- Email/push notification.
- Notification preferences (bật/tắt type).
- Xoá notification (BE không hỗ trợ).

---

## 4. Actor

- **Chính:** Người dùng đã đăng nhập, có profile đang active.
- **Phụ:** User Web App (frontend), Backend API (`NotificationsController`), PostgreSQL.

---

## 5. Tiền điều kiện

- Người dùng đã đăng nhập và có JWT access token hợp lệ.
- Người dùng đã chọn active profile (`X-Profile-Id` header hợp lệ).
- Backend `NotificationsController` đã triển khai (Phase D).
- `X-Profile-Id` header tự động gắn bởi fetcher (US-28).

---

## 6. Luồng nghiệp vụ chính

### 6.1 Xem danh sách notification

1. Người dùng navigate đến `/notifications` (từ sidebar, "View all" trong bell dropdown, hoặc URL trực tiếp).
2. Frontend gọi `GET /api/notifications?page=1&pageSize=20`.
3. Hiển thị danh sách notifications theo dạng list vertical, mỗi item có:
   - Icon + màu theo type.
   - Title (in đậm nếu chưa đọc).
   - Message preview (1 dòng).
   - Relative time.
   - Badge "New" (cho notification chưa đọc).
4. Filter tabs phía trên danh sách: "All" (mặc định), "ApprovalNeeded", "PostScheduled", "PerformanceAlert", "AiSuggestion", "SystemUpdate".
5. Khi chọn filter tab, gọi lại API với query param hoặc filter client-side.
6. Pagination controls ở cuối trang: page numbers + prev/next.

### 6.2 Xem chi tiết notification

1. Người dùng click vào một notification item.
2. Mở modal hoặc bottom sheet với thông tin chi tiết:
   - Icon lớn theo type.
   - Title.
   - Message (full text, không truncate).
   - Created at: hiển thị absolute format (e.g., "03/06/2026 14:30").
   - Status: "Đã đọc" hoặc "Chưa đọc".
3. Nếu notification có `TargetId` và `TargetType` → hiển thị nút "Xem chi tiết" → click navigate đến resource.
4. Modal có thể đóng bằng nút X hoặc click outside.

### 6.3 Điều hướng đến resource liên quan

1. Trong detail modal, nếu có TargetId/TargetType, hiển thị nút "Xem resource".
2. Mapping:
   - `TargetType` = "content" → `/content/{targetId}`.
   - `TargetType` = "post" → `/posts/{targetId}`.
   - `TargetType` = "schedule" → `/schedules/{targetId}`.
3. Click → navigate đến trang tương ứng.

| Mã | Quy tắc |

```json
{
  "success": false,
  "statusCode": 404,
  "message": "Notification not found.",
  "data": null,
  "timestamp": "2026-06-03T15:00:00Z"
```

> **Lưu ý:** BE `NotificationDetailDto` extends `NotificationListItemDto`, thêm field `ProfileId`. Tuy nhiên BE model có thêm `TargetId`/`TargetType` nhưng không expose trong DTO hiện tại. FE detail modal dùng data từ list item (đã có đủ title, message, type, createdAt). Nếu cần detail đầy đủ, có thể gọi `GET /api/notifications/{id}`.

## 12. Acceptance Criteria

### AC-01 - Danh sách notification

**Given** người dùng vào trang `/notifications`
**When** trang load
**Then** gọi `GET /api/notifications?page=1&pageSize=20`
**And** hiển thị danh sách notification items với icon, title, message, time, read/unread badge.

### AC-02 - Filter tabs

**Given** trang notification đã load
**When** chọn filter tab "Cần duyệt"
**Then** danh sách filter chỉ hiển thị notification type `ApprovalNeeded`.

### AC-03 - Phân trang

**Given** có nhiều hơn 20 notifications
**When** scroll xuống cuối
**Then** hiển thị pagination controls với page numbers, prev, next.

### AC-04 - Click notification mở detail modal

**Given** danh sách notification đang hiển thị
**When** click vào một notification item
**Then** mở detail modal với title, message (full), time absolute, trạng thái read/unread.

### AC-05 - View related resource

**Given** detail modal đang mở
**When** notification có TargetId/TargetType
**Then** hiển thị nút "Xem resource" với route tương ứng.

### AC-06 - Empty state

**Given** không có notification nào
**When** vào trang `/notifications`
**Then** hiển thị empty state với icon và hướng dẫn.

### AC-07 - Loading state

**Given** API đang xử lý
**When** chờ response
**Then** hiển thị skeleton items.

### AC-08 - Error state

**Given** API trả lỗi
**When** vào trang `/notifications`
**Then** hiển thị error message + nút "Thử lại".

#### Hooks

**useNotificationsList:**

```typescript
// hooks/use-notifications-list.ts
import { useQuery } from "@tanstack/react-query";
import { useState } from "react";
import { notificationApi } from "@/features/notifications/api/notification-api";
import type { NotificationTypeFilter } from "@/features/notifications/types/notification";

export function useNotificationsList() {
  const [page, setPage] = useState(1);
  const [filter, setFilter] = useState<NotificationTypeFilter>("All");

  const query = useQuery({
    queryKey: ["notifications", "list", page],
    queryFn: () => notificationApi.getPaged(page, 20),
    staleTime: 10_000,
  });

  // Client-side filter
  const filteredData = query.data?.data.filter((item) => {
    if (filter === "All") return true;
    return item.type === filter;
  }) ?? [];

  return {
    notifications: filteredData,
    allNotifications: query.data?.data ?? [],
    totalCount: query.data?.totalCount ?? 0,
    totalPages: query.data?.totalPages ?? 0,
    page,
    setPage,
    filter,
    setFilter,
    isLoading: query.isLoading,
    isError: query.isError,
    refetch: query.refetch,
  };
}
```

```tsx
function NotificationPagination({
  page,
  totalPages,
  totalCount,
  onPageChange,
}: {
  page: number;
  totalPages: number;
  totalCount: number;
  onPageChange: (page: number) => void;
}) {
  const startItem = (page - 1) * 20 + 1;
  const endItem = Math.min(page * 20, totalCount);

  // Generate page numbers to display
  const getPageNumbers = () => {
    const pages: (number | "...")[] = [];
    const maxVisible = 5;
    if (totalPages <= maxVisible + 2) {
      for (let i = 1; i <= totalPages; i++) pages.push(i);
    } else {
      pages.push(1);
      if (page > 3) pages.push("...");
      for (let i = Math.max(2, page - 1); i <= Math.min(totalPages - 1, page + 1); i++) {
        pages.push(i);
      }
      if (page < totalPages - 2) pages.push("...");
      pages.push(totalPages);
    }
    return pages;
  };

  return (
    <div className="flex flex-col items-center gap-3">
      <div className="flex items-center gap-1">
        <button
          onClick={() => onPageChange(page - 1)}
          disabled={page <= 1}
          className="rounded-lg px-3 py-1.5 text-sm font-medium transition-colors hover:bg-muted disabled:opacity-30 disabled:hover:bg-transparent"
        >
          ← Prev
        </button>

        {getPageNumbers().map((p, idx) =>
          p === "..." ? (
            <span key={`ellipsis-${idx}`} className="px-2 text-muted-foreground">
              ...
            </span>
          ) : (
            <button
              key={p}
              onClick={() => onPageChange(p)}
              className={`flex h-8 w-8 items-center justify-center rounded-lg text-sm font-medium transition-colors ${
                p === page
                  ? "bg-primary text-primary-foreground"
                  : "hover:bg-muted"
              }`}
            >
              {p}
            </button>
          )
        )}

        <button
          onClick={() => onPageChange(page + 1)}
          disabled={page >= totalPages}
          className="rounded-lg px-3 py-1.5 text-sm font-medium transition-colors hover:bg-muted disabled:opacity-30 disabled:hover:bg-transparent"
        >
          Next →
        </button>
      </div>

      <p className="text-xs text-muted-foreground">
        Hiển thị {startItem}-{endItem} / {totalCount}
      </p>
    </div>
  );
}
```
