# US-39 - Xem số thông báo chưa đọc

## 1. User Story

**Là** người dùng,
**tôi muốn** xem unread count để biết còn sự kiện nào chưa xử lý,
**để** có thể nhanh chóng nhận biết có thông báo mới mà không cần mở dropdown hay trang notification.

---

## 2. Mục tiêu

Cung cấp unread notification count hiển thị trên bell icon (global header) và các vị trí khác trong ứng dụng, với cơ chế polling định kỳ để luôn phản ánh số lượng thông báo chưa đọc thực tế. Count được cập nhật real-time (qua polling 30 giây) và phản hồi ngay lập tức khi user thực hiện mark-read/mark-all-read actions (optimistic update).

---

## 3. Phạm vi

### Trong phạm vi

- Unread count badge trên notification bell icon (global header).
- Polling `GET /api/notifications/unread-count` mỗi 30 giây.
- Badge ẩn khi count = 0.
- Badge hiển thị "99+" khi count > 99.
- Pulse animation khi count tăng so với lần poll trước.
- Tạm dừng polling khi dropdown đang mở.
- Unread count trong page header trang `/notifications` (e.g., "Thông báo (3 unread)").
- Optimistic update: count giảm ngay khi user mark-read/mark-all-read (shared mutation logic với US-38).
- `useUnreadCount` hook tái sử dụng cho bell badge và các vị trí khác.

### Ngoài phạm vi

- Notification bell + dropdown (US-36).
- Notification list page `/notifications` (US-37).
- Mark read actions (US-38).
- Notification preferences.
- Realtime WebSocket/SignalR (chỉ dùng polling).

---

## 4. Actor

- **Chính:** Người dùng đã đăng nhập, có active profile.
- **Phụ:** Backend API (`NotificationsController.GetUnreadCount`), React Query (`refetchInterval`).

## 5. Tiền điều kiện

- Người dùng đã đăng nhập và có JWT token hợp lệ.
- Người dùng đã chọn active profile (`X-Profile-Id` header).
- Backend `GET /api/notifications/unread-count` endpoint đã triển khai.
- `X-Profile-Id` tự động gắn bởi fetcher (US-28).

---

## 6. Luồng nghiệp vụ chính

### 6.1 Polling unread count

1. Người dùng đăng nhập và chọn active profile.
2. Frontend bắt đầu polling `GET /api/notifications/unread-count` mỗi 30 giây.
3. Response trả về `{ count: number }`.
4. Cập nhật badge trên bell icon.

### 6.2 Badge hiển thị

1. Nếu `count > 0`: badge hiển thị số count trên góc phải bell icon.
2. Nếu `count > 99`: badge hiển thị "99+".
3. Nếu `count = 0`: badge ẩn.

### 6.3 Pulse animation khi có notification mới

1. Polling trả về count mới > count cũ.
2. Bell icon thực hiện pulse animation (scale 1→1.2→1, lặp 2 lần, duration 300ms mỗi lần).
3. Animation chỉ chạy khi dropdown đóng (tránh giật UI).

### 6.4 Tạm dừng polling khi dropdown mở

1. Khi user click bell → dropdown mở.
2. Tạm dừng polling interval.
3. Khi dropdown đóng → resume polling.

### 6.5 Optimistic update từ mark-read actions

1. User mark-read một notification (US-38).
2. Optimistic update: count giảm 1 ngay lập tức (không chờ API).
3. Nếu mark-read thất bại → rollback count.

### 6.6 Unread count trong page header

1. Trang `/notifications` header hiển thị `"🔔 Thông báo ({count} unread)"`.
2. Chỉ hiển thị khi `count > 0`.

## 9. API Contracts

### 9.1 Get Unread Count

```
GET /api/notifications/unread-count
```

#### Headers
```http
Authorization: Bearer <access-token>
X-Profile-Id: <owned-profile-guid>
```

#### Response (200 OK)
```json
{
  "success": true,
  "statusCode": 200,
  "message": "Unread notification count retrieved successfully.",
  "data": {
    "count": 3
  },
  "timestamp": "2026-06-03T15:00:00Z"
}
```

#### Response (200 OK - zero)
```json
{
  "success": true,
  "statusCode": 200,
  "message": "Unread notification count retrieved successfully.",
  "data": {
    "count": 0
  },
  "timestamp": "2026-06-03T15:00:00Z"
}
```

### AC-01 - Badge hiển thị trên bell icon

**Given** người dùng đã đăng nhập và có active profile

**Then** badge hiển thị số count trên góc bell icon.

### AC-03 - Badge "99+" khi count > 99

**Then** badge hiển thị "99+".

### AC-04 - Polling 30 giây

**Given** người dùng đang active
**When** 30 giây trôi qua
**Then** gọi `GET /api/notifications/unread-count`
**And** cập nhật badge.

### AC-05 - Pulse animation khi count tăng

**Given** polling trả về count mới > count cũ
**Then** bell icon pulse animation (2 lần).

### AC-06 - Tạm dừng polling khi dropdown mở

**Given** dropdown notification đang mở
**Then** không gọi polling.
**When** dropdown đóng
**Then** resume polling.

### AC-07 - Optimistic update

**Given** user mark-read một notification
**Then** count giảm 1 ngay lập tức (không chờ API).

### AC-08 - Page header unread count

**Given** trang `/notifications` đang mở và có unread

#### Hooks

**useUnreadCount (với polling + pulse detection):**

```typescript
// features/notifications/hooks/use-unread-count.ts
import { useQuery, useQueryClient } from "@tanstack/react-query";
import { useEffect, useRef } from "react";
import { notificationApi } from "@/features/notifications/api/notification-api";

const POLL_INTERVAL = 30_000; // 30 giây

export function useUnreadCount({ paused = false }: { paused?: boolean } = {}) {
  const queryClient = useQueryClient();

  const query = useQuery({
    queryKey: ["notifications", "unread-count"],
    queryFn: notificationApi.getUnreadCount,
    refetchInterval: paused ? false : POLL_INTERVAL,
    staleTime: POLL_INTERVAL,
    // Không retry ngay lập tức khi error; chờ interval tiếp theo
    retry: false,
  });

  // Pulse detection: count tăng so với lần trước
  const prevCountRef = useRef(query.data?.count ?? 0);
  const [hasNewNotification, setHasNewNotification] = useState(false);

  useEffect(() => {
    if (query.data === undefined) return;

    const currentCount = query.data.count;
    const prevCount = prevCountRef.current;

    if (currentCount > prevCount) {
      setHasNewNotification(true);
      // Tự động tắt pulse sau 1 giây
      const timer = setTimeout(() => setHasNewNotification(false), 1000);
      prevCountRef.current = currentCount;
      return () => clearTimeout(timer);
    }

    prevCountRef.current = currentCount;
    setHasNewNotification(false);
  }, [query.data]);

  return {
    count: query.data?.count ?? 0,
    isLoading: query.isLoading,
    isError: query.isError,
    hasNewNotification,
    refetch: query.refetch,
  };
}
```

**Lưu ý về optimistic update:** Khi mark-read/mark-all-read actions (US-38) được gọi, chúng update cache của `["notifications", "unread-count"]` trực tiếp qua `queryClient.setQueryData`, nên `useUnreadCount` tự động phản ánh count mới mà không cần chờ polling.

#### Components

**NotificationBell (badge + pulse + polling pause):**

```tsx
// features/notifications/components/notification-bell.tsx
import { useState, useRef, useEffect } from "react";
import { useUnreadCount } from "@/features/notifications/hooks/use-unread-count";
import { NotificationDropdown } from "./notification-dropdown";

function NotificationBell() {
  const [isOpen, setIsOpen] = useState(false);
  const dropdownRef = useRef<HTMLDivElement>(null);

  // Pause polling khi dropdown mở
  const { count, isLoading, hasNewNotification } = useUnreadCount({
    paused: isOpen,
  });

  // Display count: 99+ nếu > 99
  const displayCount = count > 99 ? "99+" : count > 0 ? String(count) : null;

  // Click outside to close
  useEffect(() => {
    const handleClickOutside = (e: MouseEvent) => {
      if (dropdownRef.current && !dropdownRef.current.contains(e.target as Node)) {
        setIsOpen(false);
      }
    };
    document.addEventListener("mousedown", handleClickOutside);
    return () => document.removeEventListener("mousedown", handleClickOutside);
  }, []);

  return (
    <div ref={dropdownRef} className="relative">
      <button
        onClick={() => setIsOpen(!isOpen)}
        className="relative rounded-full p-2 transition-colors hover:bg-muted"
        aria-label={`Notifications${displayCount ? ` (${count} unread)` : ""}`}
      >
        <Bell
          className={`h-5 w-5 transition-transform ${
            hasNewNotification ? "animate-pulse-once" : ""
          }`}
        />
        {displayCount && (
          <span className="absolute -right-0.5 -top-0.5 flex h-4 min-w-[16px] items-center justify-center rounded-full bg-red-500 px-1 text-[10px] font-bold leading-none text-white">
            {displayCount}
          </span>
        )}
      </button>

      {isOpen && (
        <div className="absolute right-0 z-50 mt-2 w-80 rounded-2xl border bg-card shadow-2xl">
          <NotificationDropdown onClose={() => setIsOpen(false)} />
        </div>
      )}
    </div>
  );
}
```
