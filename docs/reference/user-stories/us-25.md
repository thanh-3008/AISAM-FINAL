# US-25 - Xem lịch sử AI generation của content

## 1. User Story

**Là** người dùng,
**tôi muốn** xem danh sách các generation đã tạo cho một content để so sánh và chọn lại,
**để** có cái nhìn tổng quan về tất cả phiên bản AI đã sinh và dễ dàng tìm lại phiên bản ưng ý.

---

## 2. Mục tiêu

Cung cấp một giao diện chuyên biệt để người dùng duyệt, tìm kiếm, lọc, và so sánh tất cả AI generations đã tạo cho một content cụ thể. Feature này giúp người dùng:
- Xem toàn bộ lịch sử generation theo thời gian (timeline).
- Lọc generation theo trạng thái (Completed/Failed/Pending), theo ngày, theo nguồn (generate-draft hay improve).
- Tìm kiếm generation theo nội dung prompt hoặc generated text.
- So sánh hai generation bất kỳ (side-by-side) hoặc so sánh với content hiện tại.
- Xem chi tiết từng generation: prompt, generated text, status, timestamps.
- Biết generation nào đang được áp dụng (current/approved).
- Điều hướng nhanh đến các action: Approve (US-24), Improve (US-23), Generate mới (US-22).

---

## 3. Phạm vi

### Trong phạm vi

- Màn hình "Generation History" chuyên dụng: trang riêng hoặc tab toàn màn hình trên content detail.
- Danh sách generations dạng timeline hoặc list view, sắp xếp mới nhất trước.
- Filter nhanh theo status: `All`, `Completed`, `Failed`, `Pending`.
- Filter theo nguồn: `All`, `Generate Draft`, `Improve`. (Cần backend phân biệt nguồn hoặc frontend suy luận từ context.)
- Search box tìm kiếm trong prompt và generated text.
- Date range picker lọc theo khoảng thời gian.
- Mỗi item hiển thị: prompt (rút gọn), generated text (preview), status badge, timestamp, badge "Current" nếu đang được approve.
- Click vào item để xem chi tiết (detail panel/modal) với prompt đầy đủ, generated text full, status, error message, timestamps.
- So sánh hai generation bất kỳ (click checkbox để chọn, nhấn "Compare").
- So sánh generation với content hiện tại (nút "Compare with current").
- Nút Copy generated text.
- Nút điều hướng: "Approve" (đến US-24), "Improve" (đến US-23), "Generate new" (đến US-22).
- Loading state, pagination (hoặc infinite scroll) nếu có nhiều generation.
- Empty state khi chưa có generation nào.
- Toast/notification khi copy thành công.

### Ngoài phạm vi

- Approve generation (đã có US-24).
- Improve generation (đã có US-23).
- Generate draft mới (đã có US-22).
- Reject/soft-delete generation (chưa có BE endpoint).
- Export danh sách generation ra file (CSV/PDF).
- Batch action trên nhiều generation (approve all, delete all).
- Real-time update khi có generation mới (cần refresh thủ công hoặc polling).

---

## 4. Actor

- **Chính:** Người dùng đã đăng nhập, có profile đang active, có content với ít nhất một AI generation.
- **Phụ:** User Web App (frontend), Backend API (GeminiController/AIService), PostgreSQL.

---

## 5. Tiền điều kiện

- Người dùng đã đăng nhập và có JWT access token hợp lệ.
- Người dùng đã chọn active profile (`X-Profile-Id` header hợp lệ).
- Content tồn tại, chưa bị soft-delete và thuộc profile đang active.

## 6. Luồng nghiệp vụ chính

### 6.1 Xem danh sách lịch sử generation

1. Người dùng truy cập màn hình Generation History từ một trong các entry point:
   - Tab "Generation History" trên trang chi tiết content (`/content/{contentId}`, tab thứ 3 sau "Content Details" và "Preview").
   - Nút "View All Generations" từ màn hình AI Generation (`/ai`) hoặc từ Generation History tab ẩn (US-22).
   - Đường dẫn trực tiếp `/content/{contentId}/generations`.
2. Frontend gọi `GET /api/ai/generations/{contentId}` với các query params nếu cần (filter, search, page).
3. Hệ thống hiển thị danh sách generations:
   - Mặc định: tất cả generations, sắp xếp mới nhất trước.
   - View type: list view (default) hoặc timeline view (toggle).
4. Mỗi generation item hiển thị:
   - **Status badge** (Completed xanh, Failed đỏ, Pending vàng).
   - **Source badge** (tuỳ chọn): "Generate Draft" / "Improve" — frontend tự suy luận: nếu là generation đầu tiên của content thì là "Generate Draft", các generation sau là "Improve".
   - **Prompt** (1 dòng truncate, tooltip đầy đủ).
   - **Generated text** (preview 2 dòng, expand để xem thêm).
   - **Timestamp** (relative time: "2 phút trước" + absolute tooltip).
   - **Checkbox** để chọn so sánh.
   - **Badge "Current"** nếu generation đang được áp dụng.
   - **Actions**: nút Copy, nút "View Details".

### 6.2 Filter và tìm kiếm

1. **Filter by status**: người dùng chọn tab/lọc: All, Completed, Failed, Pending.
2. **Filter by source**: All, Generated, Improved.
3. **Date range**: người dùng chọn khoảng thời gian (date picker).
4. **Search**: người dùng nhập từ khoá, frontend filter danh sách theo prompt hoặc generated text (client-side hoặc gọi API với query params).
5. Kết quả được cập nhật ngay lập tức (nếu client-side filter) hoặc sau khi gọi API (nếu server-side filter).

### 6.3 Xem chi tiết generation

1. Người dùng click vào generation item hoặc nút "View Details".
2. Hệ thống mở detail panel (slide-over) hoặc modal:
   - **Prompt** đầy đủ (read-only code block, có copy button).
   - **Generated text** (full, read-only, có copy button).
   - **Status** (badge).
   - **Error message** (nếu Failed, highlight đỏ).
   - **Source**: "Generate Draft" hoặc "Improve".
   - **Timestamps**: `CreatedAt`, `UpdatedAt`.
   - **Badge "Current"** nếu generation này đang được áp dụng.
   - **Actions**:
     - Nút "Approve" → chuyển đến US-24 approve flow.
     - Nút "Improve" → chuyển đến US-23 improve flow (pre-fill prompt với generation text).
     - Nút "Compare with current" → mở compare panel.
     - Nút "Copy text".

### 6.4 So sánh hai generation

1. Người dùng chọn checkbox trên 2 generation items.
2. Nút **"Compare"** ở toolbar enabled (chỉ khi chọn đúng 2 items).
3. Người dùng nhấn "Compare".
4. Hệ thống mở compare panel split screen:
   - **Bên trái**: Generation A (cũ hơn) — prompt + generated text.
   - **Bên phải**: Generation B (mới hơn) — prompt + generated text.
   - Highlight khác biệt giữa hai generated text (thêm/xoá).
   - Hiển thị badge "Current" nếu một trong hai đang được áp dụng.
5. Người dùng có thể:
   - Approve một trong hai generation.
   - Đóng compare panel.

### 6.5 So sánh generation với content hiện tại

1. Từ detail panel hoặc action menu, người dùng chọn "Compare with current".
2. Hệ thống mở compare panel:
   - **Bên trái**: `Content.TextContent` hiện tại.
   - **Bên phải**: `GeneratedText` của generation được chọn.
3. Highlight khác biệt.

### 6.6 Export / Copy

1. Từ detail panel, người dùng có thể copy prompt hoặc generated text vào clipboard.
2. Toast "Copied!" hiển thị khi thành công.

## 7. Luồng ngoại lệ

| Mã | Trường hợp | Kết quả mong đợi |
| --- | --- | --- |
| EX-01 | Content không tồn tại hoặc không thuộc profile | Backend trả `404 Not Found`; frontend hiển thị lỗi + nút "Quay lại". |
| EX-02 | Content không có generation nào | Empty state: illustration + "Content này chưa có AI generation nào." + nút "Tạo generation mới" (link đến US-22). |
| EX-03 | Lỗi mạng khi load danh sách | Toast "Không thể tải lịch sử generation." + nút Retry. |
| EX-04 | Không có filter result | Empty state: "Không tìm thấy generation nào phù hợp." + nút "Xoá bộ lọc". |
| EX-05 | JWT hết hạn hoặc không hợp lệ | Backend trả `401 Unauthorized`; frontend tự động refresh token hoặc chuyển hướng đăng nhập. |
| EX-06 | X-Profile-Id thiếu hoặc không thuộc user | Backend trả `400 Bad Request` / `403 Forbidden`; frontend hiển thị lỗi. |
| EX-07 | Chọn hơn 2 generation để compare | Tooltip/validation: "Chỉ có thể so sánh 2 generation cùng lúc."; disable nút Compare khi chọn >2. |
| EX-08 | Chọn ít hơn 2 generation để compare | Nút Compare disabled với tooltip "Chọn 2 generation để so sánh". |
| EX-09 | Copy text thất bại (clipboard API) | Toast "Không thể copy. Vui lòng thử lại hoặc copy thủ công." |

## 8. Quy tắc nghiệp vụ

| Mã | Quy tắc |
| --- | --- |
| BR-01 | `ProfileId` được lấy từ `X-Profile-Id` header đã được middleware validate, không lấy từ request body. |
| BR-02 | Danh sách generation hiển thị theo thứ tự mới nhất trước (descending by `CreatedAt`). |
| BR-03 | Generation bị soft-delete (`IsDeleted = true`) không được trả về từ API (backend filter sẵn). |
| BR-04 | Generation đang là `Content.TextContent` hiện tại được đánh dấu "Current" — frontend tự xác định bằng cách so sánh `generatedText === contentTextContent`. |
| BR-05 | Prompt nên được hiển thị trong detail view, nhưng BE DTO hiện tại không bao gồm `AiPrompt`. Cần mở rộng `AiGenerationResponse` để thêm field `prompt`. Nếu chưa có, frontend có thể lưu prompt từ client-side khi generate/improve (trong local state) hoặc request BE update. |
| BR-06 | Filter status và search nên ưu tiên client-side cho danh sách nhỏ (<100 items) và server-side cho danh sách lớn. |
| BR-07 | Không hỗ trợ compare generation thuộc content khác. |
| BR-08 | So sánh chỉ mang tính UI hiển thị; không tạo generation mới hay thay đổi dữ liệu. |

## 9. API Contracts

### 9.1 Get Generations by Content

```
GET /api/ai/generations/{contentId}
```

#### Headers bắt buộc

```http
Authorization: Bearer <access-token>
X-Profile-Id: <owned-profile-guid>
```

#### Path Parameters

| Tham số | Kiểu | Bắt buộc | Mô tả |
| --- | --- | --- | --- |
| `contentId` | `Guid` | Có | ID của content cần lấy lịch sử generation. |

#### Response thành công (`200 OK`)

```json
{
  "success": true,
  "statusCode": 200,
  "message": "AI generations retrieved.",
  "data": [
    {
      "aiGenerationId": "gen-uuid-3",
      "contentId": "content-uuid",
      "generatedText": "🔥 Best version with emojis and urgency!",
      "status": 1,
      "errorMessage": null,
      "createdAt": "2026-06-03T06:40:00Z"
    },
    {
      "aiGenerationId": "gen-uuid-2",
      "contentId": "content-uuid",
      "generatedText": "More professional tone for LinkedIn...",
      "status": 1,
      "errorMessage": null,
      "createdAt": "2026-06-03T06:35:00Z"
    },
    {
      "aiGenerationId": "gen-uuid-1",
      "contentId": "content-uuid",
      "generatedText": null,
      "status": 2,
      "errorMessage": "Gemini API returned 429.",
      "createdAt": "2026-06-03T06:25:00Z"
    }
  ]
}
```

> **⚠️ Cần mở rộng BE DTO:** Response hiện tại không bao gồm:
> - `prompt` (AiPrompt) — rất cần cho history view
> - `updatedAt` — hữu ích cho detail view
>
> Nên thêm vào `AiGenerationResponse`:
> ```json
> {
>   "aiGenerationId": "gen-uuid-3",
>   "contentId": "content-uuid",
>   "prompt": "Make the caption shorter and more playful",  // Thêm
>   "generatedText": "🔥 Best version with emojis and urgency!",
>   "status": 1,
>   "errorMessage": null,
>   "createdAt": "2026-06-03T06:40:00Z",
>   "updatedAt": "2026-06-03T06:40:05Z"                    // Thêm
> }
> ```

### 9.2 Response lỗi

| HTTP Status | errorCode | Trường hợp |
| --- | --- | --- |
| `401 Unauthorized` | — | JWT thiếu hoặc không hợp lệ. |
| `400 Bad Request` | — | `X-Profile-Id` thiếu hoặc sai format. |
| `403 Forbidden` | — | Profile không thuộc user đang đăng nhập. |
| `404 Not Found` | — | Content không tồn tại, đã bị xóa, hoặc không thuộc profile. |
| `500 Internal Server Error` | — | Lỗi hệ thống không mong đợi. |

### 9.3 Mapping Enums

**`aiGenerationStatus`:**

| Giá trị | Tên | Mô tả |
| --- | --- | --- |
| `0` | `Pending` | Đang chờ xử lý |
| `1` | `Completed` | Đã hoàn thành |
| `2` | `Failed` | Thất bại |

## 12. Acceptance Criteria

### AC-01 - Xem danh sách generations của content

**Given** content có ít nhất một AI generation
**When** người dùng mở màn hình Generation History
**Then** `GET /api/ai/generations/{contentId}` được gọi
**And** danh sách generation hiển thị theo thứ tự mới nhất trước
**And** mỗi item hiển thị: status badge, prompt, generated text preview, timestamp.

### AC-02 - Filter generations theo status

**Given** danh sách generation đã load
**When** người dùng chọn filter "Completed"
**Then** chỉ hiển thị generation có status Completed
**When** người dùng chọn "Failed"
**Then** chỉ hiển thị generation có status Failed.

### AC-03 - Tìm kiếm generation theo từ khoá

**Given** danh sách generation đã load
**When** người dùng nhập từ khoá vào search box
**Then** danh sách được lọc theo prompt hoặc generated text chứa từ khoá
**And** keyword được highlight trong kết quả.

### AC-04 - Xem chi tiết generation

**Given** người dùng click vào một generation item
**When** detail panel mở ra
**Then** hiển thị: prompt đầy đủ, generated text, status, error message (nếu Failed), timestamps
**And** các action: Copy, Approve, Improve, Compare.

### AC-05 - So sánh hai generation

**Given** người dùng chọn checkbox trên 2 generation items
**When** người dùng nhấn "Compare"
**Then** compare panel mở với split screen
**And** hiển thị prompt + generated text của cả hai
**And** highlight khác biệt giữa hai generated text.

### AC-06 - So sánh generation với content hiện tại

**Given** người dùng đang ở detail panel
**When** người dùng nhấn "Compare with current"
**Then** compare panel hiển thị content hiện tại (bên trái) và generation (bên phải).

### AC-07 - Badge "Current" trên generation đang được áp dụng

**Given** content đã approve một generation
**When** hiển thị danh sách
**Then** generation đó hiển thị badge "Current".

### AC-08 - Copy generated text

**Given** người dùng ở detail panel hoặc action menu
**When** người dùng nhấn "Copy"
**Then** text được copy vào clipboard
**And** toast "Copied!" hiển thị.

### AC-09 - Empty state khi chưa có generation

**Given** content chưa có AI generation nào
**When** mở màn hình Generation History
**Then** hiển thị empty state với hướng dẫn + nút "Tạo generation mới".

### AC-10 - Empty state khi filter không có kết quả

// utils/generation-utils.ts
export function isCurrentGeneration(
  generation: AiGenerationResponse,
  currentTextContent: string
): boolean {
  return (
    generation.status === 1 &&
    generation.generatedText !== null &&
    generation.generatedText === currentTextContent
  );
}

/**
 * Xác định nguồn generation dựa trên context.
 * Generation đầu tiên của content được coi là "Generate Draft",
 * các generation sau là "Improve".
 * Lưu ý: đây là heuristic, có thể không chính xác trong mọi trường hợp.
 * Cần BE thêm field `source` nếu muốn chính xác.
 */
export function inferGenerationSource(
  generation: AiGenerationResponse,
  allGenerations: AiGenerationResponse[]
): "draft" | "improve" {
  const sorted = [...allGenerations].sort(
    (a, b) => new Date(a.createdAt).getTime() - new Date(b.createdAt).getTime()
  );
  return sorted[0]?.aiGenerationId === generation.aiGenerationId
    ? "draft"
    : "improve";
}

#### Client-side filter logic

```typescript
function applyFilters(
  generations: AiGenerationResponse[],
  filters: GenerationFilters,
  currentTextContent: string
): AiGenerationResponse[] {
  return generations.filter((gen) => {
    // Status filter
    if (filters.status !== "all") {
      const statusMap = { completed: 1, failed: 2, pending: 0 };
      if (gen.status !== statusMap[filters.status]) return false;
    }

    // Search filter
    if (filters.search) {
      const keyword = filters.search.toLowerCase();
      const promptMatch = (gen.prompt ?? "").toLowerCase().includes(keyword);
      const textMatch = (gen.generatedText ?? "").toLowerCase().includes(keyword);
      if (!promptMatch && !textMatch) return false;
    }

    // Date range filter
    if (filters.dateFrom && new Date(gen.createdAt) < new Date(filters.dateFrom)) return false;
    if (filters.dateTo && new Date(gen.createdAt) > new Date(filters.dateTo)) return false;

    // Source filter (heuristic)
    if (filters.source !== "all") {
      // Cần tất cả generations để xác định source
      // Logic này được xử lý ở component cha
    }

    return true;
  }).sort((a, b) => {
    const dateA = new Date(a.createdAt).getTime();
    const dateB = new Date(b.createdAt).getTime();
    return filters.sortOrder === "newest" ? dateB - dateA : dateA - dateB;
  });
}

function highlightText(text: string, keyword: string): React.ReactNode {
  if (!keyword.trim()) return text;
  const regex = new RegExp(`(${escapeRegExp(keyword)})`, "gi");
  const parts = text.split(regex);
  return parts.map((part, i) =>
    regex.test(part) ? <mark key={i} className="bg-yellow-200">{part}</mark> : part
  );
