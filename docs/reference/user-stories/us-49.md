# US-49 - Chặn AI generation khi vượt quota

## 1. User Story

**Là** hệ thống,
**tôi muốn** từ chối AI request khi profile đã hết prompt quota,
**để** thực thi chính sách subscription và tránh lạm dụng tài nguyên AI.

---

## 2. Mục tiêu

Đảm bảo mọi endpoint AI generation (`generate-draft`, `improve`, `chat`) đều kiểm tra prompt quota trước khi xử lý. Nếu profile đã dùng hết quota, BE trả về `403 Forbidden` với error code `PROMPT_QUOTA_EXCEEDED`. FE bắt lỗi này và hiển thị giao diện thân thiện: thông báo rõ ràng, disable generate button, link đến trang `/payment` để nâng cấp. Ngoài ra, FE chủ động kiểm tra quota trước khi cho phép user nhập prompt để tránh thao tác vô ích.

---

## 3. Phạm vi

### Trong phạm vi

- **BE bổ sung** quota check vào:
  - `AIService.ImproveAsync` – thêm `EnsurePromptQuotaAsync` trước khi gọi Gemini.
  - `AIService.ChatAsync` – thêm `EnsurePromptQuotaAsync` trước khi gọi Gemini.
- **FE proactive quota check**:
  - Khi vào AI page (`/ai` hoặc các page con như `/ai/generate`), gọi `GET /api/quota/profile/{activeProfileId}` để lấy `QuotaSummaryDto`.
  - Kiểm tra `promptRemaining` trước khi enable form nhập prompt.
- **FE error handling**:
  - Interceptor/hook xử lý response từ `POST /api/ai/generate-draft`, `POST /api/ai/improve/{contentId}`, `POST /api/ai/chat`.
  - Nếu `statusCode === 403` và `error.errorCode === "PROMPT_QUOTA_EXCEEDED"`: hiển thị UI quota exceeded.
- **FE disabled state**:
  - Khi `promptRemaining <= 0`: disable hoàn toàn nút "Generate" / "Gửi", hiển thị tooltip hoặc banner giải thích.
  - Input prompt vẫn cho phép nhập nhưng submit bị chặn.
- **FE quota indicator**:
  - Hiển thị badge/card nhỏ ở đầu AI page: "Prompt AI: X/Y còn lại hôm nay".
  - Màu sắc: xanh (>50%), vàng (20-50%), đỏ (<20%), xám (hết / không có quota).
- **FE upgrade CTA**:
  - Khi quota hết: hiển thị thông báo + button "Nâng cấp gói" → navigate đến `/payment`.
  - Khi quota sắp hết (<=20%): hiển thị banner nhỏ "Sắp hết prompt quota" + link "/payment".
- **FE error toast**:
  - Nếu BE trả về lỗi quota trong lúc generate: toast error + không đóng modal/không switch tab.
  - Không mất dữ liệu prompt đã nhập.

### Ngoài phạm vi

- Block ở BE khi `postRemaining <= 0` (publish) — đã có `EnsurePostQuotaAsync` nhưng chưa tích hợp vào `ContentService.PublishAsync` (deferred).
- Hard block toàn bộ AI page khi quota = 0 — user vẫn có thể xem lịch sử generation cũ, xem conversation cũ, chỉ block generation mới.
- Giới hạn số lần retry khi gọi API — BE chỉ reject 1 lần, FE không retry tự động.
- Websocket real-time quota update — FE chỉ polling khi vào page.
- Cache quota để giảm API call — mỗi lần vào page gọi 1 lần, sau generation success thì decrement local counter.
- Xử lý quota trong `POST /api/content/publish` hoặc scheduled publish — chỉ AI endpoints.

### 6.5. `EnsurePromptQuotaAsync` (đã có, chỉ verify)

```csharp
// QuotaService.cs
public async Task<GenericResponse<bool>> EnsurePromptQuotaAsync(Guid profileId, CancellationToken ct)
{
    var summary = await GetSummaryAsync(profileId, ct);
    if (!summary.Success)
        return GenericResponse<bool>.CreateError(summary.Message!, (HttpStatusCode)summary.StatusCode);

    if (summary.Data!.PromptRemaining <= 0)
        return GenericResponse<bool>.CreateError(
            "Prompt quota has been exceeded for the current subscription.",
            HttpStatusCode.Forbidden,
            "PROMPT_QUOTA_EXCEEDED");

    return GenericResponse<bool>.CreateSuccess(true);
}
```

## 8. Frontend: Hooks

### 8.1. `use-quota.ts`

```typescript
// src/features/quota/hooks/use-quota.ts
import { useQuery } from "@tanstack/react-query";
import { getQuotaSummary, type QuotaSummary } from "../api/quota-api";
import { useActiveProfile } from "@/hooks/use-active-profile";

export function usePromptQuota() {
  const { activeProfileId } = useActiveProfile();

  return useQuery<QuotaSummary>({
    queryKey: ["quota", activeProfileId],
    queryFn: () => getQuotaSummary(activeProfileId!),
    enabled: !!activeProfileId,
    staleTime: 30_000,                // cache 30s
    refetchOnMount: true,
    retry: false,
  });
}

export function isQuotaExceeded(remaining: number): boolean {
  return remaining <= 0;
}

export function isQuotaLow(remaining: number, limit: number): boolean {
  if (limit <= 0) return true;
  return (remaining / limit) <= 0.2;
}

export function getQuotaHealthColor(remaining: number, limit: number): string {
  if (limit <= 0) return "gray";        // không có quota
  const ratio = remaining / limit;
  if (ratio > 0.5) return "green";
  if (ratio > 0.2) return "yellow";
  if (ratio > 0) return "red";
  return "gray";                        // hết quota
}
```

### 8.2. `use-quota-error-handler.ts`

```typescript
// src/features/quota/hooks/use-quota-error-handler.ts
// Hook xử lý lỗi quota từ AI API calls
import { useToast } from "@/hooks/use-toast";
import { useRouter } from "next/navigation";
import { QUOTA_ERROR_CODES } from "@/types/constants";

interface QuotaError {
  isQuotaExceeded: boolean;
  isQuotaLow: boolean;
  remaining: number;
  limit: number;
}

export function useQuotaErrorHandler() {
  const { toast } = useToast();
  const router = useRouter();

  const handleQuotaError = (error: any) => {
    const apiError = error?.response?.data?.error;
    if (apiError?.errorCode === QUOTA_ERROR_CODES.PROMPT_QUOTA_EXCEEDED) {
      toast({
        variant: "destructive",
        title: "Đã hết prompt quota",
        description:
          "Bạn đã sử dụng hết số lần tạo nội dung AI trong gói hiện tại. Vui lòng nâng cấp gói để tiếp tục.",
        action: (
          <button
            onClick={() => router.push("/payment")}
            className="rounded bg-primary px-3 py-1.5 text-sm font-medium text-primary-foreground"
          >
            Nâng cấp gói
          </button>
        ),
        duration: 8000,
      });
      return true;
    }
    return false;
  };

  return { handleQuotaError };
}
```

```tsx
// src/features/quota/components/QuotaBanner.tsx
"use client";

import { usePromptQuota, getQuotaHealthColor } from "../hooks/use-quota";
import Link from "next/link";

export function QuotaBanner() {
  const { data, isLoading, isError } = usePromptQuota();

  if (isLoading) return <div className="h-8 w-48 animate-pulse rounded bg-muted" />;
  if (isError || !data) return null;

  const { promptRemaining, promptQuotaLimit } = data;
  const color = getQuotaHealthColor(promptRemaining, promptQuotaLimit);

  const colorMap = {
    green: "bg-green-100 text-green-800 border-green-300",
    yellow: "bg-yellow-100 text-yellow-800 border-yellow-300",
    red: "bg-red-100 text-red-800 border-red-300",
    gray: "bg-gray-100 text-gray-500 border-gray-300",
  };

  return (
    <div className={`flex items-center gap-2 rounded-lg border px-3 py-2 text-sm ${colorMap[color]}`}>
      <span className="font-medium">Prompt AI:</span>
      <span>
        {promptRemaining} / {promptQuotaLimit} còn lại hôm nay
      </span>
      {promptRemaining <= 0 && (
        <Link
          href="/payment"
          className="ml-auto font-semibold underline underline-offset-2"
        >
          Nâng cấp gói →
        </Link>
      )}
      {promptRemaining > 0 && promptRemaining / promptQuotaLimit <= 0.2 && (
        <Link
          href="/payment"
          className="ml-auto text-xs underline underline-offset-2"
        >
          Sắp hết quota
        </Link>
      )}
    </div>
  );
}
```

```tsx
// src/features/quota/components/QuotaGuard.tsx
"use client";

import { usePromptQuota, isQuotaExceeded } from "../hooks/use-quota";
import Link from "next/link";
import type { ReactNode } from "react";

interface QuotaGuardProps {
  children: ReactNode;
  fallback?: ReactNode;
}

export function QuotaGuard({ children, fallback }: QuotaGuardProps) {
  const { data, isLoading } = usePromptQuota();

  if (isLoading) return null;

  if (data && isQuotaExceeded(data.promptRemaining)) {
    return (
      fallback ?? (
        <div className="flex flex-col items-center justify-center gap-4 rounded-xl border-2 border-dashed border-muted-foreground/30 py-16">
          <div className="text-4xl">🚫</div>
          <h3 className="text-lg font-semibold">Đã hết prompt quota</h3>
          <p className="max-w-md text-center text-sm text-muted-foreground">
            Bạn đã sử dụng hết {data.promptQuotaLimit} prompt AI trong gói{" "}
            <strong>{data.planName}</strong>. Vui lòng nâng cấp gói để tiếp tục sử
            dụng AI.
          </p>
          <Link
            href="/payment"
            className="rounded-lg bg-primary px-6 py-2.5 font-medium text-primary-foreground hover:bg-primary/90"
          >
            Nâng cấp gói ngay
          </Link>
        </div>
      )
    );
  }

  return <>{children}</>;
}
```

## 10. Luồng xử lý

### 10.1. Luồng chính: User tạo AI draft → hết quota

```
User vào /ai/generate
  → FE gọi GET /api/quota/profile/{profileId}
    → Trả về QuotaSummaryDto { promptRemaining: 0, ... }
  → QuotaGuard render fallback "Đã hết quota" + nút "Nâng cấp gói"
  → User click "Nâng cấp gói"
  → Navigate đến /payment
```

### 10.2. Luồng phụ: User gửi prompt → quota hết trong lúc generate

```
User click "Generate"
  → FE gọi POST /api/ai/generate-draft
  → BE check quota → hết quota
  → BE trả về 403 + PROMPT_QUOTA_EXCEEDED
  → useGenerateDraft onError: handleQuotaError()
    → Toast error "Đã hết prompt quota" + action "Nâng cấp gói"
  → Form không reset, user có thể copy prompt hoặc navigate
```

### 10.3. Luồng phụ: Chat → quota hết giữa chừng

```
User gửi message trong chat
  → FE gọi POST /api/ai/chat
  → BE check quota → hết quota
  → BE trả về 403 + PROMPT_QUOTA_EXCEEDED
  → useChat onError: handleQuotaError()
    → Toast error + không thêm AI response vào conversation
    → User vẫn thấy message của mình nhưng không có reply
  → QuotaBanner cập nhật (nếu đang hiển thị) → mặc dù stale time 30s
```

### 10.4. Luồng phụ: Improve content → quota hết

```
User click "Improve" trong content detail
  → FE gọi POST /api/ai/improve/{contentId}
  → BE check quota → hết quota
  → BE trả về 403 + PROMPT_QUOTA_EXCEEDED
  → Toast error + modal improve không đóng
```

## 13. Các điểm cần confirm

1. **Chat có nên tính quota không?** — Hiện tại mỗi message chat gọi 1 Gemini API call, tốn chi phí. Nên tính prompt quota cho chat. Nếu business muốn chat miễn phí hoặc quota riêng, cần điều chỉnh.
2. **Số quota chat hiển thị thế nào?** — Dùng chung `promptQuotaLimit/promptRemaining` hay tách riêng `chatQuotaLimit/chatRemaining`? Hiện tại `QuotaSummaryDto` chỉ có 1 trường prompt quota, dùng chung cho tất cả AI generation (kể cả chat).
3. **Sau khi generate thành công, FE có nên tự động giảm local counter không?** — Để UX mượt, FE có thể `optimisticUpdate` quota local: decrement `promptRemaining` ngay sau khi nhận response 200, trước khi cache stale. Nếu không, user phải đợi 30s (staleTime) mới thấy quota cập nhật.
4. **Profile chưa active subscription thì sao?** — `GET /api/quota/profile/{profileId}` trả về 404. FE xem như quota limit = 0, hiển thị "Vui lòng đăng ký gói để sử dụng AI" + link `/payment`.
5. **Có nên thêm `POST_QUOTA_EXCEEDED` vào post publish không?** — Ngoài phạm vi US-49. `EnsurePostQuotaAsync` đã có trong `QuotaService` nhưng chưa tích hợp vào `ContentService.PublishAsync`. Sẽ xử lý ở story riêng.

## 15. Ghi chú kỹ thuật

- **Optimistic quota update**: Sau mỗi lần generate/chat thành công, FE có thể `queryClient.setQueryData(["quota", profileId], old => ({ ...old, promptRemaining: old.promptRemaining - 1 }))` để UI phản hồi ngay. Kết hợp với `refetchInterval: 30_000` để sync với BE.
- **X-Profile-Id header**: `GET /api/quota/profile/{profileId}` cần profileId lấy từ `useActiveProfile()`. Hook này đã được implement từ US-28.
- **apiClient interceptor**: Nên thêm global error interceptor trong `api-client.ts` để bắt `PROMPT_QUOTA_EXCEEDED` và dispatch event hoặc toast nếu cần. Tuy nhiên, handle ở từng mutation cho phép UX linh hoạt hơn (không toast khi đang ở page không liên quan).
- **Không ảnh hưởng đến existing features**: US-49 chỉ thêm quota check vào `ImproveAsync` và `ChatAsync`. `GenerateDraftAsync` đã có. Các logic khác không đổi.
