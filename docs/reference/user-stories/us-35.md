# US-35 - Xem lịch sử bài đăng

## 1. User Story

**Là** người dùng,
**tôi muốn** xem danh sách và chi tiết các bài đã publish để theo dõi kết quả xuất bản,
**để** biết được nội dung nào đã được đăng, lên page nào, và khi nào.

---

## 2. Mục tiêu

Cung cấp trang "Post History" hiển thị danh sách tất cả bài đã publish của profile đang active, kèm thông tin: content title, brand, page đã đăng, thời gian publish, trạng thái. Hỗ trợ tìm kiếm, lọc theo brand, phân trang, và xem chi tiết từng post (bao gồm external link đến Facebook post).

---

## 3. Phạm vi

### Trong phạm vi

- Danh sách posts với pagination (`GET /api/posts`).
- Mỗi post item hiển thị:
  - Content title.
  - Brand name.
  - Page name (từ integration).
  - Published at (relative time + absolute date).
  - External link "View on Facebook" (từ `externalPostId`).
- Lọc theo brand (`brandId` query param).
- Phân trang (page size mặc định 10, clamp 1-100).
- Post detail page/modal (`GET /api/posts/{postId}`).
- Loading skeleton.
- Empty state khi chưa có post nào.
- Error state khi API fail.
- Link từ post đến content detail để xem lại nội dung gốc.
- Refresh danh sách.

### Ngoài phạm vi

- Xem analytics/performance metrics cho từng post (reach, impressions, etc.): US-43 (Dashboard summary MVP).
- Xoá post khỏi lịch sử — Post là immutable record, không cho phép xoá.
- Retry publish cho post failed — post failed không tồn tại trong DB (chỉ success mới có Post record).
- Export danh sách posts.

---

## 4. Actor

- **Chính:** Người dùng đã đăng nhập, có profile active, đã publish ít nhất một post.
- **Phụ:** Backend API (PostsController, PostService, PostRepository).

---

## 5. Tiền điều kiện

- Người dùng đã đăng nhập và có JWT hợp lệ.
- Người dùng đã chọn active profile (`X-Profile-Id`).
- Có ít nhất một Post record trong DB cho profile này.

---

## 6. Luồng nghiệp vụ chính

### 6.1 Xem danh sách posts

1. Người dùng vào màn hình **Post History** (route `/posts` hoặc tab trong Content).
2. Frontend gọi `GET /api/posts?page=1&pageSize=10`.
3. Backend trả `PagedResult<PostListItemDto>` sắp xếp theo `PublishedAt` giảm dần.
4. Frontend render danh sách posts dạng table hoặc list cards:
   - Content title (click → content detail).
   - Brand name.
   - Page name.
   - Published at (relative time: "2 hours ago", "3 days ago").
   - Link "View on Facebook" (mở tab mới).
5. Nếu danh sách rỗng → empty state.
6. Nếu API lỗi → error state + nút Retry.

### 6.2 Lọc theo brand

1. Trên header danh sách có brand dropdown filter.
2. Người dùng chọn brand → gọi `GET /api/posts?brandId={brandId}&page=1&pageSize=10`.
3. Danh sách được lọc.
4. Brand dropdown được populate từ danh sách brand của profile.

### 6.3 Phân trang

1. Mỗi trang hiển thị 10 posts (mặc định).
2. Bottom của danh sách có pagination controls: Previous / 1 2 3 ... N / Next.
3. Khi đổi trang → gọi lại API với page number tương ứng.
4. Scroll lên đầu danh sách sau khi đổi trang.

### 6.4 Xem chi tiết post

1. Người dùng click vào một post item.
2. Mở Post Detail modal hoặc navigate đến `/posts/{postId}`.
3. Hiển thị:
   - Content title + text content (lazy fetch từ Content API).
   - Brand name.
   - Page name + platform.
   - Published at (absolute datetime).
   - External post ID.
   - Link "View on Facebook" (mở tab mới với URL `https://facebook.com/{externalPostId}`).
   - Link "View Content" (điều hướng đến Content Detail).
4. Nếu post không tồn tại → 404 page.

### 6.5 Refresh danh sách

1. Nút Refresh trên header.
2. Gọi lại API với page hiện tại.
3. Cập nhật danh sách.

## 8. Quy tắc nghiệp vụ

| Mã | Quy tắc |
| --- | --- |
| BR-01 | Post record chỉ được tạo khi publish thành công (BE enforce). |
| BR-02 | Post là immutable read-only record; không có update/delete API cho post. |
| BR-03 | Danh sách posts được scope theo profile đang active (BE enforce ownership). |
| BR-04 | `ExternalPostId` là Facebook post ID, dùng để tạo link `https://facebook.com/{id}`. |
| BR-05 | Sắp xếp mặc định: `PublishedAt` giảm dần (mới nhất đầu tiên). |

## 12. Acceptance Criteria

### AC-01 - Xem danh sách posts

**Given** profile có posts đã publish
**When** vào màn hình Post History
**Then** `GET /api/posts?page=1&pageSize=10` được gọi
**And** danh sách posts hiển thị với content title, brand, page, thời gian.

### AC-02 - Pagination

**Given** có > 10 posts
**When** render danh sách
**Then** chỉ hiển thị 10 items + pagination controls
**When** nhấn "Next" hoặc page số
**Then** gọi API với page tương ứng.

### AC-03 - Lọc theo brand

**Given** có brand filter dropdown
**When** chọn brand cụ thể
**Then** gọi `GET /api/posts?brandId={id}&page=1&pageSize=10`
**And** danh sách chỉ hiển thị posts của brand đó.

### AC-04 - View on Facebook

**Given** post có `externalPostId`
**When** nhấn "View on Facebook"
**Then** mở tab mới với URL `https://facebook.com/{externalPostId}`.

### AC-05 - Post detail

**Given** click vào post item
**When** render detail
**Then** hiển thị đầy đủ thông tin: content title, brand, page, thời gian, external ID.

### AC-06 - Empty state

**Given** chưa có post nào
**When** vào Post History
**Then** empty state + nút "Tạo content mới".

### AC-07 - Loading state

**Given** đang fetch
**When** render
**Then** skeleton loading.

### AC-08 - Error state

**Given** API call fail
**When** render
**Then** error state + nút Retry
**When** nhấn Retry
**Then** gọi lại API.

### AC-09 - Refresh

**Given** có danh sách posts
**When** nhấn Refresh
**Then** gọi lại API với page hiện tại.

### AC-10 - Link to Content Detail

**Given** post item hiển thị
**When** click content title
**Then** navigate đến Content Detail page.

```typescript
import { apiRequest } from "@/lib/api/fetcher";
import type { PostListItemDto } from "@/features/posts/types/post";
import type { PagedResult } from "@/lib/types/pagination";

export const postsApi = {
  list: (params?: { page?: number; pageSize?: number; brandId?: string; status?: string }) =>
    apiRequest<PagedResult<PostListItemDto>>("/api/posts", {
      method: "GET",
      auth: true,
      params,
    }),

  getById: (postId: string) =>
    apiRequest<PostListItemDto>(`/api/posts/${postId}`, {
      method: "GET",
      auth: true,
    }),
};
```

#### Hooks

```typescript
export function usePosts(params?: { page?: number; brandId?: string }) {
  return useQuery({
    queryKey: ["posts", params],
    queryFn: () => postsApi.list({ page: params?.page ?? 1, pageSize: 10, brandId: params?.brandId }),
  });
}

export function usePostDetail(postId: string) {
  return useQuery({
    queryKey: ["post", postId],
    queryFn: () => postsApi.getById(postId),
    enabled: Boolean(postId),
  });
}
```

```tsx
export default function PostHistoryPage() {
  const [page, setPage] = useState(1);
  const [brandId, setBrandId] = useState<string>("");

        <h1 className="text-2xl font-semibold">Post History</h1>
        <Button variant="ghost" size="sm" onClick={() => refetch()}>

        </Button>
      </div>

      {/* Brand filter */}
      <BrandFilterSelect value={brandId} onChange={setBrandId} />

      {data && data.data.length > 0 ? (
        <>
          <div className="space-y-2">
            {data.data.map((post) => (
              <PostListItem key={post.id} post={post} />
            ))}
          </div>

          <Pagination
            page={data.page}
            totalPages={Math.ceil(data.totalCount / data.pageSize)}
            onPageChange={setPage}
          />
        </>
      ) : (
        <PostEmptyState />

    </div>
  );
}
```

```tsx
              <span>📘 {post.pageName ?? "Unknown Page"}</span>
              <span>🕐 {formatRelativeTime(post.publishedAt)}</span>

          </div>
```
