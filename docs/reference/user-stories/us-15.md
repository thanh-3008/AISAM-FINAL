# US-15 Frontend Detail - Quan ly brand kit

## 1. User story

La nguoi dung da dang nhap va da chon business profile, toi muon tao, xem, cap nhat, xoa va khoi phuc brand kit de cung cap ngu canh thuong hieu cho noi dung AI.

## 2. Muc tieu frontend

- Cung cap man hinh quan ly brand kit theo active profile.
- Goi dung API Brand MVP dang active trong backend.
- Dam bao frontend chi thao tac brand thuoc profile ma user so huu.
- Tao nen du lieu brand de cac module Product, Content va AI dung lam context.

## 3. Can cu backend va scope hien tai

### Requirement lien quan

- `docs/main/requirements.md` muc `6.3 Business Profile and Brand Kit` yeu cau tao, sua, xoa brand kit.
- Requirement co nhac color theme, tone of voice, persona va hashtag, nhung backend MVP hien tai chua co field/endpoint tuong ung.

### Backend plan lien quan

- `docs/archive/plans/backend-code-plan.md` Phase 4 da active Brand MVP.
- `CODEBASE_UPDATE.md` xac nhan Profile/Brand/Product la foundation da co controller/service/repository.

### Backend implementation thuc te

- Controller: `AISAM-BE/AISAM.API/Controllers/BrandController.cs`
- Service: `AISAM-BE/AISAM.Services/Service/BrandService.cs`
- DTO:
  - `CreateBrandRequest`
  - `UpdateBrandRequest`
  - `BrandResponseDto`
- Authorization: bat buoc JWT.
- Response list: `GenericResponse<PagedResult<BrandResponseDto>>`
- Response detail/create/update: `GenericResponse<BrandResponseDto>`
- Response delete/restore: `GenericResponse<bool>`

### Hanh vi backend can frontend phai follow

- Tat ca endpoint brand can `Authorization: Bearer <accessToken>`.
- List brand bat buoc gui `profileId` query.
- Create brand bat buoc gui `profileId` trong body.
- Backend chi cho phep thao tac brand neu profile thuoc user trong JWT.
- Neu profile khong ton tai:
  - backend tra error message `Profile not found`
- Neu profile khong thuoc user:
  - backend tra error message `You are not allowed to access this profile`
- Delete la soft delete.
- Restore chi thanh cong khi brand dang bi soft delete.
- `GET /api/brands/{id}` hien tai chi lay brand chua bi xoa.
- Muon hien brand da xoa de khoi phuc, frontend phai dung list voi `includeDeleted=true`.

## 4. Pham vi frontend

### Trong pham vi

- Tao brand kit
- Xem chi tiet brand kit
- Cap nhat brand kit

## 5. API contract can dung

### List request

`GET /api/brands?profileId={profileId}&page=1&pageSize=10&searchTerm=&sortBy=&sortDescending=true&includeDeleted=false`

Header:

```http
Authorization: Bearer <accessToken>
```

Query params:

- `profileId` required
- `page` optional, default `1`
- `pageSize` optional, default `10`, backend clamp toi da `100`
- `searchTerm` optional, search theo `name` va `description`
- `sortBy` optional:
  - `name`
  - `createdAt`
- `sortDescending` optional, default `true`
- `includeDeleted` optional, default `false`

### Detail request

`GET /api/brands/{id}`

Header:

```http
Authorization: Bearer <accessToken>
```

### Create request

`POST /api/brands`

Header:

```http
Authorization: Bearer <accessToken>
Content-Type: application/json
```

Body:

```json
{
  "name": "AISAM Coffee",
  "description": "Brand ca phe danh cho dan van phong",
  "logoUrl": "https://example.com/logo.png",
  "slogan": "Start sharp, stay warm",
  "usp": "Ca phe rang moc, giao nhanh trong ngay",
  "targetAudience": "Nhan vien van phong 22-35 tuoi",
  "profileId": "profile-guid"
}
```

### Update request

`PUT /api/brands/{id}`

Header:

```http
Authorization: Bearer <accessToken>
Content-Type: application/json
```

Body fields deu optional:

```json
{
  "name": "AISAM Coffee Updated",
  "description": "Mo ta moi",
  "logoUrl": "https://example.com/logo-new.png",
  "slogan": "Slogan moi",
  "usp": "USP moi",
  "targetAudience": "Target audience moi",
  "profileId": "profile-guid"
}
```

Luu y:

- Backend update khong doi `ProfileId`; service hien tai validate ownership theo brand dang co.
- Frontend co the gui `profileId` de giu contract thong nhat, nhung khong nen cho user chuyen brand sang profile khac trong story nay.

### Delete request

`DELETE /api/brands/{id}`

Header:

```http
Authorization: Bearer <accessToken>
```

### Restore request

`POST /api/brands/{id}/restore`

Header:

```http
Authorization: Bearer <accessToken>
```

### Error response can xu ly

- `401` neu chua dang nhap hoac token khong hop le
- `400` voi cac loi:
  - `ProfileId is required`
  - `Profile not found`
  - `You are not allowed to access this profile`
  - `Brand is not deleted`
- `404` voi detail/delete brand khong ton tai hoac khong con active
- `500` neu loi he thong

## 7. Validation frontend

- `name` required
- `name` toi da `255` ky tu
- `description` toi da `2000` ky tu
- `logoUrl` toi da `500` ky tu va nen validate URL format neu co gia tri
- `slogan` toi da `255` ky tu
- `profileId` phai lay tu active profile, khong lay tu input tay
- Khong cho submit create neu chua co active profile

## 8. Data flow frontend

1. User vao `/brand`
2. Frontend kiem tra auth session va active profile
3. Neu chua co active profile:
   - hien empty/blocking state yeu cau chon profile
   - CTA ve `/profiles`
4. Neu da co active profile:
   - goi `GET /api/brands?profileId={activeProfile.id}`
5. User search/sort/page:
   - goi lai list voi query tuong ung
6. User tao brand:
   - submit `POST /api/brands` voi `profileId` active
   - invalidate/refetch list
7. User sua brand:
   - co the dung data tren list hoac goi detail `GET /api/brands/{id}`
   - submit `PUT /api/brands/{id}`
   - invalidate/refetch list va detail
8. User xoa brand:
   - confirm
   - goi `DELETE /api/brands/{id}`
   - refetch active list va deleted list neu dang co cache
9. User khoi phuc brand:
   - chuyen sang deleted view hoac list voi `includeDeleted=true`
   - goi `POST /api/brands/{id}/restore`
   - refetch list

## 9. State can xu ly

### Loading state

- loading list ban dau
- loading search/page/sort
- loading create/update/delete/restore action

### Success state

- toast/banner khi tao, cap nhat, xoa, khoi phuc thanh cong
- list cap nhat dung sau mutation

### Error state

- chua chon active profile
- `401` redirect login theo fetcher chung
- `Profile not found`
- `You are not allowed to access this profile`
- `Brand not found`
- validation error tu backend
- generic server error

## 10. Auth/profile/session impact

- Khong doi auth session.
- Bat buoc co active profile tu `profile-store`.
- Story nay khong bat buoc gui `X-Profile-Id` vi BrandController hien tai dung `profileId` query/body, nhung neu fetcher chung da gan header nay cho module protected thi khong gay hai.
- Khi active profile thay doi, brand list phai refetch theo profile moi.

## 11. Dieu huong sau thao tac

- Sau create/update: o lai `/brand`, dong dialog/form va refetch list.
- Sau delete: o lai `/brand`, xoa item khoi active list.
- Sau restore: o lai deleted view hoac chuyen ve active view tuy UX, nhung phai refetch.

## 12. Acceptance criteria

### AC-01

Frontend chi load brand khi user da dang nhap va co active profile.

### AC-02

Frontend goi list brand dung endpoint `GET /api/brands` voi `profileId` cua active profile.

### AC-03

Frontend tao brand bang `POST /api/brands` voi JSON body co `profileId`, `name` va cac field optional dung contract.

### AC-04

Frontend cap nhat brand bang `PUT /api/brands/{id}` va dong bo lai list/detail sau khi thanh cong.

### AC-05

Frontend xoa brand bang `DELETE /api/brands/{id}` sau confirm va khong hien brand do trong active list.

### AC-06

Frontend co cach xem brand da xoa bang `includeDeleted=true` va khoi phuc bang `POST /api/brands/{id}/restore`.

### AC-07

Frontend khong expose cac field backend chua support nhu color theme, tone of voice, persona va hashtag nhu field luu chinh thuc.

### AC-08

Khi backend tra ownership/profile error, frontend hien thong diep ro va khong mat du lieu form dang nhap.

## 14. Ghi chu implementation

- Backend create tra HTTP `201`, frontend khong duoc hardcode chi chap nhan `200`.
- `BrandResponseDto` hien chua co `isDeleted`, nen khi dung `includeDeleted=true`, frontend co the can suy luan deleted view theo query/action vua thao tac hoac chi dung view nay cho restore list neu backend bo sung field sau.
- Neu UI can phan biet active/deleted ro rang, nen de xuat backend bo sung `isDeleted` vao `BrandResponseDto` trong story/backend task rieng.
- `logoUrl` chi la URL string; khong implement file picker/upload trong story nay.
- Cac field requirement chua co backend support nen nen de backlog/post-MVP hoac story rieng sau khi backend mo schema.
