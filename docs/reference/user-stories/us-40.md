# US-40 - Đặt lịch đăng bài một lần

## 1. User Story

**Là** người dùng,
**tôi muốn** tạo lịch đăng bài một lần cho content để tự động xuất bản đúng thời điểm,
**để** có thể lên kế hoạch nội dung trước mà không cần can thiệp thủ công vào thời điểm đăng.

---

## 2. Mục tiêu

Cung cấp action "Schedule" trên Content Detail, cho phép người dùng chọn một hoặc nhiều Facebook Page đã liên kết, chọn thời điểm đăng trong tương lai, và tạo ContentSchedule record. Backend sẽ tự động publish qua `ScheduledPostingService` khi đến hạn. Flow bao gồm: date/time picker, page selection, preview, validation schedule time, và notification xác nhận.

---

## 3. Phạm vi

### Trong phạm vi

- Nút "Schedule" trên Content Detail page (kế bên "Publish Now" từ US-34).
- Schedule modal với các components:
  - Preview nội dung content (text, image, video) — reuse từ US-34.
  - Date picker + time picker (chọn giờ trong tương lai).
  - Danh sách Facebook pages theo brand của content (checkbox multi-select).
  - Nút "Schedule" để xác nhận.
- Gọi `POST /api/content-schedules` với `{ contentId, integrationId, scheduledAt }`.
- Validate: scheduledAt phải > now (ít nhất 15 phút trong tương lai).
- Hỗ trợ schedule cho nhiều pages: gọi API tuần tự (mỗi integration một schedule record).
- Toast success: "Đã lên lịch đăng bài lúc {datetime}."
- Toast error với message lỗi cụ thể.
- Sau khi schedule thành công:
  - Tạo notification "PostScheduled" tự động (BE xử lý khi create).
  - Content status vẫn giữ nguyên (chưa published, chờ đến hạn).
- Loading state: spinner trên nút "Schedule".

### Ngoài phạm vi

- Xem danh sách schedule đã tạo: US-41.
- Cập nhật / xoá schedule: US-41.
- Xem upcoming schedules: US-41.
- Recurring / repeating schedule (Daily/Weekly/Monthly): deferred (BE có `RepeatTypeEnum` nhưng chưa dùng cho MVP).
- Schedule cho nhiều brand cùng lúc: mỗi content chỉ thuộc một brand.
- Publish ngay (Publish Now): US-34.
- Background worker xử lý schedule đến hạn: BE `ScheduledPostingService`.
- Dashboard tổng quan schedule count: US-43.

---

## 4. Actor

- **Chính:** Người dùng đã đăng nhập, có active profile, đã soạn content (Draft/Approved) và đã liên kết Facebook pages với brand.
- **Phụ:** Backend API (`ContentSchedulesController`, `ContentScheduleService`), `ScheduledPostingService` (worker), `NotificationService`.

---

## 5. Tiền điều kiện

- Người dùng đã đăng nhập và có JWT token hợp lệ.
- Người dùng đã chọn active profile (`X-Profile-Id` header).
- Content tồn tại, thuộc profile đang active, và chưa được publish (`Status != Published`).
- Brand của content có ít nhất một Facebook page đã liên kết (integration).
- Thời điểm schedule phải trong tương lai (> 15 phút từ hiện tại).

---

## 6. Luồng nghiệp vụ chính

### 6.1 Schedule content lên Facebook Page

1. Người dùng đang ở màn hình Content Detail.
2. Content có status là `Draft`, `PendingApproval`, hoặc `Approved` (không phải `Published`).
3. User nhấn nút **"Schedule"** (kế bên nút "Publish Now").
4. Modal "Schedule Content" mở ra với:
   - Preview nội dung: text content, images, video URL (nếu có) — reuse PublishPreview từ US-34.
   - Date picker + time picker (hiển thị giờ địa phương của user).
   - Danh sách Facebook pages đã liên kết với brand của content (từ `GET /api/social/integrations/brand/{brandId}`).
   - Mỗi page có checkbox để chọn.
   - Nút **"Schedule"** (disabled nếu chưọn page hoặc chưa chọn thời gian).
5. User chọn 1 hoặc nhiều pages, chọn thời gian, và nhấn **"Schedule"**.
6. Frontend validate: `scheduledAt` > now + 15 phút. Nếu không hợp lệ, hiển thị lỗi inline.
7. Frontend gọi `POST /api/content-schedules` cho từng integration (tuần tự).
   - Request body: `{ contentId, integrationId, scheduledAt }`.
8. Trong khi đang schedule:
   - Progress indicator: "Đang lên lịch... ({current}/{total})".
   - Mỗi page hiển thị trạng thái: pending / scheduling / success / failed.
9. Sau khi hoàn tất:
   - Toast "Đã lên lịch đăng bài lúc {datetime} cho {n} page(s)."
   - Đóng modal (auto-close sau 2 giây nếu all success).
   - BE tự động tạo notification "PostScheduled" cho user (US-36).

### 6.2 Xác nhận schedule thành công

1. Sau khi schedule, content detail vẫn giữ nguyên status (Draft/Approved).
2. Một badge/label nhỏ hiển thị "Scheduled" trên content card (nếu cần, thuộc US-41).
3. User có thể xem schedule đã tạo trong trang Schedules (US-41).

## 9. API Contracts

### 9.1 Create Content Schedule

```
POST /api/content-schedules
```

#### Headers
```http
Authorization: Bearer <access-token>
X-Profile-Id: <owned-profile-guid>
Content-Type: application/json
```

#### Request Body
```json
{
  "contentId": "content-guid",
  "integrationId": "integration-guid",
  "scheduledAt": "2026-06-10T15:00:00Z"
}
```

#### Response (201 Created)
```json
{
  "success": true,
  "statusCode": 201,
  "message": "Schedule created successfully.",
  "data": {
    "id": "schedule-guid",
    "profileId": "profile-guid",
    "contentId": "content-guid",
    "integrationId": "integration-guid",
    "scheduledAt": "2026-06-10T15:00:00Z",
    "executedAt": null,
    "status": "Pending",
    "attemptCount": 0,
    "lastError": null
  },
  "timestamp": "2026-06-03T15:00:00Z"
}
```

#### Response (400 Bad Request - invalid time)
```json
{
  "success": false,
  "statusCode": 400,
  "message": "Scheduled time is invalid.",
  "data": null,
  "timestamp": "2026-06-03T15:00:00Z"
}
```

#### Response (404 Not Found - content/integration)
```json
{
  "success": false,
  "statusCode": 404,
  "message": "Content not found.",
  "data": null,
  "timestamp": "2026-06-03T15:00:00Z"
}
```

## 12. Acceptance Criteria

### AC-01 - Nút Schedule trên Content Detail

**Given** content chưa published (Draft/Approved)
**Then** hiển thị nút "Schedule" kế bên "Publish Now".

### AC-02 - Mở Schedule modal

**Given** click nút Schedule
**Then** mở modal với preview, date/time picker, danh sách pages, nút Schedule.

### AC-03 - Chọn thời gian

**Given** modal đã mở
**When** chọn ngày và giờ trong tương lai
**Then** hiển thị thời gian đã chọn (giờ địa phương + UTC tương ứng).

### AC-04 - Chọn pages

**Given** modal đã mở
**When** chọn checkbox pages
**Then** hiển thị số pages đã chọn, nút Schedule cập nhật.

### AC-05 - Schedule thành công

**Given** đã chọn pages + thời gian
**When** nhấn Schedule
**Then** gọi `POST /api/content-schedules` cho từng integration
**And** toast "Đã lên lịch đăng bài lúc {time}."
**And** modal đóng sau 2 giây.

### AC-06 - Validate thời gian

**Given** chọn thời gian < 15 phút từ now
**When** nhấn Schedule
**Then** hiển thị lỗi inline "Thời gian phải cách hiện tại ít nhất 15 phút."

### AC-07 - Content đã published

**Given** content đã Published
**Then** ẩn nút Schedule.

### AC-08 - Không có integration

**Given** brand chưa có page nào liên kết
**When** mở Schedule modal
**Then** hiển thị empty state + nút "Manage Pages".

### AC-09 - Partial success

**Given** schedule cho 3 pages, 2 success 1 fail
**Then** toast warning "Đã lên lịch 2/3 pages."
**And** nút "Retry Failed" cho page fail.

### AC-10 - Loading state

**Given** đang schedule
**Then** nút Schedule spinner + disabled, mỗi page hiển thị trạng thái.

## 13. Gợi ý Implementation Theo Tech Stack

### Backend - .NET 8

> **Lưu ý:** Backend đã implement:
> - `ContentSchedulesController` — `POST /api/content-schedules`.
> - `ContentScheduleService.CreateAsync` — validate content/integration ownership, normalize time, create ContentCalendar record, tạo notification.
> - `ContentCalendar` model với `ScheduledAt`, `Status`, `AttemptCount`, `LastError`.
> - `CreateContentScheduleRequest` — `{ ContentId, IntegrationId, ScheduledAt }`.
> - `ContentScheduleDto` response — Id, ContentId, IntegrationId, ScheduledAt, ExecutedAt, Status, AttemptCount, LastError.
> - `ScheduleStatusEnum` — Pending=0, Processing=1, Completed=2, Failed=3.
> - Notification tự động tạo khi schedule created (type `PostScheduled`).
>
> **Lưu ý:** API hiện tại chỉ nhận một `integrationId` per request. Để schedule cho nhiều pages, FE gọi API tuần tự (mỗi page một request).

**useScheduleToMultiplePages:**

```typescript
// features/content/hooks/use-schedule-to-multiple-pages.ts
import { useCreateSchedule } from "./use-create-schedule";

export function useScheduleToMultiplePages(contentId: string) {
  const singleSchedule = useCreateSchedule();

  const scheduleAll = async (
    integrationIds: string[],
    scheduledAt: string,
    onProgress: (completed: number, total: number, failed: { id: string; error: string }[]) => void
  ) => {
    const failed: { id: string; error: string }[] = [];
    let completed = 0;

    for (const integrationId of integrationIds) {
      try {
        await singleSchedule.mutateAsync({
          contentId,
          integrationId,
          scheduledAt,
        });
      } catch (err) {
        failed.push({ id: integrationId, error: (err as Error).message });
      }
      completed++;
      onProgress(completed, integrationIds.length, failed);
    }

    return { totalSuccess: completed - failed.length, totalFailed: failed.length, failed };
  };

  return {
    scheduleAll,
    isPending: singleSchedule.isPending,
  };
}
```

#### Components

**ScheduleModal:**

```tsx
// features/content/components/schedule-modal.tsx
import { useState, useCallback } from "react";
import { format, addMinutes } from "date-fns";
import { vi } from "date-fns/locale";
import { Button } from "@/components/ui/button";
import { Dialog, DialogContent, DialogHeader, DialogTitle, DialogFooter } from "@/components/ui/dialog";
import { PublishPreview } from "./publish-preview"; // reuse từ US-34
import { ScheduleDatetimePicker } from "./schedule-datetime-picker";
import { SchedulePageItem } from "./schedule-page-item";
import { useScheduleToMultiplePages } from "@/features/content/hooks/use-schedule-to-multiple-pages";
import type { SocialIntegrationDto } from "@/features/social/types/social";
import type { ContentResponseDto } from "@/features/content/types/content";
import type { SchedulePageState } from "@/features/content/types/schedule";

const MIN_SCHEDULE_MINUTES = 15;

function ScheduleModal({
  content,
  integrations,
  open,
  onOpenChange,
}: {
  content: ContentResponseDto;
  integrations: SocialIntegrationDto[];
  open: boolean;
  onOpenChange: (open: boolean) => void;
}) {
  const [selectedIds, setSelectedIds] = useState<Set<string>>(new Set());
  const [scheduledAt, setScheduledAt] = useState<Date | null>(null);
  const [pageStates, setPageStates] = useState<SchedulePageState[]>([]);
  const [scheduleDone, setScheduleDone] = useState(false);
  const [timeError, setTimeError] = useState<string | null>(null);
  const { scheduleAll, isPending } = useScheduleToMultiplePages(content.id);

  const noIntegrations = integrations.length === 0;
  const minDate = addMinutes(new Date(), MIN_SCHEDULE_MINUTES);

  const validateTime = useCallback((date: Date | null): boolean => {
    if (!date) return false;
    const diffMs = date.getTime() - Date.now();
    const diffMin = diffMs / 60_000;
    if (diffMin < MIN_SCHEDULE_MINUTES) {
      setTimeError(`Thời gian phải cách hiện tại ít nhất ${MIN_SCHEDULE_MINUTES} phút.`);
      return false;
    }
    setTimeError(null);
    return true;
  }, []);

  const handleSchedule = async () => {
    if (!scheduledAt || !validateTime(scheduledAt)) return;

    const ids = Array.from(selectedIds);
    const initialStates: SchedulePageState[] = ids.map((id) => ({
      integration: integrations.find((i) => i.id === id)!,
      status: "pending",
    }));
    setPageStates(initialStates);
    setScheduleDone(false);

    const isoDate = scheduledAt.toISOString();
    const { totalSuccess, totalFailed } = await scheduleAll(
      ids,
      isoDate,
      (completed, total, failedSoFar) => {
        setPageStates((prev) =>
          prev.map((ps, idx) => {
            const isCompleted = idx < completed;
            const isFailed = failedSoFar.some((f) => f.id === ps.integration.id);
            if (isFailed) return { ...ps, status: "failed", errorMessage: failedSoFar.find((f) => f.id === ps.integration.id)?.error };
            if (isCompleted) return { ...ps, status: "success" };
            if (idx === completed) return { ...ps, status: "scheduling" };
            return ps;
          })
        );
      }
    );

    setScheduleDone(true);

    if (totalSuccess === ids.length) {
      useToastStore.getState().push({
        title: `Đã lên lịch đăng bài lúc ${format(scheduledAt, "HH:mm dd/MM/yyyy", { locale: vi })}.`,
        tone: "success",
      });
      setTimeout(() => onOpenChange(false), 2000);
    } else if (totalSuccess > 0) {
      useToastStore.getState().push({
        title: `Đã lên lịch ${totalSuccess}/${ids.length} pages. ${totalFailed} pages thất bại.`,
        tone: "warning",
      });
    } else {
      useToastStore.getState().push({
        title: "Tạo lịch đăng thất bại.",
        tone: "error",
      });
    }
  };

  return (
    <Dialog open={open} onOpenChange={onOpenChange}>
      <DialogContent className="max-w-lg">
        <DialogHeader>
          <DialogTitle>
            {isPending
              ? `Đang lên lịch... (${pageStates.filter((s) => s.status === "success").length}/${selectedIds.size})`
              : scheduleDone
              ? "📅 Đã lên lịch"
              : "📅 Schedule Content"}
          </DialogTitle>
        </DialogHeader>

        {/* Preview content */}
        <PublishPreview content={content} />

        {isPending || scheduleDone ? (
          /* Progress / Result */
          <div className="space-y-2">
            {pageStates.map((ps) => (
              <SchedulePageItem key={ps.integration.id} state={ps} scheduledAt={scheduledAt} />
            ))}
          </div>
        ) : noIntegrations ? (
          /* Empty state */
          <div className="flex flex-col items-center gap-3 py-8 text-center text-sm text-muted-foreground">
            <LinkIcon className="h-10 w-10" />
            <p>Chưa có page nào liên kết với brand này.</p>
            <Button variant="link" size="sm" onClick={() => {
              onOpenChange(false);
              // Navigate to social page
              window.location.href = "/social";
            }}>
              Manage Pages
            </Button>
          </div>
        ) : (
          <>
            {/* Date/Time picker */}
            <ScheduleDatetimePicker
              value={scheduledAt}
              onChange={(date) => {
                setScheduledAt(date);
                if (date) validateTime(date);
              }}
              minDate={minDate}
              error={timeError}
            />

            {/* Page selection */}
            <div className="space-y-2">
              <p className="text-sm font-medium">Select Pages:</p>
              {integrations.map((integration) => (
                <label
                  key={integration.id}
                  className="flex cursor-pointer items-center gap-3 rounded-lg border p-3 transition-colors hover:bg-muted/50"
                >
                  <input
                    type="checkbox"
                    className="h-4 w-4"
                    checked={selectedIds.has(integration.id)}
                    onChange={(e) => {
                      setSelectedIds((prev) => {
                        const next = new Set(prev);
                        e.target.checked ? next.add(integration.id) : next.delete(integration.id);
                        return next;
                      });
                    }}
                  />
                  <span className="flex-1 text-sm">{integration.name}</span>
                  <span className="text-xs text-muted-foreground">{integration.platform}</span>
                </label>
              ))}
              {selectedIds.size > 0 && (
                <p className="text-xs text-muted-foreground">
                  ({selectedIds.size} page{selectedIds.size > 1 ? "s" : ""} selected)
                </p>
              )}
            </div>
          </>
        )}

        <DialogFooter>
          <Button
            variant="outline"
            onClick={() => onOpenChange(false)}
            disabled={isPending}
          >
            {isPending ? "Đóng" : "Cancel"}
          </Button>

          {!isPending && !scheduleDone && !noIntegrations && (
            <Button
              onClick={handleSchedule}
              disabled={selectedIds.size === 0 || !scheduledAt || !!timeError}
            >
              <CalendarClock className="mr-2 h-4 w-4" />
              Schedule{selectedIds.size > 0 ? ` (${selectedIds.size})` : ""}
            </Button>
          )}

          {scheduleDone && pageStates.some((ps) => ps.status === "failed") && (
            <Button
              variant="secondary"
              onClick={() => {
                /* Retry failed */
                const failedIds = pageStates
                  .filter((ps) => ps.status === "failed")
                  .map((ps) => ps.integration.id);
                setSelectedIds(new Set(failedIds));
                setPageStates([]);
                setScheduleDone(false);
              }}
            >
              Retry Failed ({pageStates.filter((ps) => ps.status === "failed").length})
            </Button>
          )}

          {scheduleDone && (
            <Button variant="ghost" onClick={() => {
              onOpenChange(false);
              // Navigate to schedules list
              window.location.href = "/schedules";
            }}>
              Xem lịch đăng
            </Button>
          )}
        </DialogFooter>
      </DialogContent>
    </Dialog>
  );
}
```

```tsx
// features/content/components/schedule-datetime-picker.tsx
import { useState } from "react";
import { format, addMinutes } from "date-fns";
import { vi } from "date-fns/locale";
import { Calendar as CalendarIcon, Clock } from "lucide-react";
import { Button } from "@/components/ui/button";
import { Popover, PopoverContent, PopoverTrigger } from "@/components/ui/popover";
import { Calendar } from "@/components/ui/calendar";
import { Select, SelectContent, SelectItem, SelectTrigger, SelectValue } from "@/components/ui/select";

interface Props {
  value: Date | null;
  onChange: (date: Date) => void;
  minDate: Date;
  error?: string | null;
}

const TIME_OPTIONS: string[] = [];
for (let h = 0; h < 24; h++) {
  for (let m = 0; m < 60; m += 15) {
    TIME_OPTIONS.push(`${String(h).padStart(2, "0")}:${String(m).padStart(2, "0")}`);
  }
}

function ScheduleDatetimePicker({ value, onChange, minDate, error }: Props) {
  const [selectedDate, setSelectedDate] = useState<Date | undefined>(value ?? undefined);
  const [selectedTime, setSelectedTime] = useState<string>(
    value ? format(value, "HH:mm") : ""
  );

  const handleDateSelect = (date: Date | undefined) => {
    if (!date) return;
    setSelectedDate(date);
    updateDateTime(date, selectedTime);
  };

  const handleTimeSelect = (time: string) => {
    setSelectedTime(time);
    if (selectedDate) {
      updateDateTime(selectedDate, time);
    }
  };

  const updateDateTime = (date: Date, time: string) => {
    if (!time) return;
    const [hours, minutes] = time.split(":").map(Number);
    const result = new Date(date);
    result.setHours(hours, minutes, 0, 0);
    onChange(result);
  };

  const selectedDateTime = value
    ? format(value, "EEEE, dd/MM/yyyy 'lúc' HH:mm", { locale: vi })
    : "";

  const utcTime = value
    ? `→ UTC: ${format(value, "HH:mm")}`
    : "";

  return (
    <div className="space-y-3 rounded-lg border p-4">
      <p className="text-sm font-medium">Schedule Time</p>

      <div className="flex gap-2">
        {/* Date picker */}
        <Popover>
          <PopoverTrigger asChild>
            <Button
              variant="outline"
              className="flex-1 justify-start text-left font-normal"
            >
              <CalendarIcon className="mr-2 h-4 w-4" />
              {selectedDate ? format(selectedDate, "dd/MM/yyyy") : "Chọn ngày"}
            </Button>
          </PopoverTrigger>
          <PopoverContent className="w-auto p-0" align="start">
            <Calendar
              mode="single"
              selected={selectedDate}
              onSelect={handleDateSelect}
              disabled={(date) => date < minDate}
              initialFocus
              locale={vi}
            />
          </PopoverContent>
        </Popover>

        {/* Time picker */}
        <Select value={selectedTime} onValueChange={handleTimeSelect}>
          <SelectTrigger className="w-28">
            <Clock className="mr-2 h-4 w-4" />
            <SelectValue placeholder="Giờ" />
          </SelectTrigger>
          <SelectContent>
            {TIME_OPTIONS.map((t) => (
              <SelectItem key={t} value={t}>
                {t}
              </SelectItem>
            ))}
          </SelectContent>
        </Select>
      </div>

      {/* Preview / error */}
      {error && (
        <p className="text-xs text-destructive">{error}</p>
      )}
      {selectedDateTime && !error && (
        <div className="rounded-md bg-muted/30 px-3 py-2 text-xs text-muted-foreground">
          <p>⏰ {selectedDateTime} (giờ địa phương)</p>
          <p>{utcTime}</p>
        </div>
      )}
    </div>
  );
}
```
