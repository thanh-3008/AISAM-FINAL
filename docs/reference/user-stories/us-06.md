# US-06 Frontend Detail - Dang xuat tat ca phien dang nhap

## 1. User story

La nguoi dung da dang nhap, toi muon dang xuat khoi tat ca cac phien de bao ve tai khoan cua minh.

## 2. Muc tieu frontend

- Cung cap thao tac `logout all sessions` trong trang security.
- Goi dung endpoint backend dang co.
- Sau thao tac thanh cong, frontend buoc user dang nhap lai.

## 3. Can cu backend va scope hien tai

### Requirement lien quan

- `docs/main/requirements.md` muc `6.1` yeu cau quan ly session.

### Backend plan lien quan

- `docs/archive/plans/backend-code-plan.md` Phase 3 co `logout-all` va `sessions`.

### Backend implementation thuc te

- Endpoint: `POST /api/Auth/logout-all`
- Authorization: bat buoc
- Response: `GenericResponse<object>` voi `data = null`

### Hanh vi backend can frontend phai follow

- Backend revoke tat ca active sessions cua user
- Bao gom ca session hien tai, nen frontend phai xem session sau thao tac la khong con hop le

## 4. Pham vi frontend

### Trong pham vi

- CTA `Logout all sessions`
- Goi API
- Clear session local
- Redirect `/login`

### Ngoai pham vi

- Quan ly chi tiet tung session: co the doc o `sessions`, nhung xoa tung session rieng backend chua co endpoint

## 5. API contract can dung

### Request

`POST /api/Auth/logout-all`

Header:

```http
Authorization: Bearer <accessToken>
```

### Success response

HTTP: `200 OK`

```json
{
  "success": true,
  "message": "All sessions logged out successfully",
  "statusCode": 200,
  "data": null,
  "error": null
}
```

### Error response

- `500` neu loi he thong

## 6. UI/UX spec

### Route/vi tri

- Trang `/security`

### Hanh vi UX

- Nen co confirm modal vi thao tac nay co impact lon
- Copy de xuat:
  - title: `Log out all sessions`
  - body: `You will need to log in again on this device and other devices.`

## 7. Validation frontend

- Chi hien CTA cho user da authenticated
- Khong can body request

## 8. Data flow frontend

1. User vao `/security`
2. Bam `Logout all sessions`
3. Frontend xac nhan neu co modal
4. Goi `POST /api/Auth/logout-all`
5. Neu thanh cong:
   - clear auth store
   - clear active profile
   - redirect `/login`
6. Neu that bai:
   - van co the clear local session neu muon ep state an toan

## 9. State can xu ly

### Loading state

- Disable CTA khi request dang chay

### Success state

- User bi dua ve login

### Error state

- Toast thong bao thao tac khong thanh cong tren server
- Tuy nhien local session khong nen tiep tuc duoc tin tuong neu user muon ket thuc tat ca phien

## 10. Auth/session impact

- Mọi session cua user deu bi revoke o backend
- Session local hien tai khong con hop le
- TanStack Query cache cho protected data nen bi clear

## 11. Dieu huong sau thao tac

- Redirect `/login`

## 12. Acceptance criteria

### AC-01

Frontend goi dung `POST /api/Auth/logout-all` tu trang security.

### AC-02

Sau thao tac thanh cong, user hien tai bi dang xuat khoi frontend.

### AC-03

Frontend khong de user tiep tuc o protected area bang session cu sau khi da logout all.

## 13. Test cases frontend

### FE-01

Click `Logout all sessions` goi dung endpoint authorized.

### FE-02

Thanh cong se clear auth va profile store.

### FE-03

Sau thao tac, frontend redirect `/login`.

## 14. Ghi chu implementation

- Story nay phu hop dat tren security page, khong nen dat trong menu nhanh neu UX muon tranh bam nham.
- Neu co hien session list bang `GET /api/Auth/sessions`, danh sach nay chi de doc, khong co endpoint revoke tung session.
