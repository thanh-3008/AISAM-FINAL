# US-29 - Kết nối Facebook qua OAuth

## 1. User Story

**Là** người dùng,
**tôi muốn** kết nối tài khoản Facebook để hệ thống có thể truy cập các page hợp lệ,
**để** có thể chọn page Facebook làm kênh đăng bài và quản lý nội dung tập trung.

---

## 2. Mục tiêu

Cung cấp flow kết nối Facebook OAuth an toàn và trực quan: cho phép người dùng uỷ quyền tài khoản Facebook, chọn page kinh doanh, liên kết page với brand, và theo dõi trạng thái kết nối. Feature này giúp người dùng thiết lập kênh social để thực hiện publish content.

---

## 3. Phạm vi

### Trong phạm vi

- Hiển thị danh sách tài khoản Facebook đã kết nối (`/api/social/accounts/me`).
- Kết nối tài khoản Facebook mới qua OAuth flow:
  - Lấy OAuth URL từ BE (`GET /api/social-auth/facebook`).
  - Mở popup Facebook Login.
  - Xử lý callback qua route redirect hoặc manual code input (`POST /api/social-auth/facebook/callback`).
- Xem danh sách Facebook pages có sẵn của tài khoản đã kết nối (`GET /api/social/accounts/{id}/available-targets`).
- Chọn page và liên kết với brand (`POST /api/social/accounts/{id}/link-targets`).
- Xem danh sách page đã liên kết (`GET /api/social/accounts/{id}/linked-targets`).
- Xem integrations theo brand (`GET /api/social/integrations/brand/{brandId}`).
- Ngắt kết nối tài khoản (`DELETE /api/social/accounts/{id}`) — soft delete.
- Ngắt liên kết page/integration (`DELETE /api/social/integrations/{id}`) — soft delete.
- Hiển thị trạng thái kết nối: active, token expired, revoked, error.
- Reconnect khi token hết hạn (mở lại OAuth flow cho cùng account).

### Ngoài phạm vi

- Kết nối Instagram, TikTok, Twitter: sẽ triển khai sau MVP.
- Facebook Ads nâng cao (campaign, ad set, ad creative): post-MVP.
- Tự động refresh token khi sắp hết hạn: BE xử lý qua `TryRefreshPageTokenAsync`; FE chỉ hiển thị cảnh báo.
- Quản lý nhiều page cùng lúc với bulk operations.
- Real-time sync page Insights/analytics.
- Xoá cứng social account/integration (chi soft-delete).

---

## 4. Actor

- **Chính:** Người dùng đã đăng nhập, có profile đang active, có ít nhất một brand để liên kết page.
- **Phụ:** User Web App (frontend), Backend API (SocialAuthController, SocialAccountController, SocialIntegrationController, SocialService, FacebookProvider), Facebook Graph API, PostgreSQL.

---

## 5. Tiền điều kiện

- Người dùng đã đăng nhập và có JWT access token hợp lệ.
- Người dùng đã chọn active profile (`X-Profile-Id` header hợp lệ).
- Người dùng có ít nhất một brand để liên kết page (tạo từ US-04/US-05).
- Backend được cấu hình `FacebookSettings` (`AppId`, `AppSecret`, `RedirectUri`).
- Facebook App đã được cấu hình trên Meta Developer với redirect URI khớp.

---

## 6. Luồng nghiệp vụ chính

### 6.1 Kết nối Facebook account mới (OAuth flow)

1. Người dùng vào màn hình Social Connections (`/social`).
2. Màn hình hiển thị danh sách tài khoản đã kết nối (nếu có) và nút **"Connect Facebook"**.
3. Người dùng nhấn **"Connect Facebook"**.
4. Frontend gọi `GET /api/social-auth/facebook` → nhận `authUrl` và `state`.
5. Frontend mở popup (window.open) với `authUrl` hoặc redirect toàn trang.
6. Người dùng đăng nhập Facebook và cấp quyền trong popup.
7. Facebook redirect về `redirectUri` với `code` và `state` params.
   - Nếu dùng popup: redirect URI là một page FE route `/social/callback` tự động detect params và đóng popup, gửi `code` + `state` về opener window.
   - Nếu dùng redirect: FE nhận `code` + `state` trên URL và tự xử lý.
8. Frontend gọi `POST /api/social-auth/facebook/callback` với `{ code, state }`.
9. Backend:
   - Validate state khớp với `profileId` đã lưu trong `IMemoryCache`.
   - Exchange `code` lấy user access token từ Facebook Graph.
   - Lấy Facebook user profile (id, name).
   - Lưu hoặc cập nhật `SocialAccount` record (token được mã hoá bằng ASP.NET Core Data Protection).
10. Frontend nhận response `SocialAccountDto` → thêm account vào danh sách.
11. Toast "Kết nối Facebook thành công."

### 6.2 Xem danh sách Facebook page có sẵn và liên kết với brand

1. Trên account card, người dùng nhấn **"Manage Pages"**.
2. Frontend gọi `GET /api/social/accounts/{accountId}/available-targets` → danh sách page.
3. Hiển thị danh sách pages checkbox.
4. Người dùng chọn brand để liên kết và chọn các pages.
5. Nhấn **"Link Selected"**.
6. Frontend gọi `POST /api/social/accounts/{accountId}/link-targets` với:
   ```json
   {
     "provider": "facebook",
     "providerTargetIds": ["page_id_1", "page_id_2"],
     "brandId": "brand-guid"
   }
   ```
7. Backend:
   - Validate brand ownership.
   - Gọi Facebook Graph `/me/accounts` lấy page token cho từng page.
   - Lưu `SocialIntegration` record (page token được mã hoá).
   - Cập nhật account với targets.
8. Frontend cập nhật danh sách page đã liên kết.
9. Toast "Đã liên kết N page với brand {brandName}."

### 6.3 Xem danh sách page đã liên kết

1. Frontend gọi `GET /api/social/accounts/{accountId}/linked-targets` → danh sách `SocialTargetDto`.
2. Mỗi item hiển thị: tên page, brand đã liên kết, trạng thái active, thời gian tạo.
3. Có nút "Unlink" cho từng page (gọi `DELETE /api/social/integrations/{id}`).

### 6.4 Ngắt kết nối toàn bộ account

1. Người dùng nhấn **"Disconnect"** trên account card.
2. Dialog xác nhận: "Ngắt kết nối tài khoản Facebook {name}?" + "Tất cả page liên kết cũng sẽ bị ngắt." + [Cancel] [Disconnect].
3. Xác nhận → gọi `DELETE /api/social/accounts/{accountId}`.
4. Backend soft-delete account + tất cả integrations.
5. Xoá account khỏi danh sách FE.
6. Toast "Đã ngắt kết nối tài khoản Facebook."

### 6.5 Ngắt liên kết page (integration)

1. Người dùng nhấn **"Unlink"** trên page item.
2. Dialog xác nhận: "Ngắt liên kết page {pageName} khỏi brand {brandName}?" + [Cancel] [Unlink].
3. Xác nhận → gọi `DELETE /api/social/integrations/{integrationId}`.
4. Xoá page khỏi danh sách.
5. Toast "Đã ngắt liên kết page."

### 6.6 Xem integrations theo brand

1. Trong màn hình Brand Detail hoặc khi chọn brand để publish, FE gọi `GET /api/social/integrations/brand/{brandId}`.
2. Hiển thị danh sách page Facebook đã liên kết với brand đó.

## 7. Luồng ngoại lệ

| Mã | Trường hợp | Kết quả mong đợi |
| --- | --- | --- |
| EX-01 | Facebook chưa được cấu hình trên BE | Backend trả `503 Service Unavailable` "Facebook integration is not configured."; FE hiển thị thông báo cấu hình. |
| EX-02 | Người dùng từ chối quyền Facebook | Popup đóng, không có callback; FE không đổi gì. |
| EX-03 | OAuth `state` không hợp lệ hoặc hết hạn | Backend trả lỗi "OAuth state is invalid or expired."; FE toast lỗi + cho phép thử lại. |
| EX-04 | Facebook token hết hạn | Khi gọi `available-targets` hoặc `link-targets` → BE có thể báo lỗi token; FE hiển thị trạng thái "Token expired" + nút "Reconnect". |
| EX-05 | Không có page Facebook nào | `available-targets` trả mảng rỗng; FE hiển thị "No Facebook pages found" + hướng dẫn tạo page. |
| EX-06 | Brand không tồn tại hoặc không thuộc profile | Backend trả `404`; FE toast lỗi. |
| EX-07 | Chọn page không khả dụng | Backend validate page thuộc danh sách available, nếu không → lỗi "Selected target is not available." |
| EX-08 | Lỗi mạng khi gọi Facebook API | Backend trả lỗi từ FacebookProvider; FE toast "Không thể kết nối Facebook. Vui lòng thử lại." |
| EX-09 | Người dùng nhấn "Connect" nhiều lần | Frontend disable nút trong lúc OAuth flow đang chạy. |

---

## 8. Quy tắc nghiệp vụ

| Mã | Quy tắc |
| --- | --- |
| BR-01 | Mỗi profile có thể kết nối nhiều Facebook account (nhiều user Facebook). |
| BR-02 | Mỗi Facebook account có thể chứa nhiều page. |
| BR-03 | Mỗi page chỉ có thể liên kết với một `SocialIntegration` record duy nhất (unique theo `socialAccountId` + `externalId`). |
| BR-04 | Một page có thể được liên kết với brand A, nhưng không thể đồng thời liên kết với brand B qua cùng account. |
| BR-05 | Page token được refresh khi publish gặp lỗi token — nếu refresh thành công, token mới được mã hoá và persist. |
| BR-06 | Unlink account = soft delete account + tất cả integrations của account đó. |
| BR-07 | Unlink integration = soft delete integration; post history vẫn giữ. |
| BR-08 | `X-Profile-Id` phải thuộc user đang đăng nhập (do `ActiveProfileMiddleware` validate). |
| BR-09 | OAuth `state` chỉ dùng được một lần (consume) và có TTL (mặc định 5 phút từ BE). |

## 9. API Contracts

### 9.1 Get Facebook Auth URL

```
GET /api/social-auth/facebook
```

#### Headers
```http
Authorization: Bearer <access-token>
X-Profile-Id: <owned-profile-guid>
```

#### Response (200 OK)
```json
{
  "success": true,
  "statusCode": 200,
  "message": null,
  "data": {
    "authUrl": "https://www.facebook.com/v19.0/dialog/oauth?client_id=...",
    "state": "generated-state-guid"
  },
  "timestamp": "2026-06-03T12:00:00Z"
}
```

#### Response (503 Service Unavailable)
```json
{
  "success": false,
  "statusCode": 503,
  "message": "Facebook integration is not configured.",
  "data": null,
  "timestamp": "2026-06-03T12:00:00Z"
}
```

## 12. Acceptance Criteria

### AC-01 - Xem danh sách tài khoản đã kết nối

**Given** người dùng vào màn hình Social Connections
**When** màn hình load
**Then** gọi `GET /api/social/accounts/me`
**And** hiển thị danh sách account card với provider icon, status, pages.

### AC-02 - Kết nối Facebook account mới

**Given** chưa có account Facebook nào
**When** nhấn "Connect Facebook"
**Then** gọi `GET /api/social-auth/facebook` → nhận authUrl
**And** mở popup Facebook Login
**When** user cấp quyền và callback thành công
**Then** gọi `POST /api/social-auth/facebook/callback`
**And** account mới xuất hiện trong danh sách.

### AC-03 - Xem danh sách page có sẵn

**Given** đã có account Facebook đã kết nối
**When** nhấn "Manage Pages"
**Then** mở dialog
**And** gọi `GET /api/social/accounts/{id}/available-targets`
**And** hiển thị danh sách page checkbox + brand selector.

### AC-04 - Liên kết page với brand

**Given** dialog Manage Pages đang mở
**When** chọn page + brand → nhấn "Link Selected"
**Then** gọi `POST /api/social/accounts/{id}/link-targets`
**And** page xuất hiện trong linked targets list
**And** toast success.

### AC-05 - Ngắt kết nối tài khoản

**Given** đã có account Facebook
**When** nhấn "Disconnect" → xác nhận
**Then** gọi `DELETE /api/social/accounts/{id}`
**And** account biến mất khỏi danh sách.

### AC-06 - Ngắt liên kết page

**Given** đã có page đã liên kết
**When** nhấn "Unlink" → xác nhận
**Then** gọi `DELETE /api/social/integrations/{id}`
**And** page biến mất khỏi linked list.

### AC-07 - Trạng thái token expired

**Given** account có token hết hạn
**When** hiển thị account card
**Then** hiển thị "Token expired" warning + nút "Reconnect".

### AC-08 - Reconnect account

**Given** account đang ở trạng thái expired
**When** nhấn "Reconnect"
**Then** mở OAuth flow mới
**When** callback thành công
**Then** account được cập nhật token mới, trạng thái trở về active.

### AC-09 - Xem integrations theo brand

**useSocialOAuth:**

```typescript
// hooks/use-social-oauth.ts
import { useState, useCallback } from "react";
import { useMutation, useQueryClient } from "@tanstack/react-query";
import { socialApi } from "@/features/social/api/social-api";
import { useToastStore } from "@/stores/toast-store";

export function useSocialOAuth() {
  const queryClient = useQueryClient();
  const toast = useToastStore((s) => s.push);
  const [isConnecting, setIsConnecting] = useState(false);

  const callbackMutation = useMutation({
    mutationFn: ({ code, state }: { code: string; state: string }) =>
      socialApi.handleCallback(code, state),
    onSuccess: () => {
      void queryClient.invalidateQueries({ queryKey: ["social-accounts"] });
      toast({ title: "Kết nối Facebook thành công.", tone: "success" });
    },
    onError: (err: Error) => {
      toast({ title: err.message || "Không thể kết nối Facebook.", tone: "error" });
    },
  });

  const startOAuth = useCallback(async () => {
    setIsConnecting(true);
    try {
      const { authUrl, state } = await socialApi.getAuthUrl();
      // Lưu state để verify sau callback
      sessionStorage.setItem("oauth_state", state);
      // Mở popup
      const popup = window.open(authUrl, "facebook-oauth", "width=600,height=700");
      if (!popup) {
        toast({ title: "Popup bị chặn. Vui lòng cho phép popup.", tone: "error" });
        setIsConnecting(false);
        return;
      }
      // Poll popup để detect khi đóng / callback
      const timer = setInterval(() => {
        if (popup.closed) {
          clearInterval(timer);
          setIsConnecting(false);
        }
      }, 500);
    } catch {
      toast({ title: "Không thể kết nối Facebook.", tone: "error" });
      setIsConnecting(false);
    }
  }, [toast]);

  return {
    isConnecting,
    isProcessing: callbackMutation.isPending,
    startOAuth,
    processCallback: callbackMutation.mutate,
  };
}
```

#### OAuth Callback Page (`/social/callback/page.tsx`)

```tsx
"use client";

import { useEffect } from "react";
import { useRouter, useSearchParams } from "next/navigation";
import { useSocialOAuth } from "@/features/social/hooks/use-social-oauth";

export default function SocialCallbackPage() {
  const router = useRouter();
  const searchParams = useSearchParams();
  const { processCallback } = useSocialOAuth();
  const code = searchParams.get("code");
  const state = searchParams.get("state");
  const savedState = typeof window !== "undefined" ? sessionStorage.getItem("oauth_state") : null;

  useEffect(() => {
    if (code && state && state === savedState) {
      processCallback({ code, state });
      // Close popup or redirect
      if (window.opener) {
        window.close();
      } else {
        router.push("/social");
      }
    } else {
      router.push("/social");
    }
  }, [code, state, savedState, processCallback, router]);

  return <div className="flex items-center justify-center p-10">Processing Facebook connection...</div>;
}
```
