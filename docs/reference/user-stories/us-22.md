# US-22 - Sinh draft nội dung bằng AI

## 1. User Story

**Là** người dùng doanh nghiệp,
**tôi muốn** AI sinh draft text dựa trên brand, product và prompt tôi cung cấp,
**để** rút ngắn thời gian viết nội dung quảng cáo và đảm bảo thông điệp nhất quán với thương hiệu.

---

## 2. Mục tiêu

Cho phép người dùng chọn brand, product (tuỳ chọn) làm ngữ cảnh đầu vào, sau đó cung cấp prompt hoặc yêu cầu để AI (Gemini) sinh nội dung text. Người dùng có thể xem kết quả generation, cải tiến lại (improve), chat refinement, hoặc approve generation để lưu vào content draft. Tất cả generation đều được lưu lịch sử để người dùng xem lại.

---

## 3. Phạm vi

### Trong phạm vi

- Form nhập liệu để chọn brand, product (tuỳ chọn), loại nội dung (AdType), title, và prompt.
- Gọi API `POST /api/ai/generate-draft` để sinh nội dung mới.
- Gọi API `POST /api/ai/improve/{contentId}` để cải tiến nội dung đã có với prompt mới.
- Gọi API `POST /api/ai/approve/{aiGenerationId}` để áp dụng kết quả generation vào content (lấy `GeneratedText` làm `TextContent` mới của content).
- Gọi API `GET /api/ai/generations/{contentId}` để xem danh sách các generation đã tạo cho một content.
- Gọi API `POST /api/ai/chat` để chat refinement với AI (theo conversation context).
- Hiển thị trạng thái generation: `Pending`, `Completed`, `Failed`.
- Lưu lịch sử generation để người dùng có thể browse và quay lại.
- Hiển thị loading state, disable button khi đang xử lý.
- Toast thông báo thành công / lỗi.

### Ngoài phạm vi

- AI Image generation (`AdType = ImageText`): backend chưa tích hợp flow image, chỉ dùng text.
- AI Video generation (`AdType = VideoText`): tương tự, chưa hỗ trợ MVP.
- Dynamic selection target platform (Facebook/Instagram): chưa có param trong API hiện tại.
- Campaign objective (awareness/engagement/conversion): chưa có param.
- Tone of voice và representative character toggle: chưa có param riêng, có thể đưa vào prompt.
- Async generation queue (polling status): generation đồng bộ ngay trong request.
- Upload file ảnh/video kèm generation.
- Fine-tune hoặc huấn luyện model riêng.

---

## 4. Actor

- **Chính:** Người dùng đã đăng nhập, có profile đang active, có brand và product.
- **Phụ:** User Web App (frontend), Backend API (GeminiController/AIService), Gemini AI provider, PostgreSQL.

---

## 5. Tiền điều kiện

- Người dùng đã đăng nhập và có JWT access token hợp lệ.
- Người dùng đã chọn active profile (`X-Profile-Id` header hợp lệ).
- Có ít nhất một brand thuộc profile và brand đó chưa bị soft-delete.
- `GeminiSettings` (API key) đã được cấu hình trên backend. Nếu thiếu, API trả lỗi graceful (không crash server).
- Backend API và PostgreSQL đang hoạt động.

## 6. Luồng nghiệp vụ chính

### 6.1 Generate draft mới từ AI

1. Người dùng truy cập màn hình AI Content Generation (`/ai`).
2. Hệ thống hiển thị form gồm các trường:
   - **Brand** (dropdown, bắt buộc) - danh sách brand thuộc profile active.
   - **Product** (dropdown, tuỳ chọn) - danh sách product thuộc brand đã chọn.
   - **Ad Type** (dropdown, mặc định `TextOnly`) - `TextOnly`, `ImageText`, `VideoText`.
   - **Title** (text input, tuỳ chọn) - tiêu đề cho content draft.
   - **Prompt** (textarea, bắt buộc) - mô tả nội dung quảng cáo mong muốn.
3. Người dùng điền đầy đủ và nhấn **"Generate"**.
4. Frontend gọi `POST /api/ai/generate-draft` với `CreateDraftRequest` body.
5. Backend validate brand/product ownership, check prompt quota.
6. Backend tạo content `Draft` mới, gọi Gemini API sinh text.
7. Backend lưu `AiGeneration` record với status `Completed` hoặc `Failed`.
8. Frontend nhận response `AiGenerationResponse`, hiển thị kết quả:
   - Generation thành công: hiển thị `GeneratedText`, trạng thái `Completed`.
   - Generation thất bại: hiển thị `ErrorMessage`, trạng thái `Failed`.
9. Người dùng có thể:
   - **Approve** generation để lưu text vào content (gọi `POST /api/ai/approve/{aiGenerationId}`).
   - **Generate lại** với prompt khác.
   - **Improve** content hiện tại với prompt mới.
   - **Chat** với AI để refinement.
   - Xem lịch sử các generation của content này.

### 6.2 Improve nội dung đã có

1. Người dùng ở màn hình chi tiết content hoặc màn hình AI generation.
2. Người dùng nhập prompt cải tiến và nhấn **"Improve"**.
3. Frontend gọi `POST /api/ai/improve/{contentId}` với `ImproveContentRequest`.
4. Backend validate content ownership, gọi Gemini sinh nội dung mới dựa trên content hiện tại + prompt.
5. Kết quả generation trả về tương tự luồng generate-draft.

### 6.3 Approve generation

1. Người dùng xem kết quả generation thành công.
2. Người dùng nhấn **"Approve"** để áp dụng `GeneratedText` vào content.
3. Frontend gọi `POST /api/ai/approve/{aiGenerationId}`.
4. Backend copy `GeneratedText` vào `Content.TextContent`, giữ nguyên `Status = Draft`.
5. Frontend hiển thị toast thành công, cập nhật nội dung content.

### 6.4 Chat với AI

1. Người dùng có thể chat với AI trong cùng context (brand, product, ad type).
2. Frontend hiển thị chat interface với lịch sử tin nhắn (user + AI).
3. Tin nhắn mới gọi `POST /api/ai/chat` với `ChatRequest`.
4. Backend tự động tìm hoặc tạo `Conversation`, lưu tin nhắn, gọi Gemini và trả response.
5. Frontend append tin nhắn AI vào chat history.

### 6.5 Xem lịch sử generation

1. Người dùng ở trang chi tiết content hoặc panel AI.
2. Frontend gọi `GET /api/ai/generations/{contentId}`.
3. Hiển thị danh sách generation theo thời gian (mới nhất trước).
4. Mỗi item hiển thị: prompt, trạng thái, `GeneratedText` (nếu Completed), `ErrorMessage` (nếu Failed), thời gian tạo.
5. Cho phép Approve generation từ danh sách này (nếu generation đang `Completed`).

## 7. Luồng ngoại lệ

| Mã | Trường hợp | Kết quả mong đợi |
| --- | --- | --- |
| EX-01 | Brand không tồn tại hoặc không thuộc profile | Backend trả `404 Not Found`; frontend hiển thị lỗi và không gửi request. |
| EX-02 | Product không thuộc brand đã chọn | Backend trả `400 Bad Request`; frontend hiển thị lỗi validation. |
| EX-03 | Quota prompt đã hết | Backend trả `403 Forbidden` với `errorCode = PROMPT_QUOTA_EXCEEDED`; frontend hiển thị thông báo đã hết quota, gợi ý nâng cấp subscription. |
| EX-04 | Gemini API key chưa cấu hình | Backend trả `503 Service Unavailable`; frontend hiển thị thông báo "AI service is not configured" và disable các nút AI. |
| EX-05 | Gemini API trả lỗi (network, quota, timeout) | Backend bắt exception, lưu `AiGeneration.Status = Failed` với `ErrorMessage`; frontend hiển thị trạng thái failed và error message. |
| EX-06 | Content không tồn tại khi improve | Backend trả `404 Not Found`; frontend hiển thị lỗi. |
| EX-07 | Generation không tồn tại khi approve | Backend trả `404 Not Found`; frontend hiển thị lỗi. |
| EX-08 | Generation chưa hoàn thành (Pending/Failed) khi approve | Backend trả `400 Bad Request`; frontend disable nút Approve nếu generation không phải Completed. |
| EX-09 | Conversation không tồn tại khi chat | Backend trả `404 Not Found`; frontend hiển thị lỗi. |
| EX-10 | JWT hết hạn hoặc không hợp lệ | Backend trả `401 Unauthorized`; frontend tự động refresh token hoặc chuyển hướng đăng nhập. |
| EX-11 | X-Profile-Id thiếu hoặc không thuộc user | Backend trả `400 Bad Request` / `403 Forbidden`; frontend hiển thị lỗi. |
| EX-12 | Người dùng nhấn Generate/Improve/Chat nhiều lần | Frontend disable nút sau lần nhấn đầu tiên đến khi có phản hồi. |
| EX-13 | Prompt quá ngắn hoặc chỉ gồm khoảng trắng | Frontend validate prompt không được rỗng trước khi gửi; nếu backend trả lỗi validation, hiển thị dưới field prompt. |

## 8. Quy tắc nghiệp vụ

| Mã | Quy tắc |
| --- | --- |
| BR-01 | `ProfileId` được lấy từ `X-Profile-Id` header đã được middleware validate, không lấy từ request body. |
| BR-02 | `BrandId` là bắt buộc và phải thuộc profile đang active. |
| BR-03 | `ProductId` nếu có phải thuộc brand đã chọn (`Product.BrandId == BrandId`), nếu không gửi thì bỏ qua. |
| BR-04 | Mỗi lần generate-draft tạo một `Content` mới với `Status = Draft` và một `AiGeneration` liên kết. |
| BR-05 | Improve không tạo content mới, chỉ tạo `AiGeneration` mới gắn với `ContentId` hiện tại. |
| BR-06 | Approve chỉ hoạt động khi `AiGeneration.Status == Completed` và `GeneratedText` không rỗng. |
| BR-07 | Approve sẽ copy `GeneratedText` vào `Content.TextContent`; content vẫn giữ `Status = Draft`. |
| BR-08 | Generation tiêu thụ prompt quota. Backend gọi `QuotaService.EnsurePromptQuotaAsync` trước khi generate. Nếu hết quota, không gọi Gemini. |
| BR-09 | Chat không tiêu thụ prompt quota (không gọi `EnsurePromptQuotaAsync`). |
| BR-10 | Chat tự động tìm `Conversation` đang active theo `(profileId, brandId, productId, adType)` hoặc tạo mới nếu chưa có. |
| BR-11 | Nếu Gemini API key thiếu, backend không crash; generation được lưu với `Status = Failed` và error message thích hợp. Chat cũng trả `503 Service Unavailable`. |
| BR-12 | Thứ tự xem generation history: mới nhất trước (descending by `CreatedAt`). |
| BR-13 | Chat message có `SenderType` phân biệt `User` (0) và `AI` (1). |
| BR-14 | Chat response luôn được lưu vào DB (cả khi Gemini fail, lưu message lỗi). |

## 9. API Contracts

### 9.1 Generate Draft

```
POST /api/ai/generate-draft
```

#### Headers bắt buộc

```http
Authorization: Bearer <access-token>
X-Profile-Id: <owned-profile-guid>
```

#### Request Body

```json
{
  "brandId": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "productId": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "adType": 0,
  "title": "Summer campaign draft",
  "prompt": "Create a short Facebook ad caption promoting our summer sale"
}
```

#### Tham số

| Field | Kiểu | Bắt buộc | Mô tả |
| --- | --- | --- | --- |
| `brandId` | `Guid` | Có | Brand ID làm context cho AI. |
| `productId` | `Guid?` | Không | Product ID (tùy chọn). |
| `adType` | `int` | Có | Loại nội dung: 0=TextOnly, 1=ImageText, 2=VideoText. |
| `title` | `string?` | Không | Tiêu đề content draft. |
| `prompt` | `string` | Có | Prompt/hướng dẫn cho AI sinh nội dung. |

#### Response thành công (`200 OK`)

```json
{
  "success": true,
  "statusCode": 200,
  "message": "AI generation processed.",
  "data": {
    "aiGenerationId": "gen-uuid",
    "contentId": "content-uuid",
    "generatedText": "🔥 Summer is here! Check out our amazing sale at [Brand Name]. Don't miss out on...",
    "status": 1,
    "errorMessage": null,
    "createdAt": "2026-06-03T06:30:00Z"
  }
}
```

### 9.2 Improve Content

```
POST /api/ai/improve/{contentId}
```

#### Headers

```http
Authorization: Bearer <access-token>
X-Profile-Id: <owned-profile-guid>
```

#### Request Body

```json
{
  "prompt": "Make the caption shorter and more playful"
}
```

#### Response (`200 OK`)

Cùng kiểu `AiGenerationResponse` như generate-draft.

#### Response thành công (`200 OK`)

{
  "success": true,
  "statusCode": 200,
  "message": "AI generation approved.",
  "data": {
    "id": "content-uuid",
    "profileId": "profile-uuid",
    "brandId": "brand-uuid",
    "brandName": "Brand Name",
    "productId": null,
    "adType": 0,
    "title": "Summer campaign draft",
    "textContent": "🔥 Summer is here! Check out our amazing sale...",
    "imageUrl": null,
    "videoUrl": null,
    "styleDescription": null,

    "representativeCharacter": null,

### 9.5 Chat

```
POST /api/ai/chat
```

#### Request Body

```json
{
  "brandId": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "productId": null,
  "adType": 0,
  "message": "Make it more urgent with a countdown feeling",
  "conversationId": null
}
```

| Field | Kiểu | Bắt buộc | Mô tả |
| --- | --- | --- | --- |
| `brandId` | `Guid?` | Không (có nếu productId có) | Brand context cho chat. |
| `productId` | `Guid?` | Không | Product context. |
| `adType` | `int` | Có | Ad type context. |
| `message` | `string` | Có | Tin nhắn người dùng. |
| `conversationId` | `Guid?` | Không | ID conversation đang có để tiếp tục; nếu null, backend tự tìm/tạo. |

#### Response thành công (`200 OK`)

```json
{
  "success": true,
  "statusCode": 200,
  "message": null,
  "data": {
    "conversationId": "conv-uuid",
    "response": "Sure! Here's a more urgent version: ⏰ Only 24 hours left! Grab our summer sale..."
  }
}
```

### 9.6 Response Error Codes

| HTTP Status | errorCode | Trường hợp |
| --- | --- | --- |
| `401 Unauthorized` | — | JWT thiếu hoặc không hợp lệ. |
| `400 Bad Request` | — | `X-Profile-Id` thiếu, sai format, hoặc validation lỗi (vd: product không thuộc brand). |
| `403 Forbidden` | — | Profile không thuộc user đang đăng nhập. |
| `403 Forbidden` | `PROMPT_QUOTA_EXCEEDED` | Đã hết prompt quota. |
| `404 Not Found` | — | Brand/Product/Content/Generation/Conversation không tồn tại hoặc không thuộc profile. |
| `503 Service Unavailable` | — | Gemini API key chưa cấu hình hoặc AI service tạm thời không khả dụng. |
| `500 Internal Server Error` | — | Lỗi hệ thống không mong đợi. |

Ví dụ response quota exceeded:

```json
{
  "success": false,
  "statusCode": 403,
  "message": "You have reached your prompt generation limit.",
  "data": null,
  "error": {
    "errorCode": "PROMPT_QUOTA_EXCEEDED",
    "errorMessage": "You have reached your prompt generation limit."
  }
}
```

## 10. Màn hình / UI Components

### 10.1 Màn hình AI Generation (`/ai`)

Layout gồm 2 panel:

**Panel trái - Form nhập liệu:**
- Dropdown **Brand** (bắt buộc) — populate từ API brands của profile active.
- Dropdown **Product** (tuỳ chọn) — populate theo brand đã chọn, có tuỳ chọn "Không chọn product".
- Dropdown **Ad Type** (mặc định `TextOnly`).
- Input **Title** (tuỳ chọn).
- Textarea **Prompt** (bắt buộc), có placeholder gợi ý: *"Ví dụ: Viết caption quảng cáo Facebook cho sản phẩm mới, nhấn mạnh tính năng vượt trội..."*.
- Nút **"Generate"** (primary, disabled khi chưa chọn brand hoặc prompt rỗng).

**Panel phải - Khu vực kết quả:**
- Hiển thị `AiGenerationResponse` sau khi generate:
  - Card generation với: GeneratedText (highlight nếu Completed), status badge (Completed/Failed), error message nếu Failed, timestamp.
  - Nút **"Approve"** (primary) — chỉ enable nếu generation `Completed`.
  - Nút **"Improve"** (outline) — gọi improve flow.
- Tab **Generation History**: danh sách các generation trước đó (gọi `GET /api/ai/generations/{contentId}`), mỗi item có thể approve lại.
- Tab **Chat**: chat interface với AI.

### 10.2 Panel Chat

- Chat bubble hiển thị tin nhắn User (bên phải) và AI (bên trái).
- Input textarea + nút Send.
- Tự động scroll xuống message mới nhất.
- Loading indicator khi chờ AI phản hồi.
- Thông báo khi AI service unavailable.

### 10.3 Trạng thái rỗng / Lần đầu

- Khi chưa có generation nào: hiển thị placeholder "Nhập prompt và nhấn Generate để bắt đầu".
- Nếu chưa có brand nào: hiển thị thông báo hướng dẫn tạo brand trước, kèm link đến màn hình brand.

## 11. Responsive States

| State | UI hiển thị |
| --- | --- |
| **Loading** | Nút Generate/Improve hiển thị spinner, disabled. Skeleton cho kết quả generation. |
| **Success** | Hiển thị GeneratedText, status badge "Completed" (xanh), enable nút Approve/Improve. |
| **Error (Generation failed)** | Status badge "Failed" (đỏ), hiển thị ErrorMessage từ backend, enable nút Generate lại. |
| **Quota exceeded** | Toast/Alert màu vàng/cam: "Bạn đã đạt giới hạn prompt. Vui lòng nâng cấp gói hoặc đợi kỳ mới.", ẩn nút Generate. |
| **AI not configured** | Toast/Alert màu đỏ: "Dịch vụ AI chưa được cấu hình.", disable toàn bộ nút AI. |
| **Empty state** | Placeholder text, hướng dẫn sử dụng. |
| **Network error** | Toast lỗi kết nối, cho phép thử lại. |

## 12. Acceptance Criteria

### AC-01 - Generate draft thành công với brand và prompt

**Given** người dùng đã chọn brand hợp lệ, nhập prompt
**When** người dùng nhấn Generate
**Then** frontend gọi `POST /api/ai/generate-draft`
**And** hiển thị kết quả generation (Completed/Failed) trong panel kết quả
**And** nếu Completed, hiển thị `GeneratedText` và nút Approve.

### AC-02 - Product là tuỳ chọn

**Given** form generation
**When** người dùng không chọn product
**Then** request gửi `productId = null`
**And** backend vẫn xử lý bình thường.

### AC-03 - Approve generation thành công

**Given** generation đã hoàn thành (Completed)
**When** người dùng nhấn Approve
**Then** `POST /api/ai/approve/{aiGenerationId}` được gọi
**And** frontend hiển thị toast "Approved" và cập nhật nội dung content.

### AC-04 - Improve content hiện tại

**Given** nội dung content đã tồn tại
**When** người dùng nhập prompt cải tiến và nhấn Improve
**Then** `POST /api/ai/improve/{contentId}` được gọi
**And** kết quả hiển thị tương tự luồng generate-draft.

### AC-05 - Xem lịch sử generation

**Given** content đã có ít nhất một generation
**When** người dùng mở tab Generation History
**Then** `GET /api/ai/generations/{contentId}` được gọi
**And** danh sách generation hiển thị theo thứ tự mới nhất trước.

### AC-06 - Chat với AI

**Given** người dùng ở tab Chat
**When** người dùng gửi tin nhắn
**Then** `POST /api/ai/chat` được gọi
**And** response AI hiển thị trong chat bubble.

### AC-07 - Quota exceeded

**Given** prompt quota đã hết
**When** người dùng nhấn Generate
**Then** backend trả `403 PROMPT_QUOTA_EXCEEDED`
**And** frontend hiển thị thông báo quota exceeded
**And** nút Generate bị disable.

### AC-08 - Generation thất bại

**Given** Gemini API trả lỗi
**When** generate/improve
**Then** `AiGeneration.Status = Failed`, `ErrorMessage` có nội dung
**And** frontend hiển thị trạng thái Failed kèm error message.

### AC-09 - Frontend validate prompt không rỗng

**Given** người dùng chưa nhập prompt
**When** người dùng nhấn Generate
**Then** frontend hiển thị validation lỗi dưới field prompt
**And** không gọi API.

### AC-10 - Disable nút trong lúc xử lý

**Given** người dùng đã nhấn Generate/Improve/Send chat
**When** API đang xử lý
**Then** nút bị disable và hiển thị loading indicator
**And** không gửi request thứ hai.

### AC-11 - Approve chỉ khả dụng cho generation Completed

**Given** generation có `Status = Pending` hoặc `Failed`
**When** hiển thị panel kết quả
**Then** nút Approve disabled hoặc ẩn.

      body: JSON.stringify(payload),
      auth: true,
    }),

  approve: (aiGenerationId: string) =>
    apiRequest<ContentResponseDto>(`/api/ai/approve/${aiGenerationId}`, {
      method: "POST",
      auth: true,
    }),

  getGenerations: (contentId: string) =>
    apiRequest<AiGenerationResponse[]>(`/api/ai/generations/${contentId}`, {
      method: "GET",
      auth: true,
    }),

  chat: (payload: ChatInput) =>
    apiRequest<ChatResponse>("/api/ai/chat", {
      method: "POST",
      body: JSON.stringify(payload),
      auth: true,
    }),

#### Profile ID header

## 17. UI/UX Guidelines

- **Form layout:** Sử dụng grid 2 cột cho desktop (form trái, kết quả phải). Trên mobile, form và kết quả xếp dọc.

- **Quota error:** Sử dụng alert màu vàng/cam với icon warning, link đến trang subscription.
