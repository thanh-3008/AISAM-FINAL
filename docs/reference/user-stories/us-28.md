# US-28 - Xoá hội thoại AI

## 1. User Story

**Là** người dùng,
**tôi muốn** xoá conversation không cần thiết để giữ lịch sử làm việc gọn gàng,
**để** chỉ còn lại những cuộc trò chuyện hữu ích, dễ tìm kiếm và quản lý.

---

## 2. Mục tiêu

Cung cấp các công cụ xoá conversation linh hoạt: xoá từng conversation, xoá hàng loạt, và quản lý các conversation đã xoá. Feature này giúp người dùng dọn dẹp lịch sử hội thoại một cách an toàn (có xác nhận, có undo toast) và hiệu quả (batch operations).

---

## 3. Phạm vi

### Trong phạm vi

- Xoá một conversation (single delete) từ:
  - US-26 chat sidebar (icon delete khi hover).
  - US-27 history page (nút Delete trên card và detail).
- Batch delete: chọn nhiều conversations và xoá cùng lúc.
- Chế độ "Manage" / "Select mode" trên US-27 history page: checkbox chọn hàng loạt, toolbar với nút "Delete Selected (N)".
- Dialog xác nhận trước khi xoá:
  - Single: "Xoá cuộc trò chuyện này?" + hiển thị title.
  - Batch: "Xoá N cuộc trò chuyện?" + danh sách title (tối đa 5, còn lại "...và N cuộc khác").
  - Cảnh báo: "Hành động này không thể hoàn tác" (vì BE soft-delete, nhưng UI không support undo).
- Toast thông báo sau khi xoá:
  - Single: "Đã xoá cuộc trò chuyện." + nút "Undo" (nếu cần).
  - Batch: "Đã xoá N cuộc trò chuyện." + nút "Undo" (nếu cần).
- Gọi API `DELETE /api/conversations/{id}` cho mỗi conversation.
- Batch delete: gọi nhiều `DELETE` requests song song hoặc nối tiếp.
- Loading state trên nút Delete trong lúc xoá.
- Disable các nút action trong lúc xoá.

### Ngoài phạm vi

- Restore/undo conversation sau khi xoá: BE soft-delete, không có restore endpoint.
- Empty trash / permanent delete: BE không hỗ trợ hard delete.
- Xoá hàng loạt bằng một API call duy nhất: cần BE hỗ trợ `POST /api/conversations/batch-delete` (hiện tại chỉ có single delete).
- Recover conversation từ trash.
- Auto-delete conversation sau thời gian nhất định.

## 9. API Contracts

### 9.1 Delete Conversation

```
DELETE /api/conversations/{id}
```

#### Headers

```http
Authorization: Bearer <access-token>
X-Profile-Id: <owned-profile-guid>
```

#### Path Parameters

| Tham số | Kiểu | Bắt buộc | Mô tả |
| --- | --- | --- | --- |
| `id` | `Guid` | Có | ID của conversation cần xoá. |

#### Response thành công (`200 OK`)

```json
{
  "success": true,
  "statusCode": 200,
  "message": "Conversation deleted successfully.",
  "data": true
}
```

#### Response lỗi

| HTTP Status | errorCode | Trường hợp |
| --- | --- | --- |
| `401 Unauthorized` | — | JWT thiếu hoặc không hợp lệ. |
| `400 Bad Request` | — | `X-Profile-Id` thiếu hoặc sai format. |
| `403 Forbidden` | — | Profile không thuộc user đang đăng nhập. |
| `404 Not Found` | — | Conversation không tồn tại, đã bị xóa, hoặc không thuộc profile. |
| `500 Internal Server Error` | — | Lỗi hệ thống không mong đợi. |

### 9.2 Batch Delete (Frontend pattern — gọi nhiều single API)

Không có BE endpoint riêng cho batch delete. Frontend implement:

```typescript
async function batchDeleteConversations(ids: string[]): Promise<BatchDeleteResult> {
  const results = await Promise.allSettled(
    ids.map((id) => conversationApi.delete(id))
  );

  const succeeded: string[] = [];
  const failed: { id: string; error: string }[] = [];

  results.forEach((result, index) => {
    if (result.status === "fulfilled" && result.value.success) {
      succeeded.push(ids[index]);
    } else {
      failed.push({
        id: ids[index],
        error: result.status === "fulfilled"
          ? result.value.message ?? "Unknown error"
          : "Network error",
      });
    }
  });

  return { succeeded, failed };
}
```

**useDeleteConversation (single delete):**

```typescript
// hooks/use-delete-conversation.ts
function useDeleteConversation() {
  const [isDeleting, setIsDeleting] = useState(false);
  const [confirmDialog, setConfirmDialog] = useState<{
    id: string;
    title: string;
  } | null>(null);

  const requestDelete = (id: string, title: string) => {
    setConfirmDialog({ id, title });
  };

  const executeDelete = async (id: string): Promise<boolean> => {
    setIsDeleting(true);
    try {
      const result = await conversationApi.delete(id);
      if (result.success) {
        toast.success("Đã xoá cuộc trò chuyện.");
        return true;
      } else {
        toast.error(result.message ?? "Không thể xoá.");
        return false;
      }
    } catch {
      toast.error("Không thể xoá. Vui lòng thử lại.");
      return false;
    } finally {
      setIsDeleting(false);
      setConfirmDialog(null);
    }
  };

  return { isDeleting, confirmDialog, requestDelete, executeDelete, setConfirmDialog };
}
```

  } | null>(null);

  const requestBatchDelete = (ids: string[], titles: string[]) => {
    setConfirmDialog({ ids, titles });
  };

  const executeBatchDelete = async (ids: string[]): Promise<BatchDeleteResult> => {
    setIsDeleting(true);
    const results = await Promise.allSettled(
      ids.map((id) => conversationApi.delete(id))
    );

    const succeeded: string[] = [];
    const failed: { id: string; error: string }[] = [];

    results.forEach((result, index) => {
      if (result.status === "fulfilled" && result.value.success) {
        succeeded.push(ids[index]);
      } else {
        failed.push({
          id: ids[index],
          error: result.status === "fulfilled"
            ? result.value.message ?? "Unknown error"
            : "Network error",
        });
      }
    });

    if (failed.length === 0) {
      toast.success(`Đã xoá ${succeeded.length} cuộc trò chuyện.`);
    } else if (succeeded.length > 0) {
      toast.warning(
        `Đã xoá ${succeeded.length}/${ids.length} cuộc trò chuyện. ` +
        `${failed.length} cuộc không thể xoá.`
      );
    } else {
      toast.error("Không thể xoá cuộc trò chuyện nào.");
    }

    setIsDeleting(false);
    setConfirmDialog(null);
    return { succeeded, failed };
  };

  return {
    isDeleting, confirmDialog,
    requestBatchDelete, executeBatchDelete, setConfirmDialog,
  };
}
```
