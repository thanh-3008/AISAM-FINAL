# US-48 - Xem tổng quan quota theo profile

## 1. User Story

**Là** người dùng,
**tôi muốn** xem tổng quan quota prompt và quota publish còn lại theo profile,
**để** có thể quản lý mức sử dụng AI và bài đăng, tránh bị gián đoạn khi hết quota.

---

## 2. Mục tiêu

Cung cấp tab "Quota" trong trang `/payment` hiển thị trực quan tình trạng sử dụng quota của profile đang active: hai loại quota chính (Prompt AI Content, Post bài đăng) với biểu đồ dạng radial progress, usage rate, dự báo thời điểm hết quota, countdown đến ngày reset, và cảnh báo sớm khi sắp hết. Khác với US-44 (mini quota trong checkout) và US-46 (quota là một phần của subscription detail), US-48 tập trung vào **quản lý sử dụng quota như một công cụ operational** — giúp người dùng chủ động điều tiết việc dùng AI và publish.

---

## 3. Phạm vi

### Trong phạm vi

- Tab "📊 Quota" trong `/payment` (tab thứ 4, bên cạnh "Gói của tôi", "Plans", "History").
- Gọi `GET /api/quota/profile/{profileId}` → `QuotaSummaryDto`.
- **Radial progress chart** cho mỗi loại quota:
  - **Prompt Quota (AI Content)**:
    - Vòng tròn progress fill theo % đã dùng.
    - Ở giữa: số `promptRemaining` / `promptQuotaLimit`.
    - Label: "AI Content / ngày".
    - Màu sắc: xanh (>50%), vàng (20-50%), đỏ (<20%), xám (limit = 0).
  - **Post Quota (Bài đăng)**:
    - Vòng tròn progress fill theo % đã dùng.
    - Ở giữa: số `postRemaining` / `postQuotaLimit`.
    - Label: "Bài đăng / tháng".
    - Màu sắc tương tự.
- **Usage stats grid** (bên dưới radial charts):
  - **Đã dùng**: `promptUsage` / `postUsage`.
  - **Còn lại**: `promptRemaining` / `postRemaining`.
  - **Tổng**: `promptQuotaLimit` / `postQuotaLimit`.
  - **Tỉ lệ**: `usage/limit * 100`%.
- **Usage rate & forecast**:
  - Tính `usageRate = totalUsage / daysSinceWindowStart`.
  - Forecast: `daysUntilExhausted = remaining / usageRate` (nếu usageRate > 0).
  - Hiển thị: "Với tốc độ hiện tại, bạn sẽ hết quota trong X ngày."
  - Nếu chưa có usage: "Chưa có dữ liệu sử dụng."
  - Nếu limit = 0: "Không bao gồm trong gói hiện tại."
- **Countdown đến ngày reset**:
  - Tính số ngày còn lại đến `windowEnd`.
  - "Quota sẽ reset sau X ngày (dd/MM/yyyy)."
- **Quota health score**:
  - Tổng quan: "🟢 Tốt" (cả 2 > 50%), "🟡 Trung bình" (1 trong 2 < 50%), "🔴 Thấp" (1 trong 2 < 20%), "⚫ Hết" (cả 2 = 0).
- **Quota alerts**:
  - Nếu `promptRemaining <= 20%` hoặc `postRemaining <= 20%`:
    - Alert banner: ⚠️ "Sắp hết quota {type}. Còn {X} / {Y}."
    - CTA: "Nâng cấp gói" → chuyển tab Plans.
  - Nếu `promptRemaining = 0` hoặc `postRemaining = 0`:
    - Alert banner: 🔴 "Đã hết quota {type}. Không thể {generate/publish} thêm."
    - CTA: "Nâng cấp gói ngay" → chuyển tab Plans.
- **Quick actions**:
  - Nút "Tạo nội dung AI" → navigate đến `/ai`.
  - Nút "Đăng bài mới" → navigate đến `/content`.
- **No subscription state**: fallback "Bạn chưa có gói active" + CTA chọn gói.
- **Loading skeleton**: 2 radial skeletons + stats grid.
- **Error state**: banner + "Thử lại".

### Ngoài phạm vi

- Quota usage history chart (theo ngày/tuần): deferred (BE không có data).
- Quota consumption log (danh sách AI generations/posts đã dùng quota): deferred.
- So sánh quota giữa các profile: out of scope.
- Export quota report: deferred.
- Custom quota thresholds/alert preferences: deferred.
- Quota cho các resource khác (images, platforms, accounts, ads): deferred (BE chưa expose).

- Có active subscription (nếu không, Quota API trả 404 → fallback state).

## 6. Luồng nghiệp vụ chính

### 6.1 Vào tab Quota

1. Người dùng vào `/payment` → click tab "📊 Quota".
2. Frontend gọi `GET /api/quota/profile/{activeProfileId}`.
3. Nếu có dữ liệu:
   - Hiển thị 2 radial progress charts (prompt + post).
   - Usage stats grid.
   - Usage rate & forecast.
   - Countdown đến ngày reset.
   - Quota health score.
   - Alert banners (nếu sắp hết/đã hết quota).
   - Quick actions.
4. Nếu 404 (không có subscription):
   - Fallback state: "Bạn chưa có gói active" + CTA chọn gói.

### 6.2 Xem forecast

1. Tính `daysSinceWindowStart = (today - windowStart).days`.
2. Tính `promptRate = promptUsage / max(daysSinceWindowStart, 1)`.
3. Tính `postRate = postUsage / max(daysSinceWindowStart, 1)`.
4. Forecast:
   - `promptDaysUntilExhausted = promptRemaining / promptRate` (nếu rate > 0).
   - `postDaysUntilExhausted = postRemaining / postRate` (nếu rate > 0).
5. Hiển thị forecast text.

### 6.3 Click quick action

1. Click "Tạo nội dung AI" → navigate đến `/ai`.
2. Click "Đăng bài mới" → navigate đến `/content`.

### 6.4 Click upgrade CTA

1. Click "Nâng cấp gói" → chuyển tab "Plans" trong `/payment`.

```typescript
// features/payment/types/payment.ts

// Bổ sung helpers
export function calculateQuotaHealth(
  promptRemaining: number,
  promptLimit: number,
  postRemaining: number,
  postLimit: number
): { icon: string; label: string; color: string } {
  const promptPct = promptLimit > 0 ? promptRemaining / promptLimit : 0;
  const postPct = postLimit > 0 ? postRemaining / postLimit : 0;

  if (promptLimit === 0 && postLimit === 0)
    return { icon: "⚫", label: "Hết", color: "#6B7280" };
  if (promptPct === 0 && postPct === 0)
    return { icon: "⚫", label: "Hết", color: "#6B7280" };
  if (promptPct < 0.2 || postPct < 0.2)
    return { icon: "🔴", label: "Thấp", color: "#EF4444" };
  if (promptPct < 0.5 || postPct < 0.5)
    return { icon: "🟡", label: "Trung bình", color: "#F59E0B" };
  return { icon: "🟢", label: "Tốt", color: "#22C55E" };
}

export function calculateForecast(
  usage: number,
  remaining: number,
  windowStart: string,
  windowEnd?: string | null
): string | null {
  if (usage === 0) return null;

  const start = new Date(windowStart);
  const daysSince = Math.max(
    1,
    Math.floor((Date.now() - start.getTime()) / (1000 * 60 * 60 * 24))
  );
  const rate = usage / daysSince;
  if (rate <= 0) return null;

  const daysLeft = Math.ceil(remaining / rate);
  return daysLeft > 0 ? `~${daysLeft} ngày` : "Hôm nay";
}
```

```tsx
// features/payment/components/radial-quota-chart.tsx

function RadialQuotaChart({
  icon,
  label,
  usage,
  limit,
  remaining,
}: {
  icon: string;
  label: string;
  usage: number;
  limit: number;
  remaining: number;
}) {
  const percentage = limit > 0 ? (usage / limit) * 100 : 0;
  const color =
    limit === 0
      ? "#CBD5E1"
      : remaining / Math.max(limit, 1) > 0.5
        ? "#22C55E"
        : remaining / Math.max(limit, 1) > 0.2
          ? "#F59E0B"
          : "#EF4444";

  // SVG radial progress
  const radius = 60;
  const circumference = 2 * Math.PI * radius;
  const offset = circumference - (percentage / 100) * circumference;

  return (
    <div className="flex flex-col items-center rounded-2xl border bg-card p-5">
      <span className="mb-1 text-2xl">{icon}</span>

      <svg width="140" height="140" className="-rotate-90">
        {/* Background circle */}
        <circle
          cx="70" cy="70" r={radius}
          fill="none" stroke="#F1F5F9" strokeWidth="10"
        />
        {/* Progress arc */}
        {limit > 0 && (
          <circle
            cx="70" cy="70" r={radius}
            fill="none" stroke={color} strokeWidth="10"
            strokeDasharray={circumference}
            strokeDashoffset={offset}
            strokeLinecap="round"
            className="transition-all duration-700"
          />
        )}
      </svg>

      {/* Center text */}
      <div className="absolute mt-[-100px] flex flex-col items-center">
        <span className="text-2xl font-bold">{remaining}</span>
        <span className="text-xs text-muted-foreground">/ {limit}</span>
      </div>

      <p className="mt-2 text-sm font-medium">{label}</p>
      <p className="text-xs text-muted-foreground">
        {limit > 0
          ? `${remaining > 0 ? "🟢" : "🔴"} Còn ${remaining}/${limit}`
          : "⚪ Không bao gồm"}
      </p>
    </div>
  );
}
```

```tsx
        />
      </div>

      {/* Usage stats */}
      <UsageStatsGrid
        promptUsage={q.promptUsage}
        promptLimit={q.promptQuotaLimit}
        promptRemaining={q.promptRemaining}
        postUsage={q.postUsage}
        postLimit={q.postQuotaLimit}
        postRemaining={q.postRemaining}
      />

      {/* Forecast & reset */}
      <QuotaForecast
        promptUsage={q.promptUsage}
        promptRemaining={q.promptRemaining}
        postUsage={q.postUsage}
        postRemaining={q.postRemaining}
        windowStart={q.windowStart}
        windowEnd={q.windowEnd}
      />

      {/* Alerts */}
      <QuotaAlerts
        promptRemaining={q.promptRemaining}
        promptLimit={q.promptQuotaLimit}

}
```

```tsx
// features/payment/components/quota-forecast.tsx
import { calculateForecast } from "@/features/payment/types/payment";

function QuotaForecast({
  promptUsage, promptRemaining,
  postUsage, postRemaining,
  windowStart, windowEnd,
}: {
  promptUsage: number; promptRemaining: number;
  postUsage: number; postRemaining: number;
  windowStart: string; windowEnd?: string | null;
}) {
  const promptForecast = calculateForecast(promptUsage, promptRemaining, windowStart, windowEnd);
  const postForecast = calculateForecast(postUsage, postRemaining, windowStart, windowEnd);

  const daysToReset = windowEnd
    ? Math.max(0, Math.floor((new Date(windowEnd).getTime() - Date.now()) / (1000 * 60 * 60 * 24)))
    : null;

  return (
    <div className="rounded-2xl border bg-card p-5">
      <h3 className="mb-3 text-sm font-semibold text-muted-foreground uppercase tracking-wide">
        📈 Dự báo & Reset
      </h3>

      <div className="space-y-1 text-sm">
        <p>
          🤖 AI Content:{" "}
          {promptForecast
            ? `sẽ hết trong ${promptForecast}`
            : "Chưa có dữ liệu sử dụng."}
        </p>
        <p>
          📬 Bài đăng:{" "}
          {postForecast
            ? `sẽ hết trong ${postForecast}`
            : "Chưa có dữ liệu sử dụng."}
        </p>
      </div>

      {daysToReset !== null && (
        <p className="mt-3 text-xs text-muted-foreground">
          🔄 Quota sẽ reset sau {daysToReset} ngày ({formatDate(windowEnd!, "dd/MM/yyyy")}).
        </p>
      )}
    </div>
  );
}
```

```tsx
// features/payment/components/quota-alerts.tsx

function QuotaAlerts({
  promptRemaining, promptLimit,
  postRemaining, postLimit,
  onUpgrade,
}: {
  promptRemaining: number; promptLimit: number;
  postRemaining: number; postLimit: number;
  onUpgrade: () => void;
}) {
  const promptPct = promptLimit > 0 ? promptRemaining / promptLimit : 1;
  const postPct = postLimit > 0 ? postRemaining / postLimit : 1;

  const alerts: { type: "warning" | "error"; message: string }[] = [];

  if (promptLimit > 0 && promptRemaining === 0) {
    alerts.push({ type: "error", message: "🔴 Đã hết quota AI Content. Không thể tạo nội dung AI thêm." });
  } else if (promptLimit > 0 && promptPct <= 0.2) {
    alerts.push({ type: "warning", message: `⚠️ Sắp hết quota AI Content. Còn ${promptRemaining}/${promptLimit}.` });
  }

  if (postLimit > 0 && postRemaining === 0) {
    alerts.push({ type: "error", message: "🔴 Đã hết quota bài đăng. Không thể publish thêm." });
  } else if (postLimit > 0 && postPct <= 0.2) {
    alerts.push({ type: "warning", message: `⚠️ Sắp hết quota bài đăng. Còn ${postRemaining}/${postLimit}.` });
  }

  if (alerts.length === 0) return null;

  return (
    <div className="space-y-2">
      {alerts.map((alert, i) => (
        <div
          key={i}
          className={`flex items-center gap-3 rounded-xl border p-4 text-sm ${
            alert.type === "error"
              ? "border-red-200 bg-red-50 text-red-700"
              : "border-amber-200 bg-amber-50 text-amber-700"
          }`}
        >
          <span className="flex-1">{alert.message}</span>
          <Button size="sm" variant={alert.type === "error" ? "destructive" : "default"} onClick={onUpgrade}>
            Nâng cấp gói
          </Button>
        </div>
      ))}
    </div>
  );
}
```
