# US-23 - Cải thiện nội dung bằng AI

## 1. User Story

**Là** người dùng,
**tôi muốn** AI improve một content đã có dựa trên feedback tôi cung cấp,
**để** có phiên bản tốt hơn mà không phải viết lại từ đầu.

---

## 2. Mục tiêu

Cho phép người dùng chọn một content đã tồn tại (dù được tạo thủ công hay bằng AI), cung cấp prompt/feedback cải tiến, và AI (Gemini) sẽ tạo ra phiên bản nội dung mới được cải thiện. Người dùng có thể xem kết quả generation, cải tiến thêm (improve tiếp), hoặc approve generation để cập nhật `TextContent` của content hiện tại. Feature này giúp người dùng nhanh chóng tinh chỉnh nội dung mà không cần tự edit thủ công.

---

## 3. Phạm vi

### Trong phạm vi

- Nút/action "Improve with AI" trên trang chi tiết content và màn hình AI generation.
- Popup/panel nhập prompt cải tiến, hiển thị content hiện tại làm reference.
- Gọi API `POST /api/ai/improve/{contentId}` để tạo generation mới cho content hiện tại.
- Gọi API `POST /api/ai/approve/{aiGenerationId}` để áp dụng kết quả improve vào content (cập nhật `TextContent`).
- Gọi API `GET /api/ai/generations/{contentId}` để xem lịch sử improve generation của content.
- Hiển thị trạng thái generation: `Pending`, `Completed`, `Failed`.
- So sánh nội dung cũ và nội dung mới (diff preview) sau khi improve.
- Loading state, disable button khi đang xử lý.
- Toast thông báo thành công / lỗi.

### Ngoài phạm vi

- Generate draft mới từ brand/product/prompt (đã có trong US-22).
- Chat refinement với AI (đã có trong US-22).
- Improve nhiều content cùng lúc (batch).
- Lưu version history của content (chỉ lưu generation history).
- Tự động improve theo lịch (scheduled improve).
- Improve image/video content.
- Prompt template library cho improve.

---

## 4. Actor

- **Chính:** Người dùng đã đăng nhập, có profile đang active, có content hiện tại (Draft).
- **Phụ:** User Web App (frontend), Backend API (GeminiController/AIService), Gemini AI provider, PostgreSQL.

---

## 5. Tiền điều kiện

- Người dùng đã đăng nhập và có JWT access token hợp lệ.
- Người dùng đã chọn active profile (`X-Profile-Id` header hợp lệ).
- Content cần improve tồn tại, chưa bị soft-delete và thuộc profile đang active.
- `GeminiSettings` (API key) đã được cấu hình trên backend. Nếu thiếu, API trả lỗi graceful.

---

## 6. Luồng nghiệp vụ chính

### 6.1 Improve content từ trang chi tiết content

1. Người dùng truy cập trang chi tiết content (`/content/{contentId}`).
2. Hệ thống hiển thị nội dung content hiện tại (text, title, brand, product, ad type).
3. Người dùng nhấn nút **"Improve with AI"**.
4. Hệ thống mở panel/popup improve gồm:
   - **Content hiện tại** (read-only, để người dùng tham khảo).
   - **Textarea prompt** (bắt buộc) — người dùng nhập feedback hoặc hướng dẫn cải tiến, ví dụ: "Làm đoạn này ngắn hơn, thêm tính cấp bách", "Đổi giọng văn sang formal".
   - Nút **"Improve"** (primary, disabled khi prompt rỗng).
5. Người dùng nhập prompt và nhấn **"Improve"**.
6. Frontend gọi `POST /api/ai/improve/{contentId}` với `ImproveContentRequest` body.
7. Backend validate content ownership, gọi Gemini sinh nội dung mới dựa trên prompt.
8. Frontend nhận response `AiGenerationResponse`, hiển thị kết quả:
   - Generation thành công: hiển thị `GeneratedText`, trạng thái `Completed`.
   - Generation thất bại: hiển thị `ErrorMessage`, trạng thái `Failed`.
9. Người dùng có thể:
   - **Approve** generation để cập nhật `TextContent` của content (gọi `POST /api/ai/approve/{aiGenerationId}`).
   - **Improve lại** với prompt khác.
   - **So sánh** nội dung cũ và nội dung mới trước khi approve.
   - Xem lịch sử các generation improve của content này.

### 6.2 Improve content từ màn hình AI Generation

1. Người dùng ở màn hình AI Generation (`/ai`), đã generate draft thành công (US-22).
2. Trong panel kết quả, người dùng nhấn nút **"Improve"**.
3. Frontend hiển thị textarea prompt ngay trong panel result, kèm nội dung generation hiện tại.
4. Người dùng nhập feedback và nhấn **"Improve"**.
5. Frontend gọi `POST /api/ai/improve/{contentId}` (contentId lấy từ generation response trước đó).
6. Kết quả hiển thị tương tự luồng 6.1.

### 6.3 Approve improved generation

1. Người dùng xem kết quả improve generation thành công.
2. Người dùng nhấn **"Approve"** để áp dụng `GeneratedText` vào content.
3. Frontend gọi `POST /api/ai/approve/{aiGenerationId}`.
4. Backend copy `GeneratedText` vào `Content.TextContent`, giữ nguyên `Status = Draft`.
5. Frontend hiển thị toast thành công, cập nhật nội dung content hiện tại.

### 6.4 Xem lịch sử improve generation

1. Người dùng ở trang chi tiết content hoặc panel AI.
2. Frontend gọi `GET /api/ai/generations/{contentId}`.
3. Hiển thị danh sách generation theo thời gian (mới nhất trước).
4. Mỗi item hiển thị: prompt, trạng thái, `GeneratedText` (nếu Completed), `ErrorMessage` (nếu Failed), thời gian tạo.
5. Cho phép Approve generation từ danh sách này (nếu generation đang `Completed`).

## 7. Luồng ngoại lệ

| Mã | Trường hợp | Kết quả mong đợi |
| --- | --- | --- |
| EX-01 | Content không tồn tại hoặc không thuộc profile | Backend trả `404 Not Found`; frontend hiển thị lỗi và không gửi request. |
| EX-02 | Content đã bị soft-delete | Backend trả `404 Not Found`; frontend không hiển thị nút Improve cho content đã xóa. |
| EX-03 | Gemini API key chưa cấu hình | Backend trả `503 Service Unavailable`; frontend hiển thị thông báo "Dịch vụ AI chưa được cấu hình" và disable nút Improve. |
| EX-04 | Gemini API trả lỗi (network, quota, timeout) | Backend bắt exception, lưu `AiGeneration.Status = Failed` với `ErrorMessage`; frontend hiển thị trạng thái failed và error message. |
| EX-05 | Generation không tồn tại khi approve | Backend trả `404 Not Found`; frontend hiển thị lỗi. |
| EX-06 | Generation chưa hoàn thành (Pending/Failed) khi approve | Backend trả `400 Bad Request`; frontend disable nút Approve nếu generation không phải Completed. |
| EX-07 | JWT hết hạn hoặc không hợp lệ | Backend trả `401 Unauthorized`; frontend tự động refresh token hoặc chuyển hướng đăng nhập. |
| EX-08 | X-Profile-Id thiếu hoặc không thuộc user | Backend trả `400 Bad Request` / `403 Forbidden`; frontend hiển thị lỗi. |
| EX-09 | Người dùng nhấn Improve/Approve nhiều lần | Frontend disable nút sau lần nhấn đầu tiên đến khi có phản hồi. |
| EX-10 | Prompt quá ngắn hoặc chỉ gồm khoảng trắng | Frontend validate prompt không được rỗng trước khi gửi; nếu backend trả lỗi validation, hiển thị dưới field prompt. |
| EX-11 | Content chưa có TextContent (rỗng) | Backend vẫn cho phép improve (Gemini nhận prompt trực tiếp); frontend hiển thị cảnh báo nội dung hiện tại đang trống. |

## 8. Quy tắc nghiệp vụ

| Mã | Quy tắc |
| --- | --- |
| BR-01 | `ProfileId` được lấy từ `X-Profile-Id` header đã được middleware validate, không lấy từ request body. |
| BR-02 | Improve KHÔNG tạo content mới, chỉ tạo `AiGeneration` mới gắn với `ContentId` hiện tại. |
| BR-03 | Improve KHÔNG tiêu thụ prompt quota (không gọi `QuotaService.EnsurePromptQuotaAsync`). |
| BR-04 | Approve chỉ hoạt động khi `AiGeneration.Status == Completed` và `GeneratedText` không rỗng. |
| BR-05 | Approve sẽ copy `GeneratedText` vào `Content.TextContent`; content vẫn giữ `Status = Draft`. |
| BR-06 | Prompt gửi lên Gemini là nguyên văn `request.Prompt` từ client, backend không tự động ghép thêm nội dung content hiện tại. Frontend nên tự động xây dựng prompt context (content hiện tại + feedback) trước khi gửi để Gemini có ngữ cảnh. |
| BR-07 | Mỗi lần improve tạo một `AiGeneration` record mới; không ghi đè generation cũ. |
| BR-08 | Thứ tự xem generation history: mới nhất trước (descending by `CreatedAt`). |
| BR-09 | Nếu Gemini API key thiếu, backend không crash; generation được lưu với `Status = Failed` và error message thích hợp. |
| BR-10 | Improve có thể gọi nhiều lần trên cùng một content, mỗi lần tạo generation mới độc lập. |
| BR-11 | Content có `TextContent = ""` (rỗng) vẫn có thể improve — prompt gửi trực tiếp đến Gemini. |
| BR-12 | Sau approve, content cũ (`TextContent` trước improve) không được lưu lại. Nếu muốn giữ bản cũ, người dùng nên clone content trước khi improve. |

## 9. API Contracts

### 9.1 Improve Content

```
POST /api/ai/improve/{contentId}
```

#### Headers bắt buộc

```http
Authorization: Bearer <access-token>
X-Profile-Id: <owned-profile-guid>
```

#### Path Parameters

| Tham số | Kiểu | Bắt buộc | Mô tả |
| --- | --- | --- | --- |
| `contentId` | `Guid` | Có | ID của content cần improve. |

#### Request Body

```json
{
  "prompt": "Make the caption shorter and more playful, add emojis"
}
```

#### Tham số

| Field | Kiểu | Bắt buộc | Mô tả |
| --- | --- | --- | --- |
| `prompt` | `string` | Có | Feedback/hướng dẫn cải tiến nội dung cho AI. |

#### Response thành công (`200 OK`)

```json
{
  "success": true,
  "statusCode": 200,
  "message": "AI generation processed.",
  "data": {
    "aiGenerationId": "gen-uuid",
    "contentId": "content-uuid",
    "generatedText": "🔥 Don't miss out! Our summer sale is here — shop now before it's gone! 🏃‍♂️💨",
    "status": 1,
    "errorMessage": null,
    "createdAt": "2026-06-03T06:35:00Z"
  }
}
```

### 9.4 Response Error Codes

| HTTP Status | errorCode | Trường hợp |
| --- | --- | --- |
| `401 Unauthorized` | — | JWT thiếu hoặc không hợp lệ. |
| `400 Bad Request` | — | `X-Profile-Id` thiếu, sai format, hoặc generation không phải Completed khi approve. |
| `403 Forbidden` | — | Profile không thuộc user đang đăng nhập. |
| `404 Not Found` | — | Content/Generation không tồn tại, đã bị xóa, hoặc không thuộc profile. |
| `503 Service Unavailable` | — | Gemini API key chưa cấu hình hoặc AI service tạm thời không khả dụng. |
| `500 Internal Server Error` | — | Lỗi hệ thống không mong đợi. |

> **Lưu ý:** Improve không có lỗi `PROMPT_QUOTA_EXCEEDED` vì improve không tiêu thụ quota (BR-03).

### 9.5 Mapping Enums

**`aiGenerationStatus`:**

| Giá trị | Tên | Mô tả |
| --- | --- | --- |
| `0` | `Pending` | Đang chờ xử lý |
| `1` | `Completed` | Đã hoàn thành |
| `2` | `Failed` | Thất bại |

**`contentStatus`:**

| Giá trị | Tên | Mô tả |
| --- | --- | --- |
| `0` | `Draft` | Bản nháp |
| `1` | `PendingApproval` | Chờ duyệt |
| `2` | `Approved` | Đã duyệt |
| `3` | `Rejected` | Đã từ chối |
| `4` | `Published` | Đã đăng |

## 10. Màn hình / UI Components

### 10.1 Improve Panel trên trang chi tiết content

**Vị trí:** Trang `/content/{contentId}`, khu vực actions bên cạnh nội dung.

**Layout:**

- **Khu vực nội dung hiện tại** (read-only):
  - Hiển thị `Title`, `TextContent` hiện tại.
  - Badge `Brand`, `Product`, `AdType`.
- **Nút "Improve with AI"**: mở panel trượt (slide-over) hoặc modal.

**Panel improve (modal/slide-over):**

- **Section 1: Content hiện tại** (collapse/expand, mặc định expand):
  - Hiển thị `TextContent` hiện tại trong code block hoặc card read-only để người dùng tham khảo khi viết feedback.
- **Section 2: Improve form**:
  - **Prompt textarea** (bắt buộc, placeholder: *"Nhập feedback để cải thiện nội dung. Ví dụ: Làm ngắn hơn, thêm cảm xúc, đổi giọng văn sang chuyên nghiệp..."*).
  - Gợi ý prompt nhanh (quick prompts) bên dưới textarea: chip buttons như "Ngắn gọn hơn", "Thêm tính cấp bách", "Chuyên nghiệp hơn", "Thêm emoji", "Thân thiện hơn".
  - Nút **"Improve"** (primary, disabled khi prompt rỗng hoặc đang improve).
- **Section 3: Kết quả improve** (hiển thị sau khi có response):
  - Card kết quả với `GeneratedText` (nếu Completed) hoặc `ErrorMessage` (nếu Failed).
  - **Diff preview**: so sánh nội dung cũ với nội dung mới (highlight changes), giúp người dùng thấy rõ sự khác biệt trước khi approve.
  - Nút **"Approve"** (primary) — chỉ enable nếu generation `Completed`.
  - Nút **"Improve again"** (outline) — gọi improve với prompt mới.
  - Nút **"Discard"** (ghost) — đóng panel, không thay đổi gì.
- **Tab Generation History** (trong cùng panel):
  - Danh sách các generation trước đó (gọi `GET /api/ai/generations/{contentId}`).
  - Mỗi item: prompt, status badge, `GeneratedText` hoặc `ErrorMessage`, timestamp.
  - Nút "Approve" trên item nếu generation `Completed` và khác với generation hiện tại.

### 10.2 Improve từ màn hình AI Generation (`/ai`)

- Trong panel kết quả của US-22, nút **"Improve"** mở inline textarea ngay dưới kết quả generation.
- Sau khi improve, kết quả mới thay thế kết quả hiện tại; generation cũ vẫn ở history tab.

### 10.3 Trạng thái rỗng / Lần đầu

- **Chưa improve lần nào:** Ẩn tab generation history hoặc hiển thị placeholder "Chưa có lần improve nào".
- **Content chưa có TextContent:** Hiển thị cảnh báo nhẹ: "Nội dung hiện tại đang trống. AI sẽ tạo nội dung dựa trên prompt của bạn."
- **Không có quyền improve:** Nếu content không phải Draft hoặc không thuộc profile, ẩn nút Improve.

## 11. Responsive States

| State | UI hiển thị |
| --- | --- |
| **Loading (Improve)** | Nút Improve hiển thị spinner, disabled. Skeleton cho kết quả generation. |
| **Success** | Hiển thị GeneratedText, status badge "Completed" (xanh), enable nút Approve, hiển thị diff với content cũ. |
| **Error (Generation failed)** | Status badge "Failed" (đỏ), hiển thị ErrorMessage từ backend, enable nút Improve lại. |
| **AI not configured** | Alert màu đỏ: "Dịch vụ AI chưa được cấu hình.", disable nút Improve. |
| **Empty state** | Placeholder text, hướng dẫn sử dụng. |
| **Network error** | Toast lỗi kết nối, cho phép thử lại. |
| **Approve loading** | Nút Approve hiển thị spinner, disabled. |
| **Approve success** | Toast "Approved", cập nhật TextContent hiện tại, đóng panel hoặc chuyển về trang content detail mới. |

## 12. Acceptance Criteria

### AC-01 - Improve content thành công từ trang chi tiết

**Given** người dùng đang ở trang chi tiết content  
**When** người dùng nhấn Improve with AI, nhập prompt, và nhấn Improve  
**Then** frontend gọi `POST /api/ai/improve/{contentId}`  
**And** hiển thị kết quả generation (Completed/Failed)  
**And** nếu Completed, hiển thị `GeneratedText` và nút Approve.

### AC-02 - Approve improved generation thành công

**Given** generation improve đã hoàn thành (Completed)  
**When** người dùng nhấn Approve  
**Then** `POST /api/ai/approve/{aiGenerationId}` được gọi  
**And** frontend hiển thị toast "Approved"  
**And** `Content.TextContent` được cập nhật với `GeneratedText` mới.

### AC-03 - Có thể improve nhiều lần trên cùng content

**Given** content đã tồn tại  
**When** người dùng improve lần thứ hai với prompt khác  
**Then** generation mới được tạo, không ghi đè generation cũ  
**And** cả hai đều xuất hiện trong generation history.

### AC-04 - Improve không tạo content mới

**Given** content hiện tại có `ContentId = X`  
**When** improve thành công  
**Then** response có `contentId = X` (giống với content gốc)  
**And** số lượng content không tăng.

### AC-05 - Improve không tiêu thụ quota

**Given** người dùng đã hết prompt quota  
**When** người dùng nhấn Improve  
**Then** API vẫn xử lý thành công (không trả PROMPT_QUOTA_EXCEEDED).

### AC-06 - Xem lịch sử improve generation

**Given** content đã có ít nhất một generation improve  
**When** người dùng mở tab Generation History  
**Then** `GET /api/ai/generations/{contentId}` được gọi  
**And** danh sách generation hiển thị theo thứ tự mới nhất trước.

### AC-07 - Approve chỉ khả dụng cho generation Completed

**Given** generation có `Status = Pending` hoặc `Failed`  
**When** hiển thị panel kết quả  
**Then** nút Approve disabled hoặc ẩn.

### AC-08 - Hiển thị prompt suggestion chips

**Given** panel improve đang mở  
**When** người dùng chưa nhập prompt  
**Then** hiển thị các quick prompt suggestions (chip buttons)  
**And** khi click chip, prompt textarea được điền sẵn giá trị tương ứng.

### AC-09 - Diff preview trước khi approve

**Given** generation improve đã Completed  
**When** hiển thị kết quả  
**Then** hiển thị so sánh giữa nội dung cũ và nội dung mới (highlight khác biệt).

### AC-10 - Frontend validate prompt không rỗng

**Given** người dùng chưa nhập prompt  
**When** người dùng nhấn Improve  
**Then** frontend hiển thị validation lỗi dưới field prompt  
**And** không gọi API.

### AC-11 - Disable nút trong lúc xử lý

**Given** người dùng đã nhấn Improve hoặc Approve  
**When** API đang xử lý  
**Then** nút bị disable và hiển thị loading indicator  
**And** không gửi request thứ hai.

### AC-12 - Content không tồn tại

**Given** contentId không hợp lệ hoặc không thuộc profile

// features/ai/api/ai-api.ts
import { apiRequest } from "@/lib/api/fetcher";

export type ImproveContentInput = {
  prompt: string;
};

export type AiGenerationResponse = {
  aiGenerationId: string;
  contentId: string;
  generatedText: string | null;
  status: number; // 0=Pending, 1=Completed, 2=Failed
  errorMessage: string | null;
  createdAt: string;
};

export const aiApi = {
  improve: (contentId: string, payload: ImproveContentInput) =>
    apiRequest<AiGenerationResponse>(`/api/ai/improve/${contentId}`, {
      method: "POST",
      body: JSON.stringify(payload),
      auth: true,
    }),

  approve: (aiGenerationId: string) =>
    apiRequest<ContentResponseDto>(`/api/ai/approve/${aiGenerationId}`, {
      method: "POST",
      auth: true,
    }),

  getGenerations: (contentId: string) =>
    apiRequest<AiGenerationResponse[]>(`/api/ai/generations/${contentId}`, {
      method: "GET",
      auth: true,
    }),
};
