# US-45 - Xem lịch sử thanh toán

## 1. User Story

**Là** người dùng,
**tôi muốn** xem lịch sử giao dịch thanh toán đầy đủ với phân trang và bộ lọc,
**để** có thể đối chiếu các lần nâng cấp/gia hạn gói subscription của mình.

---

## 2. Mục tiêu

Cung cấp trang `/payment/history` (hoặc tab History trong `/payment`) hiển thị danh sách giao dịch thanh toán dạng bảng với phân trang server-side, filter theo trạng thái, và modal chi tiết cho từng giao dịch. Feature này bổ sung cho mini payment history table ở US-44 và cung cấp khả năng xem toàn bộ lịch sử với UX đầy đủ hơn.

---

## 3. Phạm vi

### Trong phạm vi

- Trang `/payment/history` (route con của payment).
- Danh sách giao dịch dạng bảng với các cột:
  - Ngày giờ (định dạng `dd/MM/yyyy HH:mm`).
  - Phương thức thanh toán (ví dụ: "PayOS").
  - Số tiền (định dạng tiền tệ VND, có phân cách hàng nghìn).
  - Trạng thái (badge màu).
- Filter tabs theo trạng thái (All, Pending, Success, Failed, Refunded):
  - `All`: hiển thị tất cả giao dịch.
  - `Pending`: chỉ giao dịch đang chờ.
  - `Success`: chỉ giao dịch thành công.
  - `Failed`: chỉ giao dịch thất bại.
  - `Refunded`: chỉ giao dịch đã hoàn tiền.
  - Filter được thực hiện client-side trên dữ liệu đã fetch.
- Phân trang server-side:
  - 20 items / trang (pageSize = 20).
  - Nút Previous / Next + số trang hiện tại / tổng số trang.
  - Click trang → fetch lại với Page tương ứng.
- Modal chi tiết giao dịch:
  - Click row → mở modal.
  - Hiển thị: ID giao dịch, phương thức, số tiền, trạng thái, ngày tạo.
  - Ghi chú: BE `PaymentHistoryItemDto` hiện chỉ có các field trên; nếu cần thêm (TransactionId, InvoiceUrl), cần cập nhật DTO.
- Empty state:
  - Danh sách trống → "Chưa có giao dịch nào."
  - Filter không có kết quả → "Không tìm thấy giao dịch nào với trạng thái này."
- Loading skeleton cho table rows (5-10 rows shimmer).
- Error state → error banner + nút "Thử lại".
- Link "Xem tất cả" từ mini payment history table (US-44) → navigate đến `/payment/history`.
- Refresh button (refetch current page).

### Ngoài phạm vi

- Filter theo khoảng ngày (date range picker): deferred, post-MVP.
- Tìm kiếm (search) theo transaction ID: deferred.
- Export CSV/PDF: deferred.
- Sắp xếp (sort) theo cột: deferred (BE chỉ support sort mặc định CreatedAt desc).
- Invoice download link: deferred (cần InvoiceUrl từ BE DTO).
- Filter server-side (BE hiện không hỗ trợ filter params; filter client-side).
- Real-time cập nhật khi có giao dịch mới (polling hoặc WebSocket): deferred.

## 6. Luồng nghiệp vụ chính

### 6.1 Vào trang Payment History

1. Người dùng click "Xem tất cả" từ mini payment history table (US-44) hoặc vào trực tiếp `/payment/history`.
2. Frontend gọi `GET /api/payment/history?Page=1&PageSize=20`.
3. Hiển thị bảng danh sách giao dịch.
4. Status tab mặc định là "All".

### 6.2 Phân trang

1. Người dùng click "Next" → fetch page tiếp theo.
2. Người dùng click "Previous" → fetch page trước đó.
3. Hiển thị "Trang X / Y" + [Previous] [Next].
4. Nút Previous disabled nếu đang ở trang 1.
5. Nút Next disabled nếu đang ở trang cuối.

### 6.3 Filter theo trạng thái

1. Người dùng click tab "Success" → lọc client-side các giao dịch có status = "Success".
2. Các tab: All, Pending, Success, Failed, Refunded.
3. Khi filter active, phân trang vẫn hoạt động trên dữ liệu gốc đã fetch (filter client-side).
4. Nếu filter không có kết quả → empty state message riêng.

### 6.4 Xem chi tiết giao dịch

1. Người dùng click row trong bảng → mở modal.
2. Modal hiển thị:
   - Mã giao dịch: `{id}` (UUID rút gọn: 8 ký tự đầu).
   - Phương thức: PayOS.
   - Số tiền: `{amount} VND`.
   - Trạng thái: badge màu.
   - Ngày tạo: `dd/MM/yyyy HH:mm`.
3. Nút "Đóng" hoặc click outside → đóng modal.

### 6.5 Refresh

1. Nút refresh (icon) → refetch current page data.

## 8. Quy tắc nghiệp vụ

| Mã | Quy tắc |
| --- | --- |
| BR-01 | Lịch sử thanh toán chỉ hiển thị giao dịch của profile đang active (`X-Profile-Id`). |

## 12. Acceptance Criteria

### AC-01 - Trang Payment History

**Given** người dùng vào `/payment/history`
**When** trang load
**Then** gọi `GET /api/payment/history?Page=1&PageSize=20`
**And** hiển thị bảng danh sách giao dịch + filter tabs + phân trang.

### AC-02 - Bảng hiển thị đúng cột

**Given** có dữ liệu giao dịch
**Then** bảng hiển thị các cột: Ngày, Phương thức, Số tiền, Trạng thái.

### AC-03 - Phân trang

**Given** có nhiều hơn 20 giao dịch
**When** click "Next"
**Then** fetch page 2, hiển thị giao dịch page 2.
**And** Previous/Next disabled ở page đầu/cuối.

### AC-04 - Filter tabs

**Given** đã fetch dữ liệu
**When** click tab "Thành công"
**Then** chỉ hiển thị giao dịch có status "Success" (client-side filter).

### AC-05 - Detail modal

**Given** có dữ liệu giao dịch
**When** click row
**Then** mở modal với ID, phương thức, số tiền, trạng thái, ngày tạo.

### AC-06 - Loading skeleton

**Given** API đang xử lý
**Then** hiển thị skeleton rows.

### AC-07 - Error state

**Given** API trả lỗi
**Then** hiển thị error banner + nút "Thử lại".

### AC-08 - Empty state

**Given** chưa có giao dịch nào
**Then** hiển thị "Chưa có giao dịch nào."

### AC-09 - Filter empty state

**Given** filter tab không có kết quả
**Then** hiển thị "Không tìm thấy giao dịch nào với trạng thái này."

### AC-10 - Refresh

**Given** đã fetch dữ liệu
**When** click refresh
**Then** refetch current page.

## 13. Gợi ý Implementation Theo Tech Stack

### Backend - .NET 8

> **Lưu ý:** Backend đã implement:
> - `PaymentController.GetHistory` — `GET /api/payment/history`.
> - `PayOSPaymentService.GetPaymentHistoryAsync` — map từ Payment entity → `PaymentHistoryItemDto`.
> - `PaymentRepository.GetPagedByProfileIdAsync` — paged query, sort CreatedAt desc, soft-delete aware.
> - `PaginationRequest` / `PagedResult<T>` — hỗ trợ page, pageSize, totalCount, totalPages.
>
> **Hạn chế hiện tại:**
> - `PaymentHistoryItemDto` chỉ có 5 fields: Id, PaymentMethod, Amount, Status, CreatedAt.
> - Payment entity có thêm Currency, TransactionId, InvoiceUrl, SubscriptionId nhưng chưa expose qua DTO.
> - BE không hỗ trợ server-side filter theo status hay date range.
>
> **Gợi ý cải thiện DTO (optional, post-MVP):**
> Thêm `TransactionId`, `InvoiceUrl`, `Currency` vào `PaymentHistoryItemDto` để modal chi tiết giàu hơn.

import { useQuery, keepPreviousData } from "@tanstack/react-query";
import { paymentApi } from "@/features/payment/api/payment-api";

export function usePaymentHistory(page: number, pageSize = 20) {
  return useQuery({

// features/payment/components/payment-history-page.tsx
"use client";

import { useState } from "react";
import { usePaymentHistory } from "@/features/payment/hooks/use-payment-history";
import { PaymentHistoryFilters } from "./payment-history-filters";
import { PaymentHistoryTable } from "./payment-history-table";
import { PaymentHistoryPagination } from "./payment-history-pagination";
import { PaymentDetailModal } from "./payment-detail-modal";
import type { PaymentHistoryItemDto, PaymentStatusFilter } from "@/features/payment/types/payment";

const PAGE_SIZE = 20;

export function PaymentHistoryPage() {
  const [page, setPage] = useState(1);
  const [statusFilter, setStatusFilter] = useState<PaymentStatusFilter>("All");
  const [selectedPayment, setSelectedPayment] = useState<PaymentHistoryItemDto | null>(null);

  const { data, isLoading, isError, refetch, isRefetching } = usePaymentHistory(page, PAGE_SIZE);

  const allPayments = data?.data?.data ?? [];
  const totalCount = data?.data?.totalCount ?? 0;
  const totalPages = data?.data?.totalPages ?? 0;

  // Client-side filter
  const filteredPayments =
    statusFilter === "All"
      ? allPayments
      : allPayments.filter((p) => p.status === statusFilter);

  return (
    <section className="space-y-6">
      <div className="flex items-center justify-between">
        <div>
          <h1 className="text-3xl font-semibold">💳 Lịch sử giao dịch</h1>
          <p className="mt-1 text-sm text-muted-foreground">
            Đối chiếu các lần thanh toán và nâng cấp gói.
          </p>
        </div>
        <button
          onClick={() => refetch()}
          disabled={isRefetching}
          className="rounded-full p-2 transition-colors hover:bg-muted disabled:opacity-50"
          title="Refresh"
        >
          <RefreshCw className={`h-5 w-5 ${isRefetching ? "animate-spin" : ""}`} />
        </button>
      </div>

      {isError && (
        <div className="flex items-center gap-3 rounded-xl border border-destructive/20 bg-destructive/5 p-4 text-sm text-destructive">
          <AlertCircle className="h-5 w-5 shrink-0" />
          <span className="flex-1">Không thể tải lịch sử giao dịch.</span>
          <button onClick={() => refetch()} className="font-medium underline hover:no-underline">
            Thử lại
          </button>
        </div>
      )}

      <PaymentHistoryFilters active={statusFilter} onChange={setStatusFilter} />

      <PaymentHistoryTable
        payments={filteredPayments}
        isLoading={isLoading}
        onRowClick={setSelectedPayment}
      />

      <PaymentHistoryPagination
        page={page}
        totalPages={totalPages}
        totalCount={totalCount}
        onPageChange={setPage}
      />

      <PaymentDetailModal
        payment={selectedPayment}
        onClose={() => setSelectedPayment(null)}
      />
    </section>
  );
}

          ))}

      </div>
    );
  }

  if (payments.length === 0) {
    return (
      <div className="rounded-2xl border bg-card p-6 text-center text-sm text-muted-foreground">
        {payments === undefined
          ? "Chưa có giao dịch nào."
          : "Không tìm thấy giao dịch nào với trạng thái này."}
      </div>
    );
  }

  return (
    <div className="rounded-2xl border bg-card overflow-hidden">
      <table className="w-full text-left text-sm">
        <thead>
          <tr className="border-b bg-muted/50 text-xs text-muted-foreground">
            <th className="px-4 py-3 font-medium">Ngày</th>
            <th className="px-4 py-3 font-medium">Phương thức</th>
            <th className="px-4 py-3 font-medium text-right">Số tiền</th>
            <th className="px-4 py-3 font-medium text-right">Trạng thái</th>
          </tr>
        </thead>
        <tbody>
          {payments.map((p) => (
            <tr
              key={p.id}
              onClick={() => onRowClick(p)}
              className="cursor-pointer border-b transition-colors hover:bg-muted/30 last:border-0"
            >
              <td className="px-4 py-3 tabular-nums">
                {formatDate(p.createdAt, "dd/MM/yyyy HH:mm")}
              </td>
              <td className="px-4 py-3">{p.paymentMethod}</td>
              <td className="px-4 py-3 text-right font-medium tabular-nums">
                {formatCurrency(p.amount)}₫
              </td>
              <td className="px-4 py-3 text-right">
                <PaymentStatusBadge status={p.status} />
              </td>
            </tr>
          ))}
        </tbody>
      </table>
    </div>
  );
}
