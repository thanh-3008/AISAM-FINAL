# US-09 Frontend Detail - Quen mat khau

## 1. User story

La nguoi dung quen mat khau, toi muon yeu cau gui link dat lai mat khau de co the truy cap lai tai khoan.

## 2. Muc tieu frontend

- Cung cap trang forgot password don gian va an toan.
- Goi dung endpoint forgot password cua backend.
- Hien neutral success state khong tiet lo email co ton tai hay khong.

## 3. Can cu backend va scope hien tai

### Requirement lien quan

- `requirement.md` muc `6.1` yeu cau `Quen mat khau, dat lai mat khau`.

### Backend implementation thuc te

- Endpoint: `POST /api/Auth/forgot-password`
- Request body:
  - `email`
- Response thanh cong: `200 OK`

### Hanh vi backend can frontend phai follow

- Backend co xu ly security:
  - email ton tai hay khong deu tra cung mot message
- Message:
  - `If the email exists, a password reset link has been sent`
- Neu xay ra exception trong service, controller van tra `200` voi neutral message

## 4. Pham vi frontend

### Trong pham vi

- Trang `/forgot-password`
- Form email
- Neutral success state

### Ngoai pham vi

- Dat lai mat khau bang token: thuoc `US-10`

## 5. API contract can dung

### Request

`POST /api/Auth/forgot-password`

```json
{
  "email": "user@example.com"
}
```

### Success response

HTTP: `200 OK`

```json
{
  "success": true,
  "message": "If the email exists, a password reset link has been sent",
  "statusCode": 200,
  "data": null,
  "error": null
}
```

## 6. UI/UX spec

### Route

- `/forgot-password`

### Form fields

1. `email`
   - required
   - email format

### CTA

- `Send reset link`

### Success copy

- Can dung neutral copy, khong thong bao email co ton tai

## 7. Validation frontend

- Email bat buoc
- Dung format email

## 8. Data flow frontend

1. User vao `/forgot-password`
2. Nhap email
3. Frontend validate
4. Goi `POST /api/Auth/forgot-password`
5. Hien success state trung tinh

## 9. State can xu ly

### Loading state

- Disable CTA

### Success state

- Hien message backend

### Error state

- Chu yeu la validation client-side
- Neu co loi mang bat thuong, hien generic error

## 10. Auth/session impact

- Khong thay doi auth state

## 11. Dieu huong sau submit

- Khong can redirect
- Co the cho user quay lai `/login`

## 12. Acceptance criteria

### AC-01

Frontend gui dung request forgot password den backend.

### AC-02

Sau submit thanh cong, frontend hien thong diep trung tinh.

### AC-03

Frontend khong duoc de lo email co ton tai hay khong qua noi dung UI.

## 13. Test cases frontend

### FE-01

Email sai format khong submit.

### FE-02

Submit thanh cong hien neutral success state.

### FE-03

Pending state disable CTA.

## 14. Ghi chu implementation

- Backend chu dong che thong tin account existence, frontend khong duoc bo sung copy phan biet.
- Story nay co the dung ngay ca khi user chua verify email.
