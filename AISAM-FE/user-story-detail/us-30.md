# US-30 - Xem tài khoản social đã liên kết

## 1. User Story

**Là** người dùng,
**tôi muốn** xem các tài khoản social đã kết nối trong profile hiện tại để quản lý quyền truy cập,
**để** biết được kênh nào đang hoạt động, token nào sắp hết hạn, và page nào đã liên kết với brand nào.

---

## 2. Mục tiêu

Cung cấp giao diện xem tập trung tất cả tài khoản social đã kết nối của profile đang active. Hiển thị trạng thái kết nối trực quan (active, expired, error), danh sách page đã liên kết kèm brand tương ứng, và thông tin chi tiết như thời gian tạo, thời gian hết hạn token. Feature này giúp người dùng nhanh chóng đánh giá tình trạng tích hợp social trước khi thực hiện publish.

---

## 3. Phạm vi

### Trong phạm vi

- Xem danh sách tất cả tài khoản social của profile đang active (`GET /api/social/accounts/me`).
- Mỗi account card hiển thị:
  - Provider icon (Facebook, về sau có Instagram, TikTok).
  - Provider user ID.
  - Trạng thái kết nối: **Active**, **Token expired**, **Error**.
  - Thời gian hết hạn token (nếu có).
  - Thời gian tạo và cập nhật gần nhất.
- Mỗi account card hiển thị danh sách page/target đã liên kết:
  - Tên page.
  - Brand đã liên kết (lấy từ integration).
  - Trạng thái page.
- Xem danh sách integrations theo brand (`GET /api/social/integrations/brand/{brandId}`) từ màn hình Brand Detail.
- Refresh danh sách accounts (pull-to-refresh hoặc nút reload).
- Empty state khi chưa có account nào.
- Error state khi API fail.
- Loading skeleton.

### Ngoài phạm vi

- Kết nối tài khoản mới: xem US-29.
- Ngắt kết nối account/page: xem US-29.
- Quản lý page (link/unlink target): xem US-29.
- Reconnect khi token expired: xem US-29.
- Facebook Ads nâng cao.
- Instagram/TikTok publishing.
- Real-time analytics từ social platforms.

---

## 4. Actor

- **Chính:** Người dùng đã đăng nhập, có profile đang active.
- **Phụ:** User Web App (frontend), Backend API (SocialAccountController, SocialIntegrationController, SocialService, FacebookProvider), PostgreSQL.

---

## 5. Tiền điều kiện

- Người dùng đã đăng nhập và có JWT access token hợp lệ.
- Người dùng đã chọn active profile (`X-Profile-Id` header hợp lệ).
- Backend API và PostgreSQL đang hoạt động.

---

## 6. Luồng nghiệp vụ chính

### 6.1 Xem danh sách tài khoản social

1. Người dùng vào màn hình Social Connections (`/social`).
2. Frontend gọi `GET /api/social/accounts/me`.
3. Backend trả danh sách `SocialAccountDto` (mỗi account kèm targets/integrations).
4. Frontend render danh sách account cards:
   - Mỗi card hiển thị provider icon, status badge, thông tin cơ bản.
   - Expandable section chứa danh sách page đã liên kết.
5. Nếu danh sách rỗng → hiển thị empty state.
6. Nếu API lỗi → hiển thị error state + nút Retry.

### 6.2 Xem chi tiết trạng thái token

1. Trên account card, hệ thống tự động tính toán và hiển thị:
   - **Active** (xanh): token còn hạn > 7 ngày.
   - **Expiring soon** (vàng cảnh báo): token còn hạn <= 7 ngày.
   - **Expired** (đỏ): token đã hết hạn (`expiresAt < now`).
   - **Error** (đỏ + icon lỗi): account `IsActive = false` nhưng chưa bị xoá.
2. Hiển thị ngày hết hạn token dạng relative ("còn 30 ngày", "hết hạn trong 3 ngày", "đã hết hạn").
3. Nếu `expiresAt` null → hiển thị "Không có thông tin."

### 6.3 Xem danh sách page đã liên kết theo account

1. Account card hiển thị số lượng page: "N pages linked".
2. Mặc định chỉ hiển thị 2 page gần nhất, có nút "View all N pages" expand.
3. Mỗi page item hiển thị:
   - Tên page (từ `name` field).
   - Brand đã liên kết.
   - Trạng thái active/inactive.
   - Thời gian liên kết.

### 6.4 Xem integrations theo brand (từ Brand Detail)

1. Khi người dùng xem chi tiết brand, có section "Connected Pages".
2. Frontend gọi `GET /api/social/integrations/brand/{brandId}`.
3. Hiển thị danh sách page Facebook đã liên kết với brand đó.
4. Mỗi item hiển thị: tên page, platform icon, trạng thái.

### 6.5 Refresh danh sách

1. Người dùng nhấn nút **Refresh** (icon reload) trên header.
2. Frontend gọi lại `GET /api/social/accounts/me`.
3. Danh sách được cập nhật.
4. Toast "Đã làm mới danh sách."

| Mã | Trường hợp | Kết quả mong đợi |

## 8. Quy tắc nghiệp vụ

| Mã | Quy tắc |
| --- | --- |
| BR-01 | Danh sách accounts chỉ hiển thị account `IsDeleted = false` (BE filter sẵn). |
| BR-02 | Danh sách targets chỉ hiển thị target `IsDeleted = false` (BE filter sẵn). |
| BR-03 | `AccessToken` không bao giờ được gửi lên FE (`[JsonIgnore]` trong `SocialAccountDto`). |
| BR-04 | Trạng thái token được FE tính toán từ `expiresAt` so với `Date.now()`. |
| BR-05 | Mỗi profile chỉ thấy accounts của chính mình (BE enforce ownership). |
| BR-06 | View-only không thay đổi dữ liệu; mọi thay đổi phải qua API mutation (US-29). |

## 12. Acceptance Criteria

### AC-01 - Xem danh sách accounts

**Given** profile có ít nhất một social account
**When** vào màn hình Social Connections
**Then** `GET /api/social/accounts/me` được gọi
**And** danh sách account cards hiển thị
**And** mỗi card hiển thị provider, user ID, status, token expiry, created time.

### AC-02 - Trạng thái token

**Given** account có `expiresAt`
**When** render card
**Then** tính relative time: "còn 30 ngày" / "hết hạn trong 3 ngày" / "đã hết hạn 2 ngày trước"
**And** status badge tương ứng (xanh/vàng/đỏ).

### AC-03 - Xem pages đã liên kết

**Given** account có targets
**When** render card
**Then** hiển thị danh sách pages với tên và brand liên kết.

### AC-04 - Expand pages khi > 2

**Given** account có > 2 pages
**When** render card mặc định
**Then** chỉ hiển thị 2 pages + nút "View all N pages"
**When** nhấn "View all"
**Then** expand toàn bộ danh sách.

### AC-05 - Xem integrations theo brand

**Given** brand đã liên kết với page
**When** vào Brand Detail hoặc section Integrations by Brand
**Then** gọi `GET /api/social/integrations/brand/{brandId}`
**And** hiển thị danh sách page của brand đó.

### AC-06 - Empty state

**Given** chưa có account nào
**When** vào màn hình Social Connections
**Then** hiển thị empty state + nút "Connect Facebook".

### AC-07 - Loading state

**Given** đang fetch danh sách
**When** render
**Then** hiển thị skeleton cards thay vì danh sách thật.

### AC-08 - Error state

**Given** API call fail
**When** render
**Then** hiển thị error state + nút "Retry"
**When** nhấn Retry
**Then** gọi lại API.

### AC-09 - Refresh danh sách

**Given** đã có danh sách accounts
**When** nhấn nút Refresh
**Then** gọi lại `GET /api/social/accounts/me`
**And** cập nhật danh sách.

### AC-10 - Integrations by Brand tổng hợp

**Given** có nhiều brand với pages đã liên kết
**When** ở section Integrations by Brand
**Then** group theo brand, mỗi brand hiển thị tên + số page + danh sách pages.

**use-token-status.ts (utility hook):**

```typescript
// hooks/use-token-status.ts
import { useMemo } from "react";
import type { SocialAccountDto, TokenStatus } from "@/features/social/types/social";

export function getTokenStatus(account: SocialAccountDto): {
  status: TokenStatus;
  daysUntilExpiry: number | null;
} {
  if (!account.expiresAt) {
    return { status: "unknown", daysUntilExpiry: null };
  }

  const now = Date.now();
  const expiry = new Date(account.expiresAt).getTime();
  const diffMs = expiry - now;
  const daysUntilExpiry = Math.floor(diffMs / (1000 * 60 * 60 * 24));

  if (diffMs <= 0) {
    return { status: "expired", daysUntilExpiry };
  }

  if (daysUntilExpiry <= 7) {
    return { status: "expiring-soon", daysUntilExpiry };
  }

  return { status: "active", daysUntilExpiry };
}
```

```tsx
            ? `Token expired ${Math.abs(daysUntilExpiry ?? 0)} days ago`
            : daysUntilExpiry !== null
              ? `Token expires in ${daysUntilExpiry} days`
              : "Token expiry: unknown"}
        </p>
        <p>Connected {formatRelativeTime(account.createdAt)}</p>
      </div>

      {account.targets.length > 0 && (
        <div className="mt-4">
          <p className="mb-2 text-sm font-medium text-muted-foreground">
            Linked Pages ({account.targets.length})
          </p>
          <div className="space-y-2">
            {visibleTargets.map((target) => (
              <div key={target.id} className="flex items-center gap-2 rounded-lg bg-muted/50 px-3 py-2 text-sm">
                <span>📄</span>
                <span className="flex-1">{target.name || target.providerTargetId}</span>
                <span className="text-xs text-muted-foreground">
                  {target.isActive ? "Active" : "Inactive"}
                </span>
              </div>
            ))}
          </div>
          {account.targets.length > 2 && !expanded && (
            <button
              className="mt-2 text-sm font-medium text-primary hover:underline"
              onClick={() => setExpanded(true)}
            >
              View all {account.targets.length} pages
            </button>
          )}
          {expanded && account.targets.length > 2 && (
            <button
              className="mt-2 text-sm font-medium text-primary hover:underline"
              onClick={() => setExpanded(false)}
            >
              Show less
            </button>
          )}
        </div>
      )}

      {account.targets.length === 0 && (
        <p className="mt-4 text-sm text-muted-foreground">
          No pages linked yet.
        </p>
      )}
    </div>
  );
}
```
