# US-19 Frontend Detail - Tao noi dung thu cong

## 1. User story

La nguoi dung da dang nhap va da chon business profile, toi muon tao content draft theo profile, brand va product de bat dau quy trinh sang tao.

## 2. Muc tieu frontend

- Cung cap man hinh/form tao content thu cong trong ngu canh active profile.
- Cho nguoi dung chon brand bat buoc va product tuy chon dung theo brand.
- Goi dung Content API dang active trong backend.
- Tao content voi trang thai mac dinh `Draft` de tiep tuc chinh sua, AI improve, schedule hoac publish o cac story sau.

## 3. Can cu backend va scope hien tai

### Requirement lien quan

- `requirement.md` muc `5.1 End User Use Cases`: tao content thu cong hoac bang AI.
- `requirement.md` muc `6.6 AI Content Generation`: chon brand/product lam context dau vao.
- `requirement.md` muc `7 Business Rules`: moi content phai thuoc mot business profile va mot brand hop le; product neu duoc chon phai thuoc dung brand.

### Backend plan lien quan

- `BACKEND_CODE_PLAN.md` Phase 5: Content + AI + Conversation MVP.
- `CODEBASE_UPDATE.md` xac nhan Content API da active sau Phase B.
- Content API dung `ActiveProfileMiddleware`, khong tin `ProfileId` tu body request.

### Backend implementation thuc te

- Controller: `AISAM-BE/AISAM.API/Controllers/ContentController.cs`
- Service: `AISAM-BE/AISAM.Services/Service/ContentService.cs`
- Repository: `AISAM-BE/AISAM.Repositories/Repository/ContentRepository.cs`
- DTO:
  - `CreateContentRequest`
  - `ContentResponseDto`
- Enums:
  - `AdTypeEnum`: `TextOnly = 0`, `ImageText = 1`, `VideoText = 2`
  - `ContentStatusEnum`: `Draft = 0`, `PendingApproval = 1`, `Approved = 2`, `Rejected = 3`, `Published = 4`
- Response create: `GenericResponse<ContentResponseDto>`

### Hanh vi backend can frontend phai follow

- `POST /api/content` bat buoc co JWT.
- `POST /api/content` bat buoc co header `X-Profile-Id`.
- Backend lay `profileId` tu `X-Profile-Id`, khong lay tu body.
- Backend validate brand phai thuoc active profile.
- Neu co `productId`, backend validate product ton tai va thuoc dung brand da chon.
- Content moi luon duoc tao voi `status = Draft`.
- CRUD content thu cong khong tru quota AI.

## 4. Pham vi frontend

### Trong pham vi

- Nut/route tao content draft thu cong.
- Form tao content co chon brand, product tuy chon, content type va noi dung.
- Load brand theo active profile de lam option bat buoc.
- Load product theo brand da chon de lam option tuy chon.
- Validate form truoc khi submit.
- Goi `POST /api/content` va xu ly loading/success/error.
- Sau khi tao thanh cong, dieu huong den chi tiet content hoac content library.
- Invalidate/refetch danh sach content cua active profile.

### Ngoai pham vi

- Quan ly toan bo thu vien content: thuoc `US-20`.
- Clone content: thuoc `US-21`.
- Sinh draft bang AI: thuoc `US-22`.
- Improve content bang AI: thuoc `US-23`.
- Approval workflow nang cao: thuoc `US-58`.
- Upload media qua storage service: thuoc `US-61`.
- Publish/schedule content: thuoc `US-34`, `US-40`, `US-41`.

## 5. API contract can dung

### Create content draft

`POST /api/content`

Headers:

```http
Authorization: Bearer <accessToken>
X-Profile-Id: <activeProfileId>
Content-Type: application/json
```

Body:

```json
{
  "brandId": "brand-guid",
  "productId": "product-guid-or-null",
  "adType": 0,
  "title": "Bai post khai truong thang 6",
  "textContent": "Noi dung caption hoac ban nhap quang cao...",
  "imageUrl": "https://example.com/image.png",
  "videoUrl": null,
  "styleDescription": "Ngan gon, than thien, nhan vao uu dai",
  "contextDescription": "Chien dich khai truong chi nhanh moi",
  "representativeCharacter": "Nhan vat thuong hieu neu co"
}
```

Field request:

| Field | Bat buoc | Ghi chu frontend |
| --- | --- | --- |
| `brandId` | Co | Lay tu brand thuoc active profile. |
| `productId` | Khong | Chi cho chon product thuoc brand da chon. |
| `adType` | Co | Enum number: `0 TextOnly`, `1 ImageText`, `2 VideoText`. |
| `title` | Khong | Ten noi bo de de tim kiem. |
| `textContent` | Co | Noi dung draft chinh. |
| `imageUrl` | Khong | Chi hien khi `ImageText` hoac khi user co URL anh. |
| `videoUrl` | Khong | Chi hien khi `VideoText` hoac khi user co URL video. |
| `styleDescription` | Khong | Mo ta phong cach viet. |
| `contextDescription` | Khong | Ngu canh chien dich. |
| `representativeCharacter` | Khong | Nhan vat dai dien thuong hieu neu user muon ghi thu cong. |

### Success response

HTTP: backend tra theo `result.StatusCode`; create success hien tai co `statusCode = 200` trong body.

```json
{
  "success": true,
  "message": "Content created successfully.",
  "statusCode": 200,
  "data": {
    "id": "content-guid",
    "profileId": "active-profile-guid",
    "brandId": "brand-guid",
    "brandName": "AISAM Coffee",
    "productId": "product-guid-or-null",
    "adType": 0,
    "title": "Bai post khai truong thang 6",
    "textContent": "Noi dung caption hoac ban nhap quang cao...",
    "imageUrl": null,
    "videoUrl": null,
    "styleDescription": "Ngan gon, than thien, nhan vao uu dai",
    "contextDescription": "Chien dich khai truong chi nhanh moi",
    "representativeCharacter": "Nhan vat thuong hieu neu co",
    "status": 0,
    "createdAt": "2026-06-03T00:00:00Z",
    "updatedAt": "2026-06-03T00:00:00Z"
  },
  "error": null
}
```

### Error response can xu ly

| HTTP status | Message/backend behavior | FE xu ly |
| --- | --- | --- |
| `401` | `Authentication is required.` hoac `Missing or invalid X-Profile-Id header.` | Refresh token neu co; neu khong thi ve login hoac yeu cau chon profile. |
| `403` | `You are not allowed to use this profile.` | Xoa active profile khong hop le va yeu cau chon lai profile. |
| `404` | `Profile not found.`, `Brand not found.`, `Product not found.` | Hien error va reload lai profile/brand/product options. |
| `400` | `Product does not belong to the selected brand.` | Clear product selection va yeu cau chon lai. |
| `500` | Loi he thong | Hien retry/error banner. |

## 6. UI/UX spec

### Route de xuat

- `/content/new`
- Hoac nut `Create content` trong `/content` mo page/dialog tao moi.

### Thanh phan can co

- Active profile indicator.
- Brand select bat buoc.
- Product select tuy chon, bi disable den khi da chon brand.
- Content type segmented control:
  - TextOnly
  - ImageText
  - VideoText
- Title input.
- Text content textarea lon.
- Image URL input khi chon `ImageText`.
- Video URL input khi chon `VideoText`.
- Style description textarea.
- Context description textarea.
- Representative character input/textarea.
- Primary action `Save draft`.
- Secondary action `Cancel`.

### Empty/blocking states

- Chua dang nhap: theo auth guard chung.
- Chua co active profile: hien yeu cau chon hoac tao business profile.
- Active profile chua co brand: hien CTA sang man hinh brand de tao brand truoc.
- Brand da chon chua co product: product select hien empty state nhung van cho tao content khong co product.

## 7. Validation frontend

- `activeProfileId` bat buoc.
- `brandId` bat buoc.
- `adType` bat buoc va chi nhan `0`, `1`, `2`.
- `textContent` bat buoc, khong chi gom khoang trang.
- `productId` neu co phai thuoc brand dang chon trong UI state.
- `imageUrl` nen validate URL format neu co gia tri.
- `videoUrl` nen validate URL format neu co gia tri.
- Khi doi brand:
  - clear `productId` cu
  - load lai product theo brand moi
- Khong cho user nhap `profileId` trong form; profile lay tu active profile store.

## 8. Data flow frontend

1. User vao `/content/new`.
2. Frontend kiem tra auth va active profile.
3. Neu chua co active profile, khong render form tao content.
4. Frontend load brand list theo active profile.
5. User chon brand.
6. Frontend load product list theo brand da chon.
7. User nhap title, text content, ad type va cac field optional.
8. User bam `Save draft`.
9. Frontend validate form.
10. Frontend goi `POST /api/content` voi header `X-Profile-Id = activeProfileId`.
11. Backend tao content `Draft`.
12. Frontend hien toast thanh cong, invalidate content list cache va dieu huong den detail/list.

## 9. State can xu ly

### Loading state

- loading brand options
- loading product options theo brand
- loading submit create

### Success state

- tao draft thanh cong
- form reset hoac dieu huong sang detail/list
- content library refetch de thay draft moi

### Error state

- chua co active profile
- active profile khong hop le
- chua co brand trong profile
- brand/product khong ton tai hoac khong dung ownership
- product khong thuoc brand
- token het han
- loi he thong

## 10. Auth/profile/session impact

- Story nay bat buoc dung fetcher chung co `Authorization`.
- Fetcher chung phai gan `X-Profile-Id` cho `/api/content`.
- Khi active profile thay doi trong luc dang tao content, frontend nen canh bao va reset form de tranh tao nham profile.
- Content create khong gui `profileId` trong body.

## 11. Dieu huong sau thao tac

- Sau create thanh cong nen dieu huong den `/content/{contentId}` neu detail page da co.
- Neu detail page chua co, dieu huong ve `/content` va highlight draft vua tao.
- Nut cancel quay ve `/content` hoac trang truoc do, khong submit.

## 12. Acceptance criteria

### AC-01

Frontend chi hien form tao content khi user da dang nhap va co active profile hop le.

### AC-02

Frontend load brand options theo active profile va bat buoc user chon brand truoc khi save.

### AC-03

Frontend load product options theo brand da chon, va khong cho giu product cu khi user doi brand.

### AC-04

Frontend submit `POST /api/content` voi header `Authorization` va `X-Profile-Id` dung active profile.

### AC-05

Request body khong chua `profileId`, co `brandId`, `adType`, `textContent` va cac field optional dung contract.

### AC-06

Khi tao thanh cong, frontend nhan `ContentResponseDto` co `status = Draft` va cap nhat UI/cache.

### AC-07

Neu backend tra `Brand not found`, `Product not found` hoac `Product does not belong to the selected brand`, frontend hien loi ro va cho user chon lai brand/product.

### AC-08

Neu chua co brand trong active profile, frontend khong cho save draft va huong user tao brand truoc.

## 13. Test cases frontend

### FE-01

Khong co active profile thi `/content/new` hien state yeu cau chon profile va khong goi `POST /api/content`.

### FE-02

### FE-03

Chon brand thi load product options theo brand do.

### FE-04

Doi brand thi clear product da chon truoc do.

### FE-05

### FE-06

Submit hop le goi `POST /api/content` voi `X-Profile-Id` va body dung contract.

### FE-07

Create thanh cong thi invalidate content list cache va dieu huong dung.

### FE-08

Backend tra `Product does not belong to the selected brand` thi clear product va hien loi.

### FE-09

Backend tra `Missing or invalid X-Profile-Id header` thi hien loi active profile/session phu hop.

### FE-10

Ad type `ImageText` hien image URL field; `VideoText` hien video URL field; `TextOnly` khong bat buoc media URL.

## 14. Ghi chu implementation

- `AdTypeEnum` va `ContentStatusEnum` la number enum trong backend; frontend nen map label ro rang nhung gui number.
- `ImageUrl` trong backend duoc luu dang JSON array string neu gui mot URL thuong; frontend chi can gui URL string, response co the nhan ve chuoi JSON array.
- `TextOnly` van co the de `imageUrl`/`videoUrl` null.
- Backend hien tai chua co validation attribute trong `CreateContentRequest`, nen frontend validation can chat de tranh tao draft rong.
- Content tao thu cong khong goi AI va khong consume prompt quota.
- Neu UI can upload file media, tach sang `US-61` vi backend storage chua active cho story nay.
