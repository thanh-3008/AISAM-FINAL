# US-31 - Xem danh sách page có thể đăng bài

## 1. User Story

**Là** người dùng,
**tôi muốn** xem các target/page khả dụng của tài khoản Facebook đã kết nối để chọn nội dung cần kết nối với brand,
**để** có thể liên kết đúng page kinh doanh với brand tương ứng trước khi publish.

---

## 2. Mục tiêu

Cung cấp giao diện hiển thị danh sách Facebook pages mà user đang quản lý (thông qua tài khoản Facebook đã kết nối OAuth). Cho phép user xem trước thông tin page (tên, category, avatar) và phân biệt page nào đã được liên kết với brand nào, page nào còn trống. Feature này là bước "xem và chọn" trước khi thực hiện hành động link-targets (US-29).

---

## 3. Phạm vi

### Trong phạm vi

- Xem danh sách pages có sẵn của một tài khoản Facebook đã kết nối (`GET /api/social/accounts/{socialAccountId}/available-targets`).
- Mỗi page item hiển thị:
  - Avatar page (nếu có, từ `profilePictureUrl`).
  - Tên page.
  - Category (ví dụ: "Business", "Shopping", "Entertainment").
  - Trạng thái: **Available** (chưa liên kết) hoặc **Linked** (đã liên kết với brand cụ thể).
- Phân biệt page đã linked vs available dựa trên `GET /api/social/accounts/{socialAccountId}/linked-targets`.
- Lọc/tìm kiếm page theo tên trong dialog.
- Loading skeleton khi fetch available targets.
- Error state khi API available-targets fail.
- Empty state khi tài khoản Facebook không quản lý page nào.
- Refresh danh sách available targets (nút reload).
- Preview thông tin page trước khi chọn.

### Ngoài phạm vi

- Hành động link page với brand (POST link-targets): xem US-29.
- Hành động unlink page (DELETE integration): xem US-29.
- Kết nối Facebook account mới: xem US-29.
- Xem Instagram/TikTok available targets: post-MVP.
- Facebook Ads page management.
- Real-time page Insights từ Facebook Graph.

---

## 4. Actor

- **Chính:** Người dùng đã đăng nhập, đã kết nối ít nhất một tài khoản Facebook (US-29), có ít nhất một brand (US-04/US-05).
- **Phụ:** User Web App (frontend), Backend API (SocialAccountsController, SocialService, FacebookProvider), Facebook Graph API.

---

## 5. Tiền điều kiện

- Người dùng đã đăng nhập và có JWT access token hợp lệ.
- Người dùng đã chọn active profile (`X-Profile-Id` header hợp lệ).
- Người dùng đã kết nối ít nhất một tài khoản Facebook (US-29).
- Người dùng có ít nhất một brand để liên kết page.
- Facebook user access token còn hạn (nếu token expired, API trả lỗi).
- Backend được cấu hình FacebookSettings.

---

## 6. Luồng nghiệp vụ chính

### 6.1 Xem danh sách pages khả dụng

1. Người dùng đang ở màn hình Social Connections (`/social`).
2. Trên account card Facebook, người dùng nhấn **"Manage Pages"**.
3. Frontend mở dialog **"Manage Facebook Pages"**.
4. Frontend gọi song song:
   - `GET /api/social/accounts/{socialAccountId}/available-targets` — lấy danh sách pages từ Facebook Graph.
   - `GET /api/social/accounts/{socialAccountId}/linked-targets` — lấy danh sách pages đã liên kết.
5. Backend xử lý:
   - Kiểm tra ownership của social account.
   - Gọi Facebook Graph API `/{userId}/accounts?fields=id,name,category,access_token` để lấy pages.
   - Trả về `AvailableTargetDto[]`.
6. Frontend merge 2 danh sách:
   - Page nào có trong linked-targets → đánh dấu **"Linked to {brandName}"**.
   - Page nào chưa có → đánh dấu **"Available"**.
7. Hiển thị danh sách pages dưới dạng list/grid với avatar, tên, category, status badge.
8. Người dùng xem thông tin và chọn pages để link.

### 6.2 Tìm kiếm/lọc page

1. Dialog có search bar phía trên danh sách.
2. Người dùng nhập từ khoá → lọc local theo tên page.
3. Debounce 300ms, không gọi API lại.

### 6.3 Xem preview page detail

1. Người dùng hover hoặc click vào page item.
2. Tooltip hoặc expanded row hiển thị:
   - Avatar lớn hơn.
   - Tên page.
   - Category.
   - Trạng thái linked/unlinked.
   - Brand đã liên kết (nếu có).

### 6.4 Refresh available targets

1. Dialog có nút **"Refresh"** (icon reload).
2. Người dùng nhấn Refresh → gọi lại `GET /api/social/accounts/{socialAccountId}/available-targets`.
3. Danh sách cập nhật.
4. Toast "Đã làm mới danh sách pages."

## 7. Luồng ngoại lệ

| Mã | Trường hợp | Kết quả mong đợi |
| --- | --- | --- |
| EX-01 | API available-targets trả về lỗi mạng/server | Error state trong dialog: icon + "Không thể tải danh sách pages." + nút "Retry". |
| EX-02 | API linked-targets trả về lỗi | Vẫn hiển thị available targets, nhưng không phân biệt được linked vs available. Toast cảnh báo. |
| EX-03 | Token Facebook hết hạn (expired) | API trả lỗi → dialog hiển thị "Token đã hết hạn. Vui lòng reconnect." + nút "Reconnect" (dẫn đến US-29 flow). |
| EX-04 | Không có page nào (user không quản lý page nào trên Facebook) | Empty state: icon + "Tài khoản Facebook này không quản lý page nào." |
| EX-05 | Tất cả pages đã liên kết hết | Hiển thị danh sách với tất cả đều "Linked" + thông báo "Tất cả pages đã được liên kết." |
| EX-06 | Token bị thu hồi (revoked) | API trả lỗi → dialog hiển thị "Quyền truy cập đã bị thu hồi." + nút "Reconnect". |

## 8. Quy tắc nghiệp vụ

| Mã | Quy tắc |
| --- | --- |
| BR-01 | `available-targets` luôn fetch từ Facebook Graph real-time, không cache trong BE. |
| BR-02 | `linked-targets` được lấy từ DB (`SocialIntegration` table) qua BE. |
| BR-03 | Một page chỉ được link vào **một brand duy nhất** tại một thời điểm (BE đã enforce trong `LinkSelectedTargetsForAccountAsync`). |
| BR-04 | FE không được tự động link page; link-targets chỉ xảy ra khi user nhấn "Link Selected" (US-29). |
| BR-05 | Page đã linked với brand A có thể được unlink và relink với brand B. |
| BR-06 | `available-targets` chỉ hiển thị pages **chưa bị soft-delete** trên Facebook (BE filter `IsDeleted`). |
| BR-07 | `ProfilePictureUrl` trong `AvailableTargetDto` hiện tại chưa được FE gửi từ BE (`null`), nhưng BE Graph API đã request field `id,name,category,access_token` (không có picture). Nếu cần avatar, cần sửa BE gọi thêm field `picture`. |

## 9. API Contracts

### 9.1 Get Available Targets

```
GET /api/social/accounts/{socialAccountId}/available-targets
```

#### Headers
```http
Authorization: Bearer <access-token>
X-Profile-Id: <owned-profile-guid>
```

#### Path Parameters
| Param | Type | Description |
| --- | --- | --- |
| socialAccountId | Guid | ID của social account đã connect. |

#### Response (200 OK)
```json
{
  "success": true,
  "statusCode": 200,
  "data": [
    {
      "providerTargetId": "123456789012345",
      "name": "My Business Page",
      "type": "page",
      "category": "Business",
      "profilePictureUrl": null,
      "isActive": true
    },
    {
      "providerTargetId": "987654321098765",
      "name": "Shop Page",
      "type": "page",
      "category": "Shopping",
      "profilePictureUrl": null,
      "isActive": true
    }
  ]
}
```

#### Response (200 - empty)
```json
{
  "success": true,
  "statusCode": 200,
  "data": []
}
```

#### Response (404 - account not found)
```json
{
  "success": false,
  "statusCode": 404,
  "message": "Social account not found."
}
```

### 9.2 Get Linked Targets (để đối chiếu)

```
GET /api/social/accounts/{socialAccountId}/linked-targets
```

#### Response (200 OK)
```json
{
  "success": true,
  "statusCode": 200,
  "data": [
    {
      "id": "integration-guid-1",
      "providerTargetId": "123456789012345",
      "name": "123456789012345",
      "type": "page",
      "category": null,
      "profilePictureUrl": null,
      "isActive": true
    }
  ]
}
```

> **Note:** Hiện tại `name` trong `SocialTargetDto` đang lấy từ `ExternalId` (page ID), không phải tên page thật. Đây là BE limitation cần fix riêng nếu muốn hiển thị tên page đã linked. Tuy nhiên, với available-targets, tên page đã có đầy đủ từ Facebook Graph API.

## 12. Acceptance Criteria

### AC-01 - Mở dialog Manage Pages

**Given** account card Facebook trên màn hình Social Connections
**When** nhấn "Manage Pages"
**Then** dialog "Manage Facebook Pages" mở ra
**And** `GET /api/social/accounts/{id}/available-targets` và `GET /api/social/accounts/{id}/linked-targets` được gọi song song.

### AC-02 - Hiển thị danh sách available pages

**Given** Facebook account có pages
**When** dialog mở
**Then** danh sách pages hiển thị với avatar (hoặc placeholder), tên, category, status badge.

### AC-03 - Phân biệt linked vs available

**Given** page đã liên kết với brand
**When** render page item
**Then** badge "Linked to {brandName}" (xanh dương) + checkbox disabled.
**Given** page chưa liên kết
**Then** badge "Available" (xanh lá) + checkbox enabled.

### AC-04 - Search pages

**Given** dialog có danh sách pages
**When** nhập từ khoá vào search bar
**Then** filter local theo tên page (case-insensitive, debounce 300ms).

### AC-05 - Loading state

**Given** đang fetch available targets
**When** dialog mở
**Then** skeleton loading items hiển thị.

### AC-06 - Error state

**Given** available-targets API fail
**When** render dialog
**Then** error state + nút Retry
**When** nhấn Retry
**Then** gọi lại API.

### AC-07 - Empty state

**Given** Facebook account không quản lý page nào
**When** dialog mở
**Then** empty state hiển thị.

### AC-08 - Token expired

**Given** Facebook token hết hạn
**When** dialog mở hoặc click Refresh
**Then** token expired state + nút Reconnect.

### AC-09 - Refresh available targets

**Given** dialog đang hiển thị danh sách pages
**When** nhấn nút Refresh
**Then** gọi lại `GET /api/social/accounts/{id}/available-targets`
**And** cập nhật danh sách.

### AC-10 - Bottom bar: brand selection

**Given** có ít nhất một page available được chọn
**When** render bottom bar
**Then** hiển thị "Selected: N pages" + brand dropdown + [Link Selected] enabled.
**Given** chưa chọn page nào hoặc chưa chọn brand
**Then** [Link Selected] disabled.

**use-merged-available-pages.ts:**

```typescript
export function useMergedAvailablePages(socialAccountId: string) {
  const available = useAvailableTargets(socialAccountId);
  const linked = useLinkedTargets(socialAccountId);

  const mergedPages = useMemo<AvailablePageViewModel[]>(() => {
    if (!available.data) return [];

    const linkedSet = new Set(
      (linked.data ?? []).map((lt) => lt.providerTargetId)
    );

    return available.data.map((page) => ({
      ...page,
      isLinked: linkedSet.has(page.providerTargetId),
      linkedBrandName: null,    // cần enrichment từ brand API nếu có
      linkedIntegrationId: null,
    }));
  }, [available.data, linked.data]);

  return {
    pages: mergedPages,
    isLoading: available.isLoading || linked.isLoading,
    isError: available.isError,
    refetch: () => {
      available.refetch();
      linked.refetch();
    },
  };
}
```

```tsx
        <AvatarImage src={page.profilePictureUrl ?? undefined} />
        <AvatarFallback>
          <FileTextIcon className="h-5 w-5 text-muted-foreground" />
        </AvatarFallback>
      </Avatar>

      <div className="min-w-0 flex-1">
        <p className="truncate text-sm font-medium">{page.name}</p>
        <p className="truncate text-xs text-muted-foreground">
          {page.category ?? "Page"}
        </p>
      </div>

      {isDisabled ? (
        <Badge variant="secondary" className="shrink-0">
          Linked {page.linkedBrandName ? `to ${page.linkedBrandName}` : ""}
        </Badge>
      ) : (
        <Badge variant="success" className="shrink-0">
          Available
        </Badge>
      )}

      {!isDisabled && (
        <Checkbox
          checked={selected}
          onCheckedChange={(checked) => onToggle(checked as boolean)}
        />
      )}
    </div>
  );
}
```
