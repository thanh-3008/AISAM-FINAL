# US-14 Frontend Detail - Cap nhat business profile

## 1. User story

La nguoi dung da co business profile, toi muon cap nhat thong tin profile de du lieu kinh doanh cua minh luon chinh xac.

## 2. Muc tieu frontend

- Cung cap form edit profile theo contract backend hien tai.
- Goi dung endpoint update profile.
- Khong mo rong sang upload file avatar khi backend MVP chua support.

## 3. Can cu backend va scope hien tai

### Requirement lien quan

- `requirement.md` muc `6.3` yeu cau sua profile.

### Backend plan lien quan

- `BACKEND_CODE_PLAN.md` Phase 4 da active CRUD profile.

### Backend implementation thuc te

- Endpoint detail: `GET /api/profiles/{id}`
- Endpoint update: `PUT /api/profiles/{id}`
- Authorization: bat buoc
- Content-Type update: `multipart/form-data`
- Response update: `GenericResponse<ProfileResponseDto>`

### Hanh vi backend can frontend phai follow

- Backend chi cho update profile do user so huu
- Neu profile khong ton tai hoac khong thuoc user:
  - `404 Profile not found`
- Request update fields deu optional:
  - `name`
  - `profileType`
  - `companyName`
  - `bio`
  - `avatarUrl`
  - `avatarFile` co trong DTO nhung bi reject trong MVP
- Neu gui `avatarFile`:
  - loi `Avatar file upload is not enabled in the current MVP backend. Use AvatarUrl instead.`

## 4. Pham vi frontend

### Trong pham vi

- Trang `/profiles/[id]/edit`
- Fetch chi tiet profile
- Form edit profile
- Submit `multipart/form-data`
- Dong bo profile list/detail/active profile sau update

### Ngoai pham vi

- Upload avatar file
- Team permission shared edit

## 5. API contract can dung

### Detail request

`GET /api/profiles/{id}`

### Update request

`PUT /api/profiles/{id}`

Header:

```http
Authorization: Bearer <accessToken>
Content-Type: multipart/form-data
```

FormData fields frontend nen gui khi co gia tri:

- `name`
- `profileType`
- `companyName`
- `bio`
- `avatarUrl`

### Success response

HTTP: `200 OK`

```json
{
  "success": true,
  "message": "Profile updated successfully",
  "statusCode": 200,
  "data": {
    "id": "guid",
    "userId": "guid",
    "name": "Updated Business",
    "profileType": 1,
    "subscriptionId": null,
    "companyName": "Updated Company",
    "bio": "Updated bio",
    "avatarUrl": "https://example.com/avatar.png",
    "status": 1,
    "createdAt": "2026-06-01T00:00:00Z",
    "updatedAt": "2026-06-02T00:00:00Z",
    "isOwner": true,
    "memberRole": null
  },
  "error": null
}
```

### Error response

- `404` khi profile khong ton tai/khong thuoc user
- `401` neu chua dang nhap
- `500` neu loi he thong

## 6. UI/UX spec

### Route

### Form fields

- `name`
- `profileType`

### Khong hien thi

- `avatarFile`

### CTA

## 7. Validation frontend

- `name` khong nen de rong neu user dang sua field nay
- `profileType` phai la mot gia tri hop le trong:
  - `Free`
  - `Basic`
  - `Pro`
- `avatarUrl` neu co thi co the validate URL format

## 8. Data flow frontend

1. User vao `/profiles/[id]/edit`
2. Frontend goi `GET /api/profiles/{id}`
3. Prefill form
4. User chinh sua
5. Frontend submit `PUT /api/profiles/{id}` bang `FormData`
6. Neu thanh cong:
   - cap nhat query cache/list/detail
   - neu dang la active profile thi cap nhat `profile-store`
   - redirect ve `/profiles` hoac `/profiles/[id]`

## 9. State can xu ly

### Loading state

- loading detail ban dau
- loading save changes

### Success state

- toast/banner update thanh cong

### Error state

- `404 profile not found`
- generic error
- avatar file unsupported neu frontend lỡ gui sai

## 10. Auth/session impact

- Khong doi auth session
- Co tac dong den profile state va cache

## 11. Dieu huong sau cap nhat

- Uu tien redirect `/profiles`
- Neu frontend co page detail profile on dinh thi co the redirect `/profiles/[id]`

## 12. Acceptance criteria

### AC-01

Frontend fetch duoc profile detail va prefill form edit.

### AC-02

Frontend submit update bang `multipart/form-data`.

### AC-03

Sau khi update thanh cong, frontend dong bo lai du lieu profile trong list/detail/active profile.

### AC-04

Frontend khong expose avatar file upload trong MVP.

### AC-05

Khi backend tra `404 Profile not found`, frontend hien error state phu hop.

## 13. Test cases frontend

### FE-01

Trang edit fetch profile detail thanh cong va prefill form.

### FE-02

Submit update thanh cong cap nhat cache va active profile.

### FE-03

`404` hien error state.

### FE-04

Khong render `avatarFile` input trong form.

## 14. Ghi chu implementation

- Update DTO backend la partial, nhung frontend page edit thong thuong van submit day du cac field dang hien thi de de quan ly state.
- Enum profile/status co the la so, frontend can map an toan.
- Story nay chi noi ve cap nhat; xoa/restore profile co the tach thanh story rieng neu can UI chi tiet hon.
