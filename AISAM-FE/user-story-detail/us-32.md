# US-32 - Liên kết page với brand

## 1. User Story

**Là** người dùng,
**tôi muốn** liên kết Facebook page đã chọn với brand tương ứng,
**để** có thể sử dụng page đó làm kênh đăng bài cho brand.

---

## 2. Mục tiêu

Cung cấp action liên kết một hoặc nhiều Facebook pages với một brand. Khi user chọn pages từ danh sách available (US-31) và chọn brand, hệ thống gọi BE để tạo `SocialIntegration` records, lưu page access token (đã mã hóa), và trả về account đã cập nhật. FE hiển thị kết quả ngay lập tức: page chuyển từ "Available" sang "Linked to {brand}" trong dialog và account card.

---

## 3. Phạm vi

### Trong phạm vi

- Chọn brand từ dropdown để liên kết với pages đã chọn.
- Gọi `POST /api/social/accounts/{socialAccountId}/link-targets` với danh sách `providerTargetIds` và `brandId`.
- Loading state trên nút "Link Selected" (spinner + disabled) trong thời gian API xử lý.
- Hiển thị toast thành công khi link hoàn tất: "Đã liên kết N pages với {brandName}."
- Hiển thị toast lỗi cụ thể khi link thất bại.
- Xử lý validation errors từ BE:
  - Brand không hợp lệ / không thuộc profile.
  - Page ID không có trong available targets.
  - Token Facebook hết hạn.
- Xử lý partial success (một số page link được, một số không).
- Cập nhật UI ngay sau khi link thành công:
  - Dialog cập nhật trạng thái page từ "Available" → "Linked to {brand}".
  - Account card cập nhật linked pages count + list.
  - Section "Integrations by Brand" cập nhật (nếu đang hiển thị).
- Re-fetch linked-targets sau khi link thành công để đồng bộ.
- Confirm trước khi link nếu selected pages đã từng linked với brand khác trước đó (re-link).

### Ngoài phạm vi

- Xem danh sách available pages: xem US-31.
- Xem danh sách pages đã linked: xem US-30.
- Unlink page / xóa integration: xem US-29.
- Disconnect toàn bộ account: xem US-29.
- Kết nối Facebook account mới: xem US-29.

---

## 4. Actor

- **Chính:** Người dùng đã đăng nhập, đã kết nối Facebook account (US-29), đang ở dialog Manage Pages (US-31).
- **Phụ:** Backend API (SocialAccountsController, SocialService, FacebookProvider), Facebook Graph API.

---

## 5. Tiền điều kiện

- Người dùng đã đăng nhập và có JWT hợp lệ.
- Người dùng đã chọn active profile (`X-Profile-Id`).
- Người dùng đã kết nối ít nhất một Facebook account (US-29).
- Người dùng có ít nhất một brand (US-04/US-05).
- Facebook token còn hạn (nếu expired, link sẽ fail).
- Dialog Manage Pages (US-31) đang mở với ít nhất một page available được chọn.

---

## 6. Luồng nghiệp vụ chính

### 6.1 Liên kết pages với brand

1. Dialog Manage Pages (US-31) đang hiển thị danh sách available pages.
2. Người dùng chọn N pages (checkboxes) và chọn brand từ dropdown.
3. Bottom bar hiển thị: "Selected: N pages" + brand dropdown + **[Link Selected]** enabled.
4. Người dùng nhấn **"Link Selected"**.
5. Frontend gọi `POST /api/social/accounts/{socialAccountId}/link-targets` với body:
   ```json
   {
     "provider": "facebook",
     "providerTargetIds": ["page_id_1", "page_id_2"],
     "brandId": "brand-guid"
   }
   ```
6. Nút chuyển sang loading state: spinner + "Linking..." + disabled.
7. Backend xử lý:
   - Validate account ownership.
   - Validate brand ownership (brand phải thuộc profile).
   - Decrypt user access token.
   - Gọi Facebook Graph API `/{userId}/accounts` để lấy danh sách pages hiện tại.
   - Kiểm tra từng selected page ID có trong danh sách available.
   - Lấy page access token cho từng page.
   - Tạo hoặc cập nhật `SocialIntegration` records (page token được mã hoá).
   - Trả về `SocialAccountDto` đã cập nhật với targets mới.
8. Frontend nhận response thành công:
   - Toast: "Đã liên kết 2 pages với My Brand."
   - Dialog cập nhật: pages chuyển từ "Available" → "Linked to My Brand".
   - Account card cập nhật số lượng linked pages.
   - Re-fetch linked-targets để đồng bộ trạng thái.
9. FE đóng loading và trả lại trạng thái bình thường.

### 6.2 Xử lý re-link (page đã từng linked với brand khác)

1. Nếu page đã từng linked với brand khác trước đó (soft-delete integration cũ tồn tại), BE sẽ:
   - Khôi phục `SocialIntegration` (set `IsDeleted = false`).
   - Cập nhật `BrandId` mới.
   - Mã hoá và lưu page token mới.
2. FE không cần xử lý đặc biệt; BE tự động handle.
3. Tuy nhiên nếu page hiện đang linked active với brand khác, checkbox sẽ disabled (US-31 handle).
   - Trường hợp re-link chỉ xảy ra với pages đã từng linked nhưng đã unlink trước đó.

### 6.3 Refresh danh sách sau khi link

1. Sau khi link thành công, FE gọi lại `GET /api/social/accounts/{socialAccountId}/linked-targets`.
2. Cập nhật danh sách linked pages trong dialog và account card.
3. Nếu section "Integrations by Brand" (US-30) đang hiển thị, cũng cần refresh để cập nhật brand-page mapping mới.

## 7. Luồng ngoại lệ

| Mã | Trường hợp | Kết quả mong đợi |
| --- | --- | --- |
| EX-01 | API trả về lỗi mạng / server error | Toast lỗi: "Không thể liên kết pages. Vui lòng thử lại." + nút "Link Selected" trở lại enabled. |
| EX-02 | Brand không hợp lệ / không thuộc profile | BE trả `400 Bad Request` với message "Brand not found." → Toast lỗi: "Brand không hợp lệ." |
| EX-03 | Một hoặc nhiều page ID không có trong available targets | BE trả `400 Bad Request` với message "Selected target is not available for this account." → Toast lỗi cụ thể. |
| EX-04 | Token Facebook hết hạn / bị thu hồi | BE gọi Facebook Graph API fail → throw exception → BE trả `400`. FE hiển thị toast: "Token Facebook đã hết hạn. Vui lòng reconnect." + đóng dialog. |
| EX-05 | Thiếu page token cho một số selected pages | BE trả `400` với message "Missing page token for target {id}." → Toast lỗi: "Không thể lấy quyền truy cập cho page {name}." |
| EX-06 | User không chọn brand trước khi link | Nút "Link Selected" disabled cho đến khi chọn brand. |
| EX-07 | User không chọn page nào | Nút "Link Selected" disabled. |
| EX-08 | Chọn quá nhiều pages cùng lúc | Hiện tại BE support số lượng bất kỳ; nếu có giới hạn sau, FE cần validate `maxSelectedPages` từ config. |

## 8. Quy tắc nghiệp vụ

| Mã | Quy tắc |
| --- | --- |
| BR-01 | Một page chỉ có thể linked với **một brand duy nhất** tại một thời điểm (BE enforce). |
| BR-02 | Page token được BE mã hoá bằng ASP.NET Core Data Protection trước khi lưu; FE không bao giờ thấy token. |
| BR-03 | `ProfileId` trong request body bị BE ignore; BE luôn dùng `X-Profile-Id` từ header để tránh spoofing. |
| BR-04 | Link operation là **atomic per page**: một page fail không ảnh hưởng các page khác trong cùng request? (Hiện tại BE throw exception ngay khi gặp lỗi đầu tiên → toàn bộ request fail. Cần lưu ý nếu sau này muốn partial success.) |
| BR-05 | Không thể link page nếu Facebook account không còn active (token expired / revoked). |
| BR-06 | Re-link (page đã từng linked với brand khác, đã unlink) được BE handle tự động; FE không cần UI riêng. |

## 9. API Contract

### 9.1 Link Targets

```
POST /api/social/accounts/{socialAccountId}/link-targets
```

#### Headers
```http
Authorization: Bearer <access-token>
X-Profile-Id: <owned-profile-guid>
```

#### Path Parameters
| Param | Type | Description |
| --- | --- | --- |
| socialAccountId | Guid | ID của social account đã connect. |

#### Request Body
```json
{
  "profileId": "00000000-0000-0000-0000-000000000000",
  "provider": "facebook",
  "providerTargetIds": ["123456789012345", "987654321098765"],
  "brandId": "brand-guid-here"
}
```

> **Note:** `profileId` trong body bị BE ignore; BE dùng `X-Profile-Id` từ header. FE có thể gửi `Guid.Empty` hoặc bỏ qua.

#### Response (200 OK)
```json
{
  "success": true,
  "statusCode": 200,
  "data": {
    "id": "account-guid",
    "profileId": "profile-guid",
    "provider": "facebook",
    "providerUserId": "123456789",
    "isActive": true,
    "expiresAt": "2026-07-03T12:00:00Z",
    "createdAt": "2026-06-01T10:00:00Z",
    "updatedAt": "2026-06-03T12:00:00Z",
    "targets": [
      {
        "id": "integration-guid-1",
        "providerTargetId": "123456789012345",
        "name": "123456789012345",
        "type": "page",
        "category": null,
        "profilePictureUrl": null,
        "isActive": true
      },
      {
        "id": "integration-guid-2",
        "providerTargetId": "987654321098765",
        "name": "987654321098765",
        "type": "page",
        "category": null,
        "profilePictureUrl": null,
        "isActive": true
      }
    ]
  }
}
```

#### Response (400 - brand not found)
```json
{
  "success": false,
  "statusCode": 400,
  "message": "Brand not found."
}
```

#### Response (400 - target not available)
```json
{
  "success": false,
  "statusCode": 400,
  "message": "Selected target is not available for this account."
}
```

#### Response (400 - missing page token)
```json
{
  "success": false,
  "statusCode": 400,
  "message": "Missing page token for target 123456789012345."
}
```

#### Response (400 - only Facebook supported)
```json
{
  "success": false,
  "statusCode": 400,
  "message": "Only Facebook is supported in Phase C."
}
```

## 12. Acceptance Criteria

### AC-01 - Link pages thành công

**Given** dialog Manage Pages đang mở với 2 pages available được chọn + brand đã chọn
**When** nhấn "Link Selected"
**Then** `POST /api/social/accounts/{id}/link-targets` được gọi với `providerTargetIds` và `brandId`
**And** nút chuyển sang loading state "Linking..."
**And** nhận response thành công
**And** toast "Đã liên kết 2 pages với {brandName}."
**And** dialog cập nhật: 2 pages chuyển từ "Available" → "Linked to {brandName}"
**And** checkbox của 2 pages disabled
**And** re-fetch linked-targets được gọi
**And** account card cập nhật linked pages count.

### AC-02 - Nút Link Selected disabled khi chưa chọn brand

**Given** dialog đang mở với pages được chọn nhưng chưa chọn brand
**Then** nút "Link Selected" disabled
**When** chọn brand
**Then** nút enabled.

### AC-03 - Nút Link Selected disabled khi chưa chọn page

**Given** dialog đang mở với brand đã chọn nhưng chưa chọn page nào
**Then** nút "Link Selected" disabled
**When** chọn ít nhất một page
**Then** nút enabled.

### AC-04 - Link thất bại do brand invalid

**Given** dialog đang mở
**When** gọi API link-targets và BE trả "Brand not found."
**Then** toast lỗi "Brand không hợp lệ."
**And** nút trở lại enabled, selection giữ nguyên.

### AC-05 - Link thất bại do token expired

**Given** Facebook token đã hết hạn
**When** gọi API link-targets và BE trả lỗi
**Then** toast "Token Facebook đã hết hạn. Vui lòng reconnect."
**And** dialog đóng
**And** account card hiển thị trạng thái expired.

### AC-06 - Link thất bại do network error

**Given** network bị ngắt
**When** gọi API link-targets
**Then** toast "Không thể liên kết pages. Vui lòng thử lại."
**And** nút trở lại enabled, selection giữ nguyên.

### AC-07 - Loading state

**Given** đang gọi API link-targets
**Then** nút "Link Selected" hiển thị spinner + "Linking..."
**And** nút disabled
**And** Cancel button disabled (hoặc ẩn).

### AC-08 - Re-fetch linked targets sau khi link

**Given** link-targets thành công
**Then** `GET /api/social/accounts/{id}/linked-targets` được gọi lại
**And** dialog cập nhật linked status badges từ response.

### AC-09 - Link single page

**Given** chỉ chọn 1 page
**When** nhấn "Link Selected" thành công
**Then** toast "Đã liên kết 1 page với {brandName}."

### AC-10 - UI consistency

**Given** link thành công
**When** quay lại màn hình Social Connections (`/social`)
**Then** account card hiển thị đúng số lượng linked pages
**And** section Integrations by Brand hiển thị page mới dưới brand tương ứng.

  // ... existing methods
  linkTargets: (
    socialAccountId: string,
    payload: {
      provider: string;

    }

    apiRequest<SocialAccountDto>(

#### Hooks

**useLinkTargets:**

```typescript
import { useMutation, useQueryClient } from "@tanstack/react-query";
import { socialApi } from "@/features/social/api/social-api";

export function useLinkTargets(socialAccountId: string) {
  const queryClient = useQueryClient();

  return useMutation({
    mutationFn: (payload: {
      providerTargetIds: string[];
      brandId: string;
    }) =>
      socialApi.linkTargets(socialAccountId, {
        provider: "facebook",
        ...payload,
      }),

    onSuccess: () => {
      queryClient.invalidateQueries({
        queryKey: ["social-linked-targets", socialAccountId],
      });
      queryClient.invalidateQueries({
        queryKey: ["social-accounts"],
      });
      queryClient.invalidateQueries({
        queryKey: ["social-integrations"],
      });
    },
  });
}
```

#### Components

**LinkTargetsBar (bottom bar của dialog):**

```tsx
function LinkTargetsBar({
  selectedCount,
  brands,
  selectedBrandId,
  onBrandChange,
  onLink,
  isLoading,
}: {
  selectedCount: number;
  brands: { id: string; name: string }[];
  selectedBrandId: string;
  onBrandChange: (brandId: string) => void;
  onLink: () => void;
  isLoading: boolean;
}) {
  const canLink = selectedCount > 0 && selectedBrandId.length > 0 && !isLoading;

  return (
    <div className="flex items-center justify-between border-t pt-4">
      <span className="text-sm text-muted-foreground">
        Selected: {selectedCount} page{selectedCount !== 1 ? "s" : ""}
      </span>

      <div className="flex items-center gap-3">
        <Select
          value={selectedBrandId}
          onValueChange={onBrandChange}
          disabled={isLoading}
        >
          <SelectTrigger className="w-44">
            <SelectValue placeholder="Select brand" />
          </SelectTrigger>
          <SelectContent>
            {brands.map((brand) => (
              <SelectItem key={brand.id} value={brand.id}>
                {brand.name}
              </SelectItem>
            ))}
          </SelectContent>
        </Select>

        <Button onClick={onLink} disabled={!canLink}>
          {isLoading ? (
            <>
              <Spinner className="mr-2 h-4 w-4" />
              Linking...
            </>
          ) : (
            "Link Selected"
          )}
        </Button>
      </div>
    </div>
  );
}
```

**Tích hợp vào ManagePagesDialog:**

```tsx
function ManagePagesDialog({ socialAccount, open, onClose }) {
  const { pages, isLoading, isError, refetch } = useMergedAvailablePages(socialAccount.id);
  const linkMutation = useLinkTargets(socialAccount.id);
  const [selectedIds, setSelectedIds] = useState<Set<string>>(new Set());
  const [selectedBrandId, setSelectedBrandId] = useState<string>("");

  const handleLink = () => {
    if (selectedIds.size === 0 || !selectedBrandId) return;

    linkMutation.mutate(
      {
        providerTargetIds: Array.from(selectedIds),
        brandId: selectedBrandId,
      },
      {
        onSuccess: () => {
          toast.success(
            `Đã liên kết ${selectedIds.size} page${selectedIds.size !== 1 ? "s" : ""} với ${getBrandName(selectedBrandId)}.`
          );
          setSelectedIds(new Set());
          setSelectedBrandId("");
        },
        onError: (error) => {
          if (error.message?.includes("Token")) {
            toast.error("Token Facebook đã hết hạn. Vui lòng reconnect.");
            onClose();
          } else {
            toast.error(error.message ?? "Không thể liên kết pages.");
          }
        },
      }
    );
  };

  // ... render
}
```
