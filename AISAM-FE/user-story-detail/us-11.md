# US-11 Frontend Detail - Dang nhap bang Google

## 1. User story

La nguoi dung moi hoac da co tai khoan Google, toi muon dang nhap bang Google de vao AISAM nhanh hon.

## 2. Muc tieu frontend

- Tich hop diem vao Google login theo backend contract hien tai.
- Khi lay duoc `idToken` tu Google, gui token do len backend.
- Dong bo session frontend giong login email/password.

## 3. Can cu backend va scope hien tai

### Requirement lien quan

- `requirement.md` khong ghi chi tiet Google login, nhung module auth hien tai da ho tro va codebase backend dang active endpoint nay.

### Backend implementation thuc te

- Endpoint: `POST /api/Auth/google`
- Request DTO:
  - `idToken`
- Response: `GenericResponse<TokenResponse>`

### Hanh vi backend can frontend phai follow

- Backend validate `idToken` voi Google
- Neu user chua ton tai:
  - tu tao user moi
  - `isEmailVerified = true`
- Neu token invalid:
  - `401 Unauthorized`
- Login thanh cong tra session day du giong login thuong

## 4. Pham vi frontend

### Trong pham vi

- Nut `Continue with Google`
- Luong lay Google `idToken`
- Goi backend `/api/Auth/google`
- Luu session va redirect

### Ngoai pham vi

- Tu tuong toi uu UI Google SDK nang cao
- Quan ly Google account unlink: backend chua co trong nhom nay

## 5. API contract can dung

### Request

`POST /api/Auth/google`

```json
{
  "idToken": "google-id-token"
}
```

### Success response

HTTP: `200 OK`

```json
{
  "success": true,
  "message": "Google login successful",
  "statusCode": 200,
  "data": {
    "accessToken": "string",
    "refreshToken": "string",
    "expiresAt": "2026-06-02T00:00:00Z",
    "tokenType": "Bearer",
    "user": {
      "id": "guid",
      "email": "user@gmail.com",
      "fullName": "Google User",
      "role": 0,
      "isEmailVerified": true,
      "createdAt": "2026-06-02T00:00:00Z",
      "lastLoginAt": "2026-06-02T00:00:00Z"
    }
  },
  "error": null
}
```

### Error response

- `401` khi Google token invalid
- `500` khi loi he thong

## 6. UI/UX spec

### Vi tri

- Trang `/login`
- Co the dat o `/sign-up` neu muon

### CTA

- `Continue with Google`

### UX state

- pending trong luc doi Google SDK + backend
- error state neu token invalid hoac popup bi fail

## 7. Validation frontend

- Chi goi backend khi da lay duoc `idToken`
- Neu user dong popup hoac Google flow bi cancel, khong goi backend

## 8. Data flow frontend

1. User bam `Continue with Google`
2. Frontend goi Google login SDK/client
3. Nhan `idToken`
4. Goi `POST /api/Auth/google`
5. Neu thanh cong:
   - luu session
   - redirect `/profiles`
6. Neu that bai:
   - hien error state

## 9. State can xu ly

### Loading state

- Disable nut Google login trong luc xu ly

### Success state

- Session da luu

### Error state

- Google popup/SDK fail
- Backend tra `401`

## 10. Auth/session impact

- Giong login thuong:
  - luu access token
  - luu refresh token
  - luu expiresAt
  - luu user

## 11. Dieu huong sau dang nhap

- Redirect `/profiles`

## 12. Acceptance criteria

### AC-01

Frontend chi gui backend sau khi nhan du `idToken` tu Google.

### AC-02

Khi backend tra thanh cong, frontend luu session va redirect `/profiles`.

### AC-03

Khi backend tra `401`, frontend hien thong diep login that bai va khong luu session loi.

## 13. Test cases frontend

### FE-01

Google tra `idToken` hop le se goi backend `/api/Auth/google`.

### FE-02

Backend thanh cong se luu session va redirect `/profiles`.

### FE-03

Google flow bi cancel khong goi backend.

### FE-04

Backend `401` se hien error state.

## 14. Ghi chu implementation

- Story nay phu thuoc client-side Google library, nhung backend contract da ro.
- Backend tu tao user neu chua ton tai; frontend khong can tach `sign up with Google` va `login with Google`.
- Neu frontend scaffold hien tai chi co placeholder cho Google, story nay la diem de wire that.
