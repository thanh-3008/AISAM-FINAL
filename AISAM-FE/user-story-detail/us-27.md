# US-27 - Xem lịch sử hội thoại AI

## 1. User Story

**Là** người dùng,
**tôi muốn** xem danh sách và chi tiết các conversation để theo dõi quá trình làm việc với AI,
**để** có thể xem lại các ý tưởng đã brainstorm trước đó, tìm lại thông tin từ các cuộc trò chuyện cũ, và tiếp tục conversation nếu cần.

---

## 2. Mục tiêu

Cung cấp giao diện chuyên biệt để người dùng duyệt, tìm kiếm và xem chi tiết tất cả các cuộc hội thoại AI đã thực hiện trong profile. Feature này giúp người dùng:
- Xem toàn bộ danh sách conversation với thông tin tóm tắt (title, brand, product, last message, message count, thời gian).
- Tìm kiếm conversation theo title.
- Lọc conversation theo brand, ad type, khoảng thời gian.
- Xem chi tiết conversation: toàn bộ tin nhắn (user + AI) theo thứ tự thời gian.
- Xem nhanh context (brand, product, ad type) của từng conversation.
- Copy tin nhắn từ lịch sử.
- Tiếp tục conversation (chuyển đến US-26 chat).
- Xoá conversation không cần thiết.
- Export conversation (copy toàn bộ hội thoại).

---

## 3. Phạm vi

### Trong phạm vi

- Màn hình Conversation History chuyên dụng (`/ai/conversations`).
- Danh sách conversations dạng card/table view, sắp xếp theo thời gian hoạt động gần nhất.
- Tìm kiếm conversation theo title (search box).
- Filter nhanh theo brand (dropdown) và ad type.
- Date range picker lọc theo khoảng thời gian tạo.
- Sort theo title, createdAt, messageCount, lastMessageAt.
- Pagination (server-side) cho danh sách.
- Click vào conversation để xem chi tiết (detail page hoặc modal).
- Detail view: hiển thị context info + toàn bộ messages.
- Tin nhắn AI được render markdown.
- Copy tin nhắn (user hoặc AI).
- Nút "Continue Chat" → chuyển đến US-26 chat page với conversation này.
- Nút "Delete" → xoá conversation (soft delete) với xác nhận.
- Export conversation: copy toàn bộ hội thoại dạng text.
- Loading state, empty state, error state.

### Ngoài phạm vi

- Gửi tin nhắn mới từ history page (phải chuyển đến US-26).
- Tạo conversation mới (US-26).
- Batch xoá conversation.
- Export ra file (PDF, CSV) — chỉ support copy text.
- Recover conversation đã xoá (soft delete, không undo từ UI).
- Real-time update danh sách.

---

## 4. Actor

- **Chính:** Người dùng đã đăng nhập, có profile đang active, có ít nhất một conversation AI.
- **Phụ:** User Web App (frontend), Backend API (ConversationController/ConversationService), PostgreSQL.

---

## 5. Tiền điều kiện

- Người dùng đã đăng nhập và có JWT access token hợp lệ.
- Người dùng đã chọn active profile (`X-Profile-Id` header hợp lệ).
- Backend API và PostgreSQL đang hoạt động.

---

## 6. Luồng nghiệp vụ chính

### 6.1 Xem danh sách conversations

1. Người dùng truy cập màn hình Conversation History (`/ai/conversations`).
2. Entry point:
   - Tab / navigation item "Conversation History" trong AI section.
   - Nút "View All" từ US-26 chat sidebar header.
3. Frontend gọi `GET /api/conversations?page=1&pageSize=20`.
4. Hệ thống hiển thị danh sách conversations dạng card view (default) hoặc table view (toggle).
5. Mỗi conversation card hiển thị:
   - **Title** (nếu có, fallback: "Untitled").
   - **Brand/Product context** (badge/chips).
   - **Ad Type** badge.
   - **Last message** preview (2 dòng truncate).
   - **Message count**.
   - **Timestamp** (relative + absolute tooltip).
   - **Active status** (nếu conversation đang active).
   - Nút **"Continue"** → chuyển đến US-26.
   - Nút **"Delete"** (icon).
6. Nếu có nhiều hơn 20 conversations, hiển thị phân trang (pagination).

### 6.2 Tìm kiếm và lọc

1. Người dùng nhập từ khoá vào search box.
2. Frontend gọi `GET /api/conversations?searchTerm=...` (server-side search theo title).
3. Người dùng chọn brand filter (dropdown).
4. Người dùng chọn ad type filter.
5. Người dùng chọn date range.
6. Kết quả được cập nhật sau mỗi filter change (debounce cho search).

### 6.3 Xem chi tiết conversation

1. Người dùng click vào conversation card.
2. Hệ thống chuyển đến trang chi tiết (`/ai/conversations/{id}`) hoặc mở detail modal.
3. Frontend gọi `GET /api/conversations/{id}`.
4. Hiển thị:
   - **Header**: title, context info (brand, product, ad type), message count, timestamps.
   - **Messages**: danh sách tin nhắn theo thời gian (cũ nhất trước).
     - User message: bubble phải, plain text.
     - AI message: bubble trái, markdown rendered.
     - Mỗi message có timestamp + copy button.
   - **Actions**: nút "Continue Chat", nút "Export", nút "Delete".

### 6.4 Xem preview nhanh (Quick View)

1. Từ danh sách, người dùng có thể hover hoặc click vào một conversation để xem preview nhanh.
2. Popover/tooltip hiển thị:
   - Title.
   - Last message (đầy đủ).
   - Context (brand, product, ad type).
   - Message count.
   - Nút "View Details" và "Continue".

### 6.5 Export conversation

1. Từ detail view, người dùng nhấn nút **"Export"**.
2. Hệ thống tạo text format:
   ```
   Conversation: {title}
   Brand: {brandName} | Product: {productName} | Ad Type: {adType}
   Date: {createdAt} — {updatedAt}
   Messages: {messageCount}
   ─────────────────────────────────────
   [User] 06:44 AM
   Can you suggest a catchy headline for our summer sale?

   [AI] 06:44 AM
   Sure! How about: 🔥 Summer Sale Alert! 🔥
   ...
   ```
3. Copy vào clipboard.
4. Toast "Exported!" hiển thị.

### 6.6 Xoá conversation

1. Từ danh sách hoặc detail view, người dùng nhấn nút **"Delete"**.
2. Dialog xác nhận: "Xoá cuộc trò chuyện này? Hành động này không thể hoàn tác."
3. Người dùng xác nhận.
4. Frontend gọi `DELETE /api/conversations/{id}`.
5. Backend soft-delete.
6. Frontend: xoá khỏi danh sách, toast "Đã xoá cuộc trò chuyện."

### 6.7 Tiếp tục conversation

1. Từ danh sách hoặc detail view, người dùng nhấn **"Continue Chat"**.
2. Frontend điều hướng đến `/ai/chat?conversationId={id}` (US-26).
3. US-26 tự động load conversation này và focus vào input.

## 7. Luồng ngoại lệ

| Mã | Trường hợp | Kết quả mong đợi |
| --- | --- | --- |
| EX-01 | Profile chưa có conversation nào | Empty state: "Chưa có cuộc trò chuyện nào với AI." + nút "Bắt đầu chat ngay" (→ US-26). |
| EX-02 | Conversation không tồn tại hoặc không thuộc profile | Backend trả `404 Not Found`; frontend hiển thị lỗi và chuyển về danh sách. |
| EX-03 | Filter/search không có kết quả | Empty state: "Không tìm thấy cuộc trò chuyện nào." + nút "Xoá bộ lọc". |
| EX-04 | Lỗi mạng khi load danh sách | Toast "Không thể tải danh sách cuộc trò chuyện." + nút Retry. |
| EX-05 | Lỗi mạng khi load detail | Toast "Không thể tải chi tiết cuộc trò chuyện." + nút Retry. |
| EX-06 | JWT hết hạn hoặc không hợp lệ | Backend trả `401 Unauthorized`; frontend tự động refresh token hoặc chuyển hướng đăng nhập. |
| EX-07 | X-Profile-Id thiếu hoặc không thuộc user | Backend trả `400 Bad Request` / `403 Forbidden`; frontend hiển thị lỗi. |
| EX-08 | Xoá conversation thất bại | Toast "Không thể xoá cuộc trò chuyện. Vui lòng thử lại." |
| EX-09 | Export thất bại (clipboard API) | Toast "Không thể export. Vui lòng thử lại." |

---

## 8. Quy tắc nghiệp vụ

| Mã | Quy tắc |
| --- | --- |
| BR-01 | `ProfileId` được lấy từ `X-Profile-Id` header đã được middleware validate, không lấy từ request body. |
| BR-02 | Danh sách conversation hiển thị theo `updatedAt` giảm dần (mới nhất trước). |
| BR-03 | Conversation bị soft-delete (`IsDeleted = true`) không được trả về từ API. |
| BR-04 | Search conversation theo `title` (server-side, case-insensitive ILike). |
| BR-05 | Chỉ hiển thị conversation thuộc profile đang active. |
| BR-06 | Conversation detail bao gồm tất cả messages (không filter deleted messages — BE đã filter sẵn `!IsDeleted`). |
| BR-07 | Messages được sắp xếp theo `CreatedAt` tăng dần (cũ nhất trước). |
| BR-08 | Tin nhắn AI được render markdown, tin nhắn user hiển thị plain text. |
| BR-09 | Xoá conversation là soft delete: set `IsDeleted = true` và `IsActive = false`. |
| BR-10 | Export conversation là read-only operation, không ảnh hưởng dữ liệu. |

## 9. API Contracts

### 9.1 List Conversations

```
GET /api/conversations?page=1&pageSize=20&searchTerm=&sortBy=updatedAt&sortDescending=true
```

#### Headers

```http
Authorization: Bearer <access-token>
X-Profile-Id: <owned-profile-guid>
```

#### Query Parameters

| Field | Kiểu | Bắt buộc | Mặc định | Mô tả |
| --- | --- | --- | --- | --- |
| `page` | `int` | Không | 1 | Số trang. |
| `pageSize` | `int` | Không | 10 | Số item mỗi trang (max 100). |
| `searchTerm` | `string?` | Không | null | Tìm kiếm theo title (ILike). |
| `sortBy` | `string?` | Không | updatedAt | `title`, `createdAt`. |
| `sortDescending` | `bool` | Không | true | Sắp xếp giảm dần. |


```json

  "statusCode": 200,
```

### 9.4 Response Error Codes

| HTTP Status | errorCode | Trường hợp |
| --- | --- | --- |
| `401 Unauthorized` | — | JWT thiếu hoặc không hợp lệ. |
| `400 Bad Request` | — | `X-Profile-Id` thiếu hoặc sai format. |
| `403 Forbidden` | — | Profile không thuộc user đang đăng nhập. |
| `404 Not Found` | — | Conversation không tồn tại, đã bị xóa, hoặc không thuộc profile. |
| `500 Internal Server Error` | — | Lỗi hệ thống không mong đợi. |

### 10.3 Conversation Card

```tsx
function ConversationCard({
  conversation,
  onContinue,
  onDelete,
  isDeleting,
}: Props) {
  return (
    <div className="border rounded-lg p-4 hover:shadow-sm transition-shadow">
      {/* Header: title + badges */}
      <div className="flex items-start justify-between mb-2">
        <div className="flex-1 min-w-0">
          <h3 className="font-medium truncate">
            {conversation.title || "Untitled"}
          </h3>
          <div className="flex items-center gap-2 mt-1">
            {conversation.brandName && (
              <Badge variant="outline">{conversation.brandName}</Badge>
            )}
            {conversation.productName && (
              <Badge variant="outline">{conversation.productName}</Badge>
            )}
            <Badge>{adTypeLabel(conversation.adType)}</Badge>
            {conversation.isActive && (
              <Badge color="green">Active</Badge>
            )}
          </div>
        </div>
        <span className="text-xs text-gray-500 whitespace-nowrap ml-2">
          <time title={formatDateTime(conversation.lastMessageAt || conversation.createdAt)}>
            {formatRelativeTime(conversation.lastMessageAt || conversation.createdAt)}
          </time>
        </span>
      </div>

      {/* Last message */}
      {conversation.lastMessage && (
        <p className="text-sm text-gray-600 line-clamp-2 mb-3">
          {conversation.lastMessage}
        </p>
      )}

      {/* Footer: meta + actions */}
      <div className="flex items-center justify-between">
        <span className="text-xs text-gray-400">
          {conversation.messageCount} messages
        </span>
        <div className="flex gap-2">
          <Button
            variant="primary"
            size="sm"
            onClick={() => onContinue(conversation.id)}
          >
            Continue
          </Button>
          <Button
            variant="ghost"
            size="sm"
            onClick={() => onDelete(conversation.id)}
            disabled={isDeleting}
          >
            {isDeleting ? <Spinner /> : <TrashIcon />}
          </Button>
        </div>
      </div>
    </div>
  );
}
```

## 12. Acceptance Criteria

### AC-01 - Xem danh sách conversations

**Given** profile có ít nhất một conversation
**When** người dùng vào màn hình Conversation History
**Then** `GET /api/conversations` được gọi với page mặc định
**And** danh sách conversation hiển thị dạng card
**And** mỗi card hiển thị: title, brand/product, ad type, last message, message count, timestamp.

### AC-02 - Phân trang danh sách

**Given** có nhiều hơn 20 conversations
**When** hiển thị danh sách
**Then** hiển thị phân trang (pagination)
**When** người dùng nhấn "Next"
**Then** gọi API với page tiếp theo
**And** cập nhật danh sách.

### AC-03 - Tìm kiếm conversation

**Given** danh sách conversations
**When** người dùng nhập từ khoá vào search box
**Then** `GET /api/conversations?searchTerm=...` được gọi (debounce 300ms)
**And** danh sách được lọc theo title.

### AC-04 - Xem chi tiết conversation

**Given** người dùng click vào conversation card
**When** chuyển đến detail page
**Then** `GET /api/conversations/{id}` được gọi
**And** hiển thị context info + tất cả messages
**And** user messages bên phải, AI messages bên trái
**And** AI messages render markdown.

### AC-05 - Copy tin nhắn

**Given** người dùng ở detail view
**When** hover vào message và click copy
**Then** nội dung tin nhắn được copy vào clipboard
**And** toast "Copied!".

### AC-06 - Export conversation

**Given** người dùng ở detail view
**When** nhấn "Export"

```typescript
export type ConversationSummary = {
```

```typescript
// hooks/use-conversations.ts
function useConversations() {
  const [conversations, setConversations] = useState<ConversationSummary[]>([]);
  const [isLoading, setIsLoading] = useState(false);
  const [error, setError] = useState<string | null>(null);
  const [pagination, setPagination] = useState({ page: 1, pageSize: 20, totalCount: 0 });
  const [searchTerm, setSearchTerm] = useState("");

  const fetchConversations = async (page = 1) => {
    setIsLoading(true);
    setError(null);
    try {
      const result = await conversationApi.list({
        page,
        pageSize: pagination.pageSize,
        searchTerm: searchTerm || undefined,
      });
      if (result.success && result.data) {
        setConversations(result.data.data);
        setPagination({
          page: result.data.page,
          pageSize: result.data.pageSize,
          totalCount: result.data.totalCount,
        });
      } else {
        setError(result.message ?? "Failed to load.");
      }
    } catch {
      setError("Network error. Please try again.");
    } finally {
      setIsLoading(false);
    }
  };

  useEffect(() => {
    fetchConversations(1);
  }, [searchTerm]);

  return {
    conversations, isLoading, error,
    pagination, searchTerm, setSearchTerm,
    fetchConversations, refetch: () => fetchConversations(pagination.page),
  };
}
```

```typescript
// utils/export-conversation.ts
function exportConversation(conversation: ConversationDetail): void {
  const lines: string[] = [];
  lines.push(`Conversation: ${conversation.title || "Untitled"}`);
  lines.push(`Brand: ${conversation.brandName || "—"} | Product: ${conversation.productName || "—"} | Ad Type: ${adTypeLabel(conversation.adType)}`);
  lines.push(`Date: ${formatDateTime(conversation.createdAt)}`);
  lines.push(`Messages: ${conversation.messageCount}`);
  lines.push("─".repeat(50));

  for (const msg of conversation.messages) {
    const sender = msg.senderType === 0 ? "User" : "AI";
    const time = formatTime(msg.createdAt);
    lines.push("");
    lines.push(`[${sender}] ${time}`);
    lines.push(msg.message);
  }

  const text = lines.join("\n");
  copyToClipboard(text).then(() => {
    toast.success("Conversation exported to clipboard!");
  });
}
```
