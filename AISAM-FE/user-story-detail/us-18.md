# US-18 Frontend Detail - Tim kiem va loc san pham

## 1. User story

La nguoi dung da dang nhap, da chon business profile va brand, toi muon tim kiem va loc san pham theo brand va tu khoa de chon dung du lieu dau vao.

## 2. Muc tieu frontend

- Cung cap trai nghiem tim kiem product nhanh trong product catalog.
- Cho phep loc product theo selected brand thuoc active profile.
- Ho tro search theo tu khoa de tim product theo ten hoac mo ta.
- Ho tro pagination va sort theo contract backend hien tai.
- Dam bao product duoc chon lam input cho Content/AI dung brand/profile context.

## 3. Can cu backend va scope hien tai

### Requirement lien quan

- `requirement.md` muc `6.4 Product Catalog` yeu cau tim kiem va loc san pham theo brand.
- `requirement.md` muc `6.6 AI Content Generation` yeu cau chon brand va product lam context dau vao.
- Business rule: Product neu duoc chon phai thuoc dung brand tuong ung.

### Backend plan lien quan

- `BACKEND_CODE_PLAN.md` Phase 4 va Task 4.3 da active Product module.
- `CODEBASE_UPDATE.md` xac nhan active backend co `ProductController`, `ProductService`, `ProductRepository`.
- Task 4.3 ghi ro `GET /api/products` ho tro `brandId` query de test product theo brand da tao.

### Backend implementation thuc te

- Controller: `AISAM-BE/AISAM.API/Controllers/ProductController.cs`
- Service: `AISAM-BE/AISAM.Services/Service/ProductService.cs`
- Repository: `AISAM-BE/AISAM.Repositories/Repository/ProductRepository.cs`
- DTO response: `ProductResponseDto`

- List response: `GenericResponse<PagedResult<ProductResponseDto>>`
- Search backend dung `EF.Functions.ILike` tren:
  - `Product.Name`
  - `Product.Description`
- Filter backend hien tai:
  - `brandId`
  - `includeDeleted`
- Sort backend hien tai:
  - `name`
  - `price`
  - `createdAt`
- Pagination backend:
  - `page`
  - `pageSize`, clamp toi da `100`

## 4. Pham vi frontend

### Trong pham vi

- Search input cho product keyword.
- Loc product theo selected brand.
- Hien thi product list co paging.
- Sort product theo `createdAt`, `name`, `price`.
- Toggle hoac filter xem active/deleted product neu man hinh can chon product da xoa de khoi phuc.
- Reset search/filter khi active profile hoac selected brand thay doi.
- Debounce search de tranh goi API qua nhieu.
- Cho phep chon mot product hop le de lam input cho content/AI flow.
- Hien empty state khi khong co ket qua.

### Ngoai pham vi

- Tao, cap nhat, xoa, khoi phuc product: thuoc `US-17`.
- Upload anh product.
- Search nang cao theo gia min/max, category, tag, SKU, stock.
- Full-text search nang cao, highlight tu khoa trong backend.
- Product analytics.
- Search product cross-profile hoac cross-tenant.

## 5. API contract can dung

### List/search/filter request

`GET /api/products?brandId={brandId}&page=1&pageSize=10&searchTerm={keyword}&sortBy=createdAt&sortDescending=true&includeDeleted=false`

Header:

```http
Authorization: Bearer <accessToken>
X-Profile-Id: <activeProfileId>
```

Query params:

| Param | Required tren UI | Ghi chu |
| --- | --- | --- |
| `brandId` | Yes | Lay tu brand dang chon. Backend cho optional, nhung FE nen required de tranh list qua rong. |
| `page` | No | Default `1`. Reset ve `1` khi keyword/filter doi. |
| `pageSize` | No | Default `10`, backend clamp `1..100`. |
| `searchTerm` | No | Tim theo `name` va `description`, case-insensitive. |
| `sortBy` | No | `createdAt`, `name`, `price`. |
| `sortDescending` | No | Default `true`. |
| `includeDeleted` | No | Default `false`; chi bat trong deleted/restore view. |

### Success response

HTTP `200 OK`

```json
{
  "success": true,
  "message": "Products retrieved successfully",
  "statusCode": 200,
  "data": {
    "data": [
      {
        "id": "product-guid",
        "brandId": "brand-guid",
        "name": "Ca phe rang moc 250g",
        "description": "Huong chocolate nhe, phu hop pha phin va cold brew",
        "price": 149000,
        "images": [],
        "createdAt": "2026-06-03T00:00:00Z",
        "updatedAt": "2026-06-03T00:00:00Z"
      }
    ],
    "totalCount": 1,
    "page": 1,
    "pageSize": 10
  },
  "error": null
}
```

### Error response can xu ly

| HTTP status | Truong hop | FE xu ly |
| --- | --- | --- |
| `401` | Token thieu/khong hop le | Thu refresh token hoac dua ve login. |
| `400` | `Brand not found` | Hien loi brand khong ton tai, reload brand list. |
| `400` | `You are not allowed to access this brand` | Hien loi khong co quyen, reset selected brand. |
| `500` | `System error` | Hien loi he thong va cho phep retry. |

## 6. UI/UX spec

### Vi tri su dung

- Trang product catalog: `/products` hoac `/brand/{brandId}/products`.
- Product picker trong flow tao content/AI draft.
- Product selector trong form tao/cap nhat content neu co.

### Thanh phan can co

- Active profile indicator.
- Brand selector chi hien brand thuoc active profile.
- Search input co placeholder ngan gon, vi du `Search products`.
- Sort select:
  - newest/oldest theo `createdAt`
  - name A-Z/Z-A
  - price low-high/high-low
- Page size select hoac pagination control.
- Product list dang table/card compact.
- Product selected state neu dung picker.
- Empty state:
  - chua co active profile
  - chua chon brand
  - brand chua co product
  - khong co ket qua voi keyword hien tai

### Search behavior

- Trim keyword truoc khi gui API.
- Debounce khoang 300-500ms.
- Khi keyword thay doi:
  - reset `page = 1`
  - goi lai `GET /api/products`
  - giu selected brand hien tai
- Neu keyword rong:
  - bo `searchTerm` hoac gui chuoi rong deu duoc, nhung nen bo param de URL gon.

### Filter behavior

- Brand filter bat buoc trong UI story nay.
- Khi selected brand thay doi:
  - reset selected product
  - reset page ve `1`
  - co the giu keyword neu UX mong muon search tiep trong brand moi, hoac clear keyword neu app pattern dang lam vay.
- Khi active profile thay doi:
  - reset selected brand
  - reset selected product
  - clear product query cache cua profile cu
  - load lai brand list theo profile moi.

### Sort behavior

Frontend map UI sort sang query backend:

| UI option | `sortBy` | `sortDescending` |
| --- | --- | --- |
| Newest | `createdAt` | `true` |
| Oldest | `createdAt` | `false` |
| Name A-Z | `name` | `false` |
| Name Z-A | `name` | `true` |
| Price low-high | `price` | `false` |
| Price high-low | `price` | `true` |

## 7. Validation frontend

- Khong goi Product API neu chua dang nhap.
- Khong goi Product API neu chua co active profile.
- Khong goi Product API neu chua co selected brand.
- `brandId` phai thuoc brand list cua active profile.
- `page` toi thieu `1`.
- `pageSize` trong UI nen nam trong `10`, `20`, `50`, `100`.
- `sortBy` chi dung cac gia tri backend ho tro: `createdAt`, `name`, `price`.
- `searchTerm` nen trim va co gioi han do dai UI, vi du 100 ky tu.

## 8. Data flow frontend

1. User vao product catalog hoac product picker.
2. Frontend kiem tra auth session va active profile.
3. Frontend load brand list theo active profile.
4. User chon brand hoac app nhan `brandId` tu route.
5. Frontend verify brand thuoc active profile.
6. Frontend goi `GET /api/products` voi `brandId`, `page`, `pageSize`, `searchTerm`, `sortBy`, `sortDescending`, `includeDeleted`.
7. User nhap keyword:
   - debounce
   - reset page
   - refetch list.
8. User doi sort/page/page size:
   - update query state
   - refetch list.
9. User chon product:
   - frontend luu `selectedProductId`
   - verify product co `brandId` khop selected brand.
10. Neu dung cho AI/content:
   - truyen `brandId` va `productId` sang flow tiep theo.

## 9. State can xu ly

### Loading state

- Loading brand selector.
- Loading product list lan dau.
- Loading khi search debounce dang fetch.
- Loading khi doi page/sort.

### Success state

- Hien danh sach product va total count.
- Hien selected product ro rang neu trong picker.
- Pagination cap nhat dung `totalCount`, `page`, `pageSize`.

### Empty state

- Chua co active profile: yeu cau chon/tao profile.
- Chua co brand: yeu cau tao brand truoc.
- Chua chon brand: yeu cau chon brand.
- Khong co product trong brand: goi y tao product trong `US-17`.
- Khong co ket qua search: hien keyword va nut clear search.

### Error state

- Token het han/chua dang nhap.
- Brand khong ton tai.
- Khong co quyen truy cap brand.
- Loi he thong.
- Network timeout.

## 10. Auth/profile/brand impact

- Product API hien tai duoc bao ve bang JWT.
- Product API hien tai chua nam trong `ActiveProfileMiddleware`, nhung API client chung nen gui `X-Profile-Id` de thong nhat voi cac module khac.
- Backend validate ownership qua `Brand.Profile.UserId`.
- Frontend phai dua vao active profile va selected brand de tranh request sai context.
- Khi active profile thay doi, product search state cua profile cu khong duoc leak sang profile moi.

## 11. Acceptance criteria

### AC-01

Frontend chi hien product search/list khi user da dang nhap, co active profile va co selected brand.

### AC-02

Khi selected brand la Brand A, frontend goi `GET /api/products` voi `brandId=Brand A`.

### AC-03

Khi user nhap keyword, frontend goi lai API voi `searchTerm` da trim va reset `page=1`.

### AC-04

Ket qua search chi hien product co `brandId` khop selected brand.

### AC-05

Khi user xoa keyword, frontend load lai product list cua selected brand khong co filter keyword.

### AC-06

Khi user doi sort, frontend map dung `sortBy` va `sortDescending` theo backend contract.

### AC-07

Khi user doi page/page size, frontend goi lai API voi query pagination dung va render total/page state tu `PagedResult`.

### AC-08

Khi active profile thay doi, frontend reset selected brand, selected product va product query/cache cua profile cu.

### AC-09

Khi backend tra `Brand not found` hoac ownership error, frontend khong render product list stale va hien thong bao phu hop.

### AC-10

Khi user chon product de lam input cho content/AI, frontend chi chap nhan product co `brandId` khop selected brand hien tai.

## 13. Ghi chu implementation

- Nen dung query key co du thong tin scope, vi du:
  - `["products", activeProfileId, brandId, searchTerm, page, pageSize, sortBy, sortDescending, includeDeleted]`
- Nen debounce search o hook/component, khong debounce trong API client chung.
- Nen dung URL search params cho product catalog de user back/forward van giu filter.
- Product response hien chua co `isDeleted`; neu deleted filter can UX ro hon, can backend task rieng bo sung field nay.
- Backend search hien chi tim `name` va `description`, khong tim theo `price`, image, selling points rieng.
- Neu user can search theo selling points, tam thoi nhap selling points trong `description` cho den khi backend co field rieng.
