# US-12 Frontend Detail - Tao business profile

## 1. User story

La nguoi dung da dang nhap, toi muon tao business profile dau tien de bat dau quan ly du lieu trong AISAM.

## 2. Muc tieu frontend

- Cung cap form tao profile dung voi backend MVP hien tai.
- Goi dung endpoint `create profile` dang active.
- Dan nguoi dung vao flow co active profile sau khi tao thanh cong.

## 3. Can cu backend va scope hien tai

### Requirement lien quan

- `requirement.md` muc `6.3 Business Profile and Brand Kit` yeu cau tao business profile.

### Backend plan lien quan

- `BACKEND_CODE_PLAN.md` Phase 4 xac dinh Profile MVP da active.
- `CODEBASE_UPDATE.md` Phase A xac nhan Profile da co controller/service/repository.

### Backend implementation thuc te

- Endpoint: `POST /api/profiles/user/{userId}`
- Authorization: bat buoc
- Content-Type: `multipart/form-data`
- Success response: `201 Created`
- Response shape: `GenericResponse<ProfileResponseDto>`

### Hanh vi backend can frontend phai follow

- Backend chi cho tao profile cho chinh `userId` trong JWT
- Neu route `userId` khac JWT user:
  - `403 Forbidden`
- Request fields:
  - `name` bat buoc
  - `profileType` bat buoc
  - `companyName` optional
  - `bio` optional
  - `avatarUrl` optional
  - `avatarFile` co trong DTO nhung backend MVP reject
- Neu gui `avatarFile`:
  - loi `Avatar file upload is not enabled in the current MVP backend. Use AvatarUrl instead.`

## 4. Pham vi frontend

### Trong pham vi

- Trang `/profiles/new`
- Form tao profile
- Submit `multipart/form-data`
- Hien backend error
- Set active profile sau khi tao thanh cong

### Ngoai pham vi

- Upload file avatar that: backend chua support
- Quan ly team member/shared profile: chua migrate

## 5. API contract can dung

### Request

`POST /api/profiles/user/{userId}`

Header:

```http
Authorization: Bearer <accessToken>
Content-Type: multipart/form-data
```

FormData fields:

- `name`
- `profileType`
- `companyName`
- `bio`
- `avatarUrl`

### Success response

HTTP: `201 Created`

```json
{
  "success": true,
  "message": "Profile created successfully",
  "statusCode": 200,
  "data": {
    "id": "guid",
    "userId": "guid",
    "name": "My Business",
    "profileType": 0,
    "subscriptionId": null,
    "companyName": "My Company",
    "bio": "Short bio",
    "avatarUrl": "https://example.com/avatar.png",
    "status": 0,
    "createdAt": "2026-06-02T00:00:00Z",
    "updatedAt": "2026-06-02T00:00:00Z",
    "isOwner": true,
    "memberRole": null
  },
  "error": null
}
```

Luu y:

- HTTP status la `201`
- Trong body `statusCode` van co the la `200` do helper response hien tai

### Error response

- `401` neu chua dang nhap
- `403` neu `userId` route khong trung JWT user
- `400`/`500` cho cac loi he thong hoac request khong hop le

### CTA

## 7. Validation frontend

- `name` required
- `profileType` required
- `avatarUrl` neu co thi co the validate URL format o muc mem

Khong them field ngoai backend contract.

## 8. Data flow frontend

1. User da dang nhap vao `/profiles/new`
2. Frontend lay `user.id` tu auth store
3. Render form
4. Submit bang `FormData`
5. Goi `POST /api/profiles/user/{userId}`
6. Neu thanh cong:
   - nhan `ProfileResponseDto`
   - luu profile vao state/query cache
   - set active profile = profile moi
   - redirect `/dashboard`
7. Neu that bai:
   - hien error state

## 9. State can xu ly

### Loading state

- Disable CTA

### Success state

- Profile duoc tao thanh cong
- Active profile duoc set

### Error state

- `403` ownership mismatch
- Loi avatar file neu frontend lỡ gui sai field
- Generic server error

## 10. Auth/session impact

- Khong doi auth session
- Co tac dong den `profile-store`:
  - them profile moi
  - set active profile

## 11. Dieu huong sau tao profile

- Redirect: `/dashboard`

Ly do:

- Sau khi da co profile dau tien, user co the vao khu protected co context profile

## 12. Acceptance criteria

### AC-01

Frontend gui request tao profile bang `multipart/form-data`.

### AC-02

Frontend su dung `user.id` tu auth session de tao dung route `user/{userId}`.

### AC-03

Sau khi tao thanh cong, frontend set active profile va redirect `/dashboard`.

### AC-04

Frontend khong hien upload avatar file control trong MVP.

### AC-05

Khi backend tra loi ownership hoac server error, frontend hien thong diep ro rang va giu du lieu form.

## 14. Ghi chu implementation

- Backend response HTTP la `201`, frontend khong duoc hardcode chi chap nhan `200`.
- Enum `profileType` co the serialize dang so; frontend nen map giua UI label va backend value.
- `status` profile moi tao hien tai co the la enum so, frontend khong nen gia dinh la string.
