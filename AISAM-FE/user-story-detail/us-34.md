# US-34 - Đăng bài ngay lên Facebook

## 1. User Story

**Là** người dùng,
**tôi muốn** publish content lên Facebook Page đã liên kết để xuất bản bài viết trực tiếp từ AISAM,
**để** đưa nội dung quảng cáo lên Facebook ngay lập tức mà không cần thao tác thủ công bên ngoài.

---

## 2. Mục tiêu

Cung cấp action "Publish Now" cho phép người dùng đăng một content đã được soạn thảo lên một Facebook Page đã liên kết. Flow bao gồm: chọn page đích, gọi BE publish API, hiển thị trạng thái real-time (đang publish / thành công / thất bại), và cập nhật trạng thái content cùng lịch sử Post sau khi hoàn tất.

---

## 3. Phạm vi

### Trong phạm vi

- Hiển thị danh sách Facebook pages đã liên kết với brand của content để user chọn nơi publish.
- Gọi `POST /api/content/{contentId}/publish/{integrationId}` với content đã chọn và integration đã chọn.
- Loading state: progress indicator "Đang đăng bài..." trong suốt quá trình publish.
- Toast success: "Đã đăng bài lên {pageName} thành công."
- Toast error với message lỗi cụ thể từ BE (token expired, quota hết, Facebook reject, etc.).
- Xem trước nội dung trước khi publish (text content, images).
- Cập nhật trạng thái content từ Draft/Approved → Published.
- Hiển thị Post history entry ngay sau khi publish.
- Nếu content.ImageUrl tồn tại, publish kèm ảnh (TextOnly → feed, ImageText → single/multi image post).
- Nếu content.VideoUrl tồn tại, publish kèm video (VideoText → video post).
- Hỗ trợ publish lên nhiều pages bằng cách gọi API tuần tự (multi-select pages).
- Xử lý quota check failure (403 PROMPT_QUOTA_EXCEEDED / POST_QUOTA_EXCEEDED).
- Xử lý trường hợp token cần refresh (BE tự động refresh và persist token mới).

### Ngoài phạm vi

- Schedule / lên lịch đăng bài: xem US-40 (scheduling).
- Approval flow trước khi publish: xem US-26/US-27 (approval).
- Publish lên Instagram, TikTok: post-MVP.
- Facebook Ads (campaign, ad set, ad creative): post-MVP.
- Retry tự động khi publish fail — FE chỉ cho phép retry thủ công.
- Xem lịch sử publish (Posts list): xem US-35 (post history).

---

## 4. Actor

- **Chính:** Người dùng đã đăng nhập, đã soạn content và đã liên kết Facebook pages với brand.
- **Phụ:** Backend API (ContentController, ContentService, FacebookProvider), Facebook Graph API, QuotaService.

---

## 5. Tiền điều kiện

- Người dùng đã đăng nhập và có JWT hợp lệ.
- Người dùng đã chọn active profile (`X-Profile-Id`).
- Content tồn tại và thuộc profile đang active.
- Content chưa được publish trước đó (`Status != Published`).
- Brand của content có ít nhất một Facebook page đã liên kết (integration).
- Facebook page token còn hạn (BE sẽ attempt refresh nếu cần).
- User còn post quota (BE check; nếu hết quota, API trả 403).

---

## 6. Luồng nghiệp vụ chính

### 6.1 Publish Now lên một Facebook Page

1. Người dùng đang ở màn hình Content Detail (hoặc Content List với inline publish).
2. Content có status là `Draft` hoặc `Approved`.
3. User nhấn nút **"Publish Now"**.
4. Modal "Publish Content" mở ra với:
   - Preview nội dung: text content, images, video URL (nếu có).
   - Danh sách Facebook pages đã liên kết với brand của content (lấy từ `GET /api/social/integrations/brand/{brandId}`).
   - Checkbox để chọn 1 hoặc nhiều pages.
   - Nút [Publish].
5. User chọn N pages và nhấn **"Publish"**.
6. Frontend gọi `POST /api/content/{contentId}/publish/{integrationId}` cho từng page (tuần tự).
7. Trong khi đang publish:
   - Progress indicator: "Đang đăng bài lên {pageName}... ({current}/{total})".
   - Nút Publish disabled + spinner.
8. Sau mỗi page hoàn tất:
   - **Thành công:** đánh dấu page đó là "✅ Published" trong danh sách.
   - **Thất bại:** đánh dấu page đó là "❌ Failed" + message lỗi.
9. Sau khi tất cả pages hoàn tất:
   - Nếu **tất cả success:** toast "Đã đăng bài lên {N} pages thành công." + đóng modal sau 2 giây.
   - Nếu **partial success:** toast "Đã đăng lên {X}/{N} pages. {Y} pages thất bại." + để modal mở để user retry.
   - Nếu **tất cả fail:** toast "Đăng bài thất bại." + để modal mở + nút Retry.
10. Content status được cập nhật:
    - Nếu ít nhất 1 page thành công → content status = `Published`.
    - Nếu tất cả fail → content status giữ nguyên.
11. Tạo Post record cho mỗi page publish thành công (BE tự động làm).
12. UI cập nhật: content detail hiển thị trạng thái Published + Post history.

### 6.2 Preview nội dung trước khi publish

1. Trong modal Publish, hiển thị preview nội dung sẽ đăng:
   - **TextOnly:** text content.
   - **ImageText:** text + ảnh thumbnail.
   - **VideoText:** text + video thumbnail/URL.
2. Hiển thị brand name và page name sẽ đăng.
3. Không cho phép chỉnh sửa nội dung trong modal (edit quay lại Content Edit).

### 6.3 Xử lý lỗi publish chi tiết

1. **Token expired:** BE trả lỗi → modal hiển thị "Token Facebook đã hết hạn. Vui lòng reconnect." + nút "Reconnect" dẫn đến US-29 flow.
2. **Quota exceeded:** BE trả 403 POST_QUOTA_EXCEEDED → modal hiển thị "Bạn đã hết post quota trong tháng này." + nút "View Plan" dẫn đến Subscription page.
3. **Facebook API reject:** BE trả lỗi từ Facebook → modal hiển thị message gốc từ Facebook Graph API.
4. **Network error:** Toast generic + nút Retry.

| EX-08 | Content không có integration nào cho brand | Modal hiển thị "Chưa có page nào liên kết với brand này." + nút "Manage Pages" (US-31). |

| Mã | Quy tắc |

| BR-08 | AdType quyết định loại post Facebook: `TextOnly` → feed post, `ImageText` → image post, `VideoText` → video post. |

## 9. API Contract

### 9.1 Publish Content

```
POST /api/content/{contentId}/publish/{integrationId}
```

#### Headers
```http
Authorization: Bearer <access-token>
X-Profile-Id: <owned-profile-guid>
```

#### Response (200 OK - success)
```json
{
  "success": true,
  "statusCode": 200,
  "message": "Content published successfully.",
  "data": {
    "success": true,
    "providerPostId": "facebook-post-id-123",
    "errorMessage": null,
    "postedAt": "2026-06-04T10:30:00Z",
    "refreshedTargetAccessToken": null
  }
}
```

#### Response (400 - already published)
```json
{
  "success": false,
  "statusCode": 400,
  "message": "Content has already been published.",
  "data": null
}
```

#### Response (403 - quota exceeded)
```json
{
  "success": false,
  "message": "Post quota has been exceeded for the current subscription.",
  "statusCode": 403,
  "data": null,
  "error": {
    "errorCode": "POST_QUOTA_EXCEEDED",
    "errorMessage": "Post quota has been exceeded for the current subscription."
  },
  "timestamp": "2026-06-03T12:00:00Z"
}
```

#### Response (404 - content/integration not found)
```json
{
  "success": false,
  "statusCode": 404,
  "message": "Social integration not found.",
  "data": null
}
```

#### Response (502 - Facebook API error)
```json
{
  "success": false,
  "statusCode": 502,
  "message": "(#100) The message exceeds the 63206 character limit.",
  "data": null
}
```

## 12. Acceptance Criteria

### AC-01 - Publish lên 1 page thành công

**Given** content detail với brand có 1 integration hợp lệ
**When** mở Publish modal → chọn page → nhấn "Publish Now"
**Then** `POST /api/content/{contentId}/publish/{integrationId}` được gọi
**And** loading state "Đang đăng bài..."
**And** API trả success
**And** toast "Đã đăng bài lên {pageName} thành công."
**And** content status chuyển Published
**And** Post record được tạo.

### AC-02 - Publish lên nhiều pages tuần tự

**Given** content detail với brand có 3 integrations
**When** chọn 3 pages → nhấn Publish
**Then** API được gọi tuần tự 3 lần
**And** progress indicator cập nhật sau mỗi page.

### AC-03 - Partial success

**Given** publish lên 2 pages, page 1 success, page 2 fail
**When** hoàn tất
**Then** toast "Đã đăng lên 1/2 pages. 1 page thất bại."
**And** modal hiển thị kết quả từng page
**And** nút "Retry Failed" hiển thị.

### AC-04 - Content đã published

**Given** content đã published trước đó
**When** nhấn "Publish Now"
**Then** toast "Content đã được đăng trước đó."
**And** nút Publish disabled.

### AC-05 - Token expired

**Given** token Facebook hết hạn
**When** publish → BE trả lỗi
**Then** modal hiển thị "Token đã hết hạn." + nút "Reconnect".

### AC-06 - Hết quota

**Given** user hết post quota
**When** publish → BE trả 403 POST_QUOTA_EXCEEDED
**Then** modal hiển thị "Hết quota đăng bài." + nút "View Plan".

### AC-07 - Không có page nào

**Given** brand chưa có integration nào
**When** mở Publish modal
**Then** hiển thị "Chưa có page nào liên kết." + nút "Manage Pages".

### AC-08 - Preview nội dung

**Given** mở Publish modal
**Then** hiển thị text content + image/video preview nếu có.

### AC-09 - Loading state

**Given** đang publish
**Then** nút Publish spinner + disabled, mỗi page hiển thị trạng thái.

### AC-10 - Retry failed pages

**Given** partial success hoặc all failed
**When** nhấn "Retry Failed"
**Then** chỉ gọi API cho các page bị fail.

**usePublishContent:**

```typescript
import { useMutation, useQueryClient } from "@tanstack/react-query";
import { contentApi } from "@/features/content/api/content-api";
import { toast } from "sonner";

export function usePublishContent(contentId: string) {
  const queryClient = useQueryClient();

  return useMutation({
    mutationFn: (integrationId: string) =>
      contentApi.publish(contentId, integrationId),

    onSuccess: () => {
      queryClient.invalidateQueries({ queryKey: ["content", contentId] });
      queryClient.invalidateQueries({ queryKey: ["content-list"] });
      queryClient.invalidateQueries({ queryKey: ["posts"] });
    },
  });
}
```

**usePublishToMultiplePages:**

```typescript
export function usePublishToMultiplePages(contentId: string) {
  const singlePublish = usePublishContent(contentId);

  const publishAll = async (
    integrationIds: string[],
    onProgress: (completed: number, total: number, failed: { id: string; error: string }[]) => void
  ) => {
    const failed: { id: string; error: string }[] = [];
    let completed = 0;

    for (const integrationId of integrationIds) {
      try {
        await singlePublish.mutateAsync(integrationId);
      } catch (err) {
        failed.push({ id: integrationId, error: (err as Error).message });
      }
      completed++;
      onProgress(completed, integrationIds.length, failed);
    }

    return { totalSuccess: completed - failed.length, totalFailed: failed.length, failed };
  };

  return { publishAll, isPending: singlePublish.isPending };
}
```

#### Components

**PublishModal:**

```tsx
function PublishModal({
  content,
  integrations,
  open,
  onOpenChange,
}: {
  content: ContentResponseDto;
  integrations: SocialIntegrationDto[];
  open: boolean;
  onOpenChange: (open: boolean) => void;
}) {
  const [selectedIds, setSelectedIds] = useState<Set<string>>(new Set());
  const [pageStates, setPageStates] = useState<PublishPageState[]>([]);
  const { publishAll, isPending } = usePublishToMultiplePages(content.id);
  const [publishDone, setPublishDone] = useState(false);

  const isMulti = selectedIds.size > 1;
  const noIntegrations = integrations.length === 0;

  const handlePublish = async () => {
    const ids = Array.from(selectedIds);
    const initialStates: PublishPageState[] = ids.map((id) => ({
      integration: integrations.find((i) => i.id === id)!,
      status: "pending",
    }));
    setPageStates(initialStates);
    setPublishDone(false);

    const { totalSuccess, totalFailed, failed } = await publishAll(ids, (completed, total, failedSoFar) => {
      setPageStates((prev) =>
        prev.map((ps, idx) => {
          const isCompleted = idx < completed;
          const isFailed = failedSoFar.some((f) => f.id === ps.integration.id);
          if (isFailed) return { ...ps, status: "failed", errorMessage: failedSoFar.find((f) => f.id === ps.integration.id)?.error };
          if (isCompleted) return { ...ps, status: "success" };
          if (idx === completed) return { ...ps, status: "publishing" };
          return ps;
        })
      );
    });

    setPublishDone(true);

    if (totalSuccess === ids.length) {
      toast.success(`Đã đăng bài lên ${totalSuccess} page${totalSuccess > 1 ? "s" : ""} thành công.`);
      setTimeout(() => onOpenChange(false), 2000);
    } else if (totalSuccess > 0) {
      toast.warning(`Đã đăng lên ${totalSuccess}/${ids.length} pages. ${totalFailed} pages thất bại.`);
    } else {
      toast.error("Đăng bài thất bại.");
    }
  };

  return (
    <Dialog open={open} onOpenChange={onOpenChange}>
      <DialogContent className="max-w-lg">
        <DialogHeader>
          <DialogTitle>
            {isPending ? `Publishing... (${pageStates.filter((s) => s.status === "success").length}/${selectedIds.size})` : "Publish Content"}
          </DialogTitle>
        </DialogHeader>

        {/* Preview */}
        <PublishPreview content={content} />

        {/* Page selection / progress */}
        {isPending || publishDone ? (
          <div className="space-y-2">
            {pageStates.map((ps) => (
              <PublishPageItem key={ps.integration.id} state={ps} />
            ))}
          </div>
        ) : noIntegrations ? (
          <div className="py-8 text-center text-sm text-muted-foreground">
            <p>Chưa có page nào liên kết với brand này.</p>
            <Button variant="link" size="sm">Manage Pages</Button>
          </div>
        ) : (
          <div className="space-y-2">
            <p className="text-sm font-medium">Select Pages:</p>
            {integrations.map((integration) => (
              <label key={integration.id} className="flex cursor-pointer items-center gap-3 rounded-lg border p-3 hover:bg-muted/50">
                <Checkbox
                  checked={selectedIds.has(integration.id)}
                  onCheckedChange={(checked) => {
                    setSelectedIds((prev) => {
                      const next = new Set(prev);
                      checked ? next.add(integration.id) : next.delete(integration.id);
                      return next;
                    });
                  }}
                />
                <span className="flex-1 text-sm">{integration.name}</span>
                <span className="text-xs text-muted-foreground">{integration.platform}</span>
              </label>
            ))}
          </div>
        )}

        <DialogFooter>
          <Button variant="outline" onClick={() => onOpenChange(false)} disabled={isPending}>
            {isPending ? "Close" : "Cancel"}
          </Button>
          {!isPending && !publishDone && !noIntegrations && (
            <Button onClick={handlePublish} disabled={selectedIds.size === 0}>
              <SendIcon className="mr-2 h-4 w-4" />
              Publish {isMulti ? `(${selectedIds.size} pages)` : "Now"}
            </Button>
          )}
          {publishDone && pageStates.some((ps) => ps.status === "failed") && (
            <Button variant="destructive" onClick={() => { /* retry failed */ }}>
              Retry Failed
            </Button>
          )}
        </DialogFooter>
      </DialogContent>
    </Dialog>
  );
}
```

**PublishPageItem:**

```tsx
function PublishPageItem({ state }: { state: PublishPageState }) {
  const icons = {
    pending: "⬜",
    publishing: "⏳",
    success: "✅",
    failed: "❌",
  };

  return (
    <div className="flex items-center gap-3 rounded-lg border px-3 py-2 text-sm">
      <span>{icons[state.status]}</span>
      <span className="flex-1">{state.integration.name}</span>
      {state.status === "failed" && (

      )}
    </div>
  );
}
```
