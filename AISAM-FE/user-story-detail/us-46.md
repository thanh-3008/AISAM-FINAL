# US-46 - Xem subscription hiện tại

## 1. User Story

**Là** người dùng,
**tôi muốn** xem thông tin chi tiết gói subscription đang active của profile,
**để** biết được hạn mức sử dụng, thời hạn còn lại, và các tính năng đi kèm.

---

## 2. Mục tiêu

Cung cấp tab "Gói của tôi" trong trang `/payment` hiển thị đầy đủ thông tin gói subscription đang active: tên gói, trạng thái, ngày bắt đầu/kết thúc, số ngày còn lại, danh sách tính năng đi kèm, và hạn mức sử dụng (quota) với biểu đồ trực quan. Tab này thay thế mini subscription card và mini quota bars ở US-44 bằng một view chi tiết, giàu thông tin hơn.

---

## 3. Phạm vi

### Trong phạm vi

- Tab "Gói của tôi" là tab mặc định khi vào `/payment`.
- Header section:
  - Icon + tên gói (lớn, nổi bật).
  - Status badge: "Active" (xanh) / "Inactive" (xám) / "Hết hạn" (đỏ).
  - Ngày bắt đầu → ngày kết thúc.
  - **Days remaining**: số ngày còn lại (nếu có EndDate), hoặc "Không có hạn" (nếu null).
- Plan features checklist:
  - Lấy từ hardcoded FE plan config (PLANS array từ US-44), cross-reference bằng `planName`.
  - Hiển thị danh sách tính năng với icon check (✅ nếu included) hoặc dash (— nếu không).
  - Gồm: quota posts, AI content, platforms, accounts, analysis level, ad budget, ad campaigns.
- Quota usage detail (2 khung riêng biệt, giàu thông tin hơn US-44):
  - **Prompt Quota (AI Content)**:
    - Label: "AI Content / ngày".
    - Progress bar với màu sắc (xanh/vàng/đỏ).
    - Usage text: "Đã dùng X / Y — Còn Z".
    - Warning nếu `promptRemaining` thấp hoặc `promptQuotaLimit = 0` (không có quota).
  - **Post Quota (Bài đăng)**:
    - Label: "Bài đăng / tháng".
    - Progress bar với màu sắc.
    - Usage text: "Đã dùng X / Y — Còn Z".
    - Warning nếu `postRemaining` thấp.
  - Window info: "Chu kỳ: dd/MM/yyyy → dd/MM/yyyy".
  - Nếu không có subscription → ẩn quota section.
- Quota limit info cards:
  - **Platforms**: "X / Y nền tảng" (hardcoded từ plan config).
  - **Accounts**: "X / Y tài khoản" (hardcoded từ plan config).
  - **Analysis Level**: tên level (Basic / Plus / Premium).
- Nút "Quản lý gói" → chuyển sang tab "Plans" (chuyển tab, không chuyển trang).
- Nút "Lịch sử giao dịch" → chuyển sang tab "History".
- Loading skeleton cho toàn bộ tab.
- Error state: banner + "Thử lại".
- Fallback nếu không có active subscription:
  - Hiển thị message "Bạn chưa có gói active."
  - Nút "Chọn gói ngay" → chuyển sang tab "Plans".
  - Không hiển thị quota section.

### Ngoài phạm vi

- Thay đổi subscription (nâng cấp, hủy): đã có trong US-44 (tab Plans).
- Auto-renew toggle: deferred.
- Invoice/receipt download: deferred.
- Usage history chart (biểu đồ theo thời gian): deferred.
- Hiển thị thông tin payment method đã lưu: deferred.
- Cancel subscription flow: deferred.

## 4. Actor

- **Chính:** Người dùng đã đăng nhập, có active profile.
- **Phụ:** User Web App, Backend API (`PaymentController`, `QuotaController`), React Query cache.

## 5. Tiền điều kiện

- Người dùng đã đăng nhập và có JWT access token hợp lệ.
- Người dùng đã chọn active profile (`X-Profile-Id` header).
- Backend `GET /api/payment/subscription/current` và `GET /api/quota/profile/{profileId}` đã triển khai (Phase E).
- `CurrentSubscriptionDto` và `QuotaSummaryDto` có sẵn.

## 6. Luồng nghiệp vụ chính

### 6.1 Xem tab "Gói của tôi"

1. Người dùng vào `/payment` → tab "Gói của tôi" active mặc định.
2. Frontend gọi 2 API song song:
   - `GET /api/payment/subscription/current`.
   - `GET /api/quota/profile/{activeProfileId}`.
3. Nếu có subscription:
   - Hiển thị header: plan icon + name, status badge, date range, days remaining.
   - Hiển thị feature checklist từ plan config (FE hardcoded).
   - Hiển thị 2 quota progress bars (prompt + post) với warning.
   - Hiển thị limit info cards (platforms, accounts, analysis level).
   - Nút "Quản lý gói" + "Lịch sử giao dịch".
4. Nếu không có subscription:
   - Hiển thị fallback: "Bạn chưa có gói active."
   - Nút "Chọn gói ngay" → chuyển tab "Plans".

### 6.2 Xem days remaining

1. Nếu `EndDate` có giá trị → tính `daysRemaining = (EndDate - today).Days`.
2. Hiển thị:
   - `> 30 ngày`: xanh, "Còn X ngày".
   - `7-30 ngày`: vàng, "Còn X ngày".
   - `< 7 ngày`: đỏ, "Sắp hết hạn — Còn X ngày".
   - `<= 0`: đỏ, "Đã hết hạn".
3. Nếu `EndDate` null → "Không có hạn".

### 6.3 Chuyển tab

1. Click "Quản lý gói" → chuyển tab "Plans" (cùng trong `/payment`).
2. Click "Lịch sử giao dịch" → chuyển tab "History" (cùng trong `/payment`).

## 7. Luồng ngoại lệ

| Mã | Trường hợp | Kết quả mong đợi |
| --- | --- | --- |
| EX-01 | Subscription API trả 404 (không có active sub) | Fallback: "Bạn chưa có gói active" + CTA "Chọn gói ngay". |
| EX-02 | Quota API trả 404 | Ẩn quota section. |
| EX-03 | Subscription API lỗi 500 | Error banner + "Thử lại". |
| EX-04 | Quota API lỗi 500 | Ẩn quota section + toast log (không critical). |
| EX-05 | Network error (cả 2 API) | Error banner + "Thử lại" cho subscription; ẩn quota. |
| EX-06 | Plan name từ API không match FE plan config | Fallback: hiển thị tên gốc từ API + feature list mặc định. |

## 9. API Contracts

### 9.1 Get Current Subscription

```
GET /api/payment/subscription/current
```

#### Response (200 OK) — Có subscription
```json
{
  "success": true,
  "statusCode": 200,
  "message": "Operation successful",
  "data": {
    "subscriptionId": "guid-here",
    "planName": "Plus",
    "status": "Active",
    "startDate": "2026-06-01T00:00:00",
    "endDate": "2026-07-01T00:00:00"
  },
  "timestamp": "2026-06-03T15:00:00Z"
}
```

#### Response (404) — Không có subscription
```json
{
  "success": false,
  "statusCode": 404,
  "message": "Active subscription not found.",
  "error": { "errorCode": null, "errorMessage": "Active subscription not found." },
  "timestamp": "2026-06-03T15:00:00Z"
}
```

### 9.2 Get Quota Summary

```
GET /api/quota/profile/{profileId}
```

#### Response (200 OK) — Có subscription
```json
{
  "success": true,
  "statusCode": 200,
  "message": "Operation successful",
  "data": {
    "planName": "Plus",
    "subscriptionStatus": "Active",
    "windowStart": "2026-06-01T00:00:00",
    "windowEnd": "2026-07-01T00:00:00",
    "promptQuotaLimit": 10,
    "promptUsage": 3,
    "promptRemaining": 7,
    "postQuotaLimit": 50,
    "postUsage": 12,
    "postRemaining": 38

  "timestamp": "2026-06-03T15:00:00Z"
}
```

## 12. Acceptance Criteria

### AC-01 - Tab "Gói của tôi" mặc định

**Given** người dùng vào `/payment`
**Then** tab "Gói của tôi" active
**And** gọi subscription + quota API.

### AC-02 - Hiển thị thông tin gói

**Given** có active subscription
**Then** hiển thị: icon + plan name, status badge, date range, days remaining.

### AC-03 - Feature checklist

**Given** có active subscription
**Then** hiển thị danh sách tính năng của gói (✅ included / — not included).

### AC-04 - Quota progress bars

**Given** có active subscription + quota data
**Then** hiển thị 2 bars (prompt + post) với usage/limit, remaining, window info.
**And** màu sắc: xanh (>50%), vàng (20-50%), đỏ (<20%).

### AC-05 - Days remaining

**Given** có active subscription với EndDate
**Then** hiển thị số ngày còn lại với màu sắc phù hợp.

### AC-06 - Không có subscription

**Given** không có active subscription
**Then** hiển thị fallback "Bạn chưa có gói active" + CTA "Chọn gói ngay".

### AC-07 - Chuyển tab

**Given** đang ở tab "Gói của tôi"
**When** click "Quản lý gói"
**Then** chuyển sang tab "Plans".

### AC-08 - Loading skeleton

**Given** API đang xử lý
**Then** hiển thị skeleton cho các section.

### AC-09 - Error state

**Given** subscription API lỗi
**Then** error banner + "Thử lại".

### AC-10 - Prompt quota limit = 0

**Given** promptQuotaLimit = 0 (Free plan)
**Then** hiển thị "Không bao gồm" thay vì progress bar.

### Backend - .NET 8

> **Lưu ý:** Backend đã implement:
> - `GET /api/payment/subscription/current` → `CurrentSubscriptionDto`.
> - `GET /api/quota/profile/{profileId}` → `QuotaSummaryDto`.

```typescript
// src/app/(protected)/payment/page.tsx
"use client";

import { useState } from "react";
import { PaymentPage as CheckoutTab } from "@/features/payment/components/payment-page"; // US-44
import { MyPlanTab } from "@/features/payment/components/my-plan-tab";                    // US-46
import { PaymentHistoryPage } from "@/features/payment/components/payment-history-page"; // US-45

type Tab = "my-plan" | "plans" | "history";

const TABS: { key: Tab; label: string; icon: string }[] = [
  { key: "my-plan", label: "Gói của tôi", icon: "📋" },
  { key: "plans", label: "Plans", icon: "📦" },
  { key: "history", label: "History", icon: "📜" },
];

export default function PaymentRoute() {
  const [activeTab, setActiveTab] = useState<Tab>("my-plan");

  return (
    <section className="space-y-6">
      <div>
        <h1 className="text-3xl font-semibold">💳 Payment & Subscription</h1>
        <p className="mt-1 text-sm text-muted-foreground">
          Quản lý gói dịch vụ, thanh toán và hạn mức sử dụng.
        </p>
      </div>

      {/* Tab bar */}
      <div className="flex gap-1 rounded-xl bg-muted p-1">
        {TABS.map((tab) => (
          <button
            key={tab.key}
            onClick={() => setActiveTab(tab.key)}
            className={`flex-1 rounded-lg px-4 py-2 text-sm font-medium transition-colors ${
              activeTab === tab.key
                ? "bg-background shadow-sm"
                : "text-muted-foreground hover:text-foreground"
            }`}
          >
            {tab.icon} {tab.label}
          </button>
        ))}
      </div>

      {/* Tab content */}
      {activeTab === "my-plan" && <MyPlanTab onSwitchTab={setActiveTab} />}
      {activeTab === "plans" && <CheckoutTab />}
      {activeTab === "history" && <PaymentHistoryPage />}
    </section>
  );
}
```

#### MyPlanTab Component

```typescript
// features/payment/components/my-plan-tab.tsx
"use client";

import { useCurrentSubscription } from "@/features/payment/hooks/use-current-subscription";
import { useQuotaSummary } from "@/features/payment/hooks/use-quota-summary";
import { SubscriptionHeaderCard } from "./subscription-header-card";
import { PlanFeaturesList } from "./plan-features-list";
import { QuotaUsageDetail } from "./quota-usage-detail";
import { QuotaLimitCards } from "./quota-limit-cards";
import { SubscriptionEmptyState } from "./subscription-empty-state";
import { PLANS } from "@/features/payment/types/payment";

function MyPlanTab({ onSwitchTab }: { onSwitchTab: (tab: string) => void }) {
  const subscription = useCurrentSubscription();
  const quota = useQuotaSummary();

  const isLoading = subscription.isLoading;
  const subData = subscription.data?.data;
  const quotaData = quota.data?.data;

  // Error: subscription API failed
  if (subscription.isError && (subscription.error as any)?.statusCode !== 404) {
    return (
      <div className="flex items-center gap-3 rounded-xl border border-destructive/20 bg-destructive/5 p-4 text-sm text-destructive">
        <AlertCircle className="h-5 w-5 shrink-0" />
        <span className="flex-1">Không thể tải thông tin gói.</span>
        <button
          onClick={() => subscription.refetch()}
          className="font-medium underline hover:no-underline"
        >
          Thử lại
        </button>
      </div>
    );
  }

  // No active subscription
  if (!isLoading && (!subData || subscription.isError)) {
    return <SubscriptionEmptyState onSelectPlan={() => onSwitchTab("plans")} />;
  }

  // Loading
  if (isLoading) {
    return <SubscriptionSkeleton />;
  }

  const planConfig = PLANS.find(
    (p) => p.code.toLowerCase() === subData.planName.toLowerCase()
  );

  return (
    <div className="space-y-6">
      {/* Header: plan name, status, dates, days remaining */}
      <SubscriptionHeaderCard
        planName={subData.planName}
        status={subData.status}
        startDate={subData.startDate}
        endDate={subData.endDate}
        planIcon={planConfig?.icon ?? "🎁"}
      />

      {/* Feature checklist */}
      {planConfig && <PlanFeaturesList planConfig={planConfig} />}

      {/* Quota usage detail */}
      {quotaData && (
        <QuotaUsageDetail
          promptLimit={quotaData.promptQuotaLimit}
          promptUsage={quotaData.promptUsage}
          promptRemaining={quotaData.promptRemaining}
          postLimit={quotaData.postQuotaLimit}
          postUsage={quotaData.postUsage}
          postRemaining={quotaData.postRemaining}
          windowStart={quotaData.windowStart}
          windowEnd={quotaData.windowEnd}
        />
      )}

      {/* Limit info cards */}
      {planConfig && (
        <QuotaLimitCards planConfig={planConfig} />
      )}

      {/* Action buttons */}
      <div className="flex flex-wrap gap-3">
        <Button onClick={() => onSwitchTab("plans")}>
          🔄 Quản lý gói
        </Button>
        <Button variant="outline" onClick={() => onSwitchTab("history")}>
          📜 Lịch sử giao dịch
        </Button>
      </div>
    </div>
  );
}
```

#### SubscriptionHeaderCard

```tsx
// features/payment/components/subscription-header-card.tsx

function SubscriptionHeaderCard({
  planName,
  status,
  startDate,
  endDate,
  planIcon,
}: {
  planName: string;
  status: string;
  startDate: string;
  endDate?: string | null;
  planIcon: string;
}) {
  const daysRemaining = endDate
    ? Math.max(0, Math.floor((new Date(endDate).getTime() - Date.now()) / (1000 * 60 * 60 * 24)))
    : null;

  const daysColor =
    daysRemaining === null
      ? "text-muted-foreground"
      : daysRemaining > 30
        ? "text-green-600"
        : daysRemaining > 7
          ? "text-amber-600"
          : "text-red-600";

  const isActive = status.toLowerCase() === "active";

  return (
    <div className="rounded-2xl border bg-card p-6 text-center">
      <span className="text-5xl">{planIcon}</span>
      <h2 className="mt-3 text-2xl font-bold">{planName} Plan</h2>

      <div className="mt-2 flex items-center justify-center gap-2">
        <span
          className={`inline-flex items-center gap-1 rounded-full px-3 py-0.5 text-xs font-medium ${
            isActive
              ? "bg-green-100 text-green-700"

          }`}
        >
          <span className={`h-1.5 w-1.5 rounded-full ${isActive ? "bg-green-500" : "bg-gray-400"}`} />
          {isActive ? "Active" : "Inactive"}
        </span>
      </div>

      <p className="mt-3 text-sm text-muted-foreground">
        {formatDate(startDate, "dd/MM/yyyy")}
        {endDate ? ` → ${formatDate(endDate, "dd/MM/yyyy")}` : " — Không có hạn"}
      </p>

      {daysRemaining !== null && (
        <p className={`mt-1 text-sm font-medium ${daysColor}`}>

            ? `⏳ Còn ${daysRemaining} ngày`
```

```tsx
function QuotaBar({
  icon,
  label,
  usage,
  limit,
  remaining,
}: {
  icon: string;
  label: string;
  usage: number;
  limit: number;
  remaining: number;
}) {
  const percentage = limit > 0 ? (usage / limit) * 100 : 0;
  const barColor =
    percentage > 80
      ? "bg-red-500"
      : percentage > 50
        ? "bg-amber-500"
        : "bg-green-500";

  return (
    <div>
      <div className="mb-1 flex items-center justify-between text-sm">
        <span>
          {icon} {label}
        </span>
        <span className="text-muted-foreground">
          <span className="font-medium text-foreground">{usage}</span>
          {" / "}
          <span className="font-medium">{limit}</span>
          {"  "}
          {remaining > 0 ? (
            <span className={remaining < limit * 0.2 ? "text-red-500 font-medium" : "text-muted-foreground"}>
              🟢 Còn {remaining}
            </span>
          ) : (
            <span className="text-red-500 font-medium">🔴 Đã hết</span>
          )}
        </span>
      </div>
      <div className="h-2.5 w-full overflow-hidden rounded-full bg-muted">
        <div
          className={`h-full rounded-full transition-all ${barColor}`}
          style={{ width: `${Math.min(percentage, 100)}%` }}
        />
      </div>
    </div>
  );
}
```
