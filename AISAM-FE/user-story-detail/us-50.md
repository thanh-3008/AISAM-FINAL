# US-50 - Chặn publish khi vượt quota

## 1. User Story

**Là** hệ thống,
**tôi muốn** từ chối publish now hoặc scheduled publish khi profile đã hết post quota,
**để** thực thi chính sách subscription và ngăn đăng bài vượt hạn mức cho phép.

---

## 2. Mục tiêu

Đảm bảo mọi đường dẫn publish (publish now, scheduled publish) đều kiểm tra `POST_QUOTA_EXCEEDED` và chặn trước khi gọi Facebook API. FE hiển thị trạng thái post quota proactive: disable nút "Publish Now" và "Schedule" khi hết quota, cảnh báo sớm khi sắp hết, và cung cấp CTA nâng cấp gói. Khác với US-34 (xử lý lỗi reactive trong modal publish), US-50 tập trung vào **proactive blocking toàn hệ thống** — user thấy quota trước khi click bất kỳ nút publish nào.

---

## 3. Phạm vi

### Trong phạm vi

- **Proactive disable nút "Publish Now"** trên Content Detail và Content List:
  - Gọi `GET /api/quota/profile/{profileId}` để lấy `QuotaSummaryDto`.
  - Nếu `postRemaining <= 0`: disable nút, tooltip "Đã hết quota đăng bài".
  - Nếu `postRemaining / postQuotaLimit <= 0.2`: nút vẫn enabled nhưng hiển thị icon cảnh báo.
- **Proactive disable nút "Schedule"** trên Content Detail:
  - Nếu `postRemaining <= 0`: disable nút, tooltip "Đã hết quota đăng bài — lịch đăng sẽ fail".
  - Nếu `postRemaining > 0`: nút enabled, schedule vẫn tạo được (quota check khi worker execute).
- **Post quota indicator** trên Content List page (`/content`):
  - Header banner: "Bài đăng: X/Y còn lại tháng này" với màu sắc theo mức độ.
  - Icon/màu sắc trên mỗi content card nếu brand có integration.
- **Schedule modal (US-40) quota warning**:
  - Khi mở Schedule modal, nếu `postRemaining <= 0`: warning banner "Bạn đã hết quota đăng bài. Bài đã lên lịch sẽ không thể xuất bản." + link nâng cấp.
  - Nếu `postRemaining` thấp (<=20%): warning nhẹ "Bạn sắp hết quota đăng bài tháng này."
- **Worker schedule fail notification** (US-42):
  - Khi scheduled publish thất bại vì `POST_QUOTA_EXCEEDED`, notification message cần nói rõ "Hết quota đăng bài" thay vì generic "Publishing failed".
  - (Lưu ý: BE worker dùng `PublishAsync` → trả về `quotaCheck.Message!` trong `publishResult.Message` → worker dùng `publishResult.Message` làm `LastError` → notification dùng `LastError` → message đã bao gồm "Post quota has been exceeded...")
- **Error handling chi tiết cho 403 POST_QUOTA_EXCEEDED**:
  - Publish Now: giữ nguyên modal mở, hiển thị error state, không mất dữ liệu đã chọn page.
  - Schedule: toast error, không đóng modal.
  - Multi-page publish: nếu 1 page fail vì quota, các page khác vẫn được xử lý; toast báo partial failure.
- **Upgrade CTA**: Mọi thông báo quota đều kèm link đến `/payment`.

### Ngoài phạm vi

- Block content creation (Draft) khi hết quota — chỉ block publish.
- Block AI generation — US-49.
- Post quota management tab — US-48.
- Recurring schedule quota: deferred.
- Retry schedule thất bại vì quota — worker không retry tự động.
- Email notification khi schedule fail vì quota — deferred.
- Hard block toàn bộ content page khi hết quota — user vẫn xem, edit, clone content.
- Cache quota để giảm API call — mỗi lần vào page gọi 1 lần, sau publish success decrement local counter.

### 6.3. Response format khi quota exceeded (từ PublishAsync)

```json
HTTP 403 Forbidden
{
  "success": false,
  "message": "Post quota has been exceeded for the current subscription.",
  "statusCode": 403,
  "data": null,
  "error": {
    "errorCode": "POST_QUOTA_EXCEEDED",
    "errorMessage": "Post quota has been exceeded for the current subscription."
  },
  "timestamp": "2026-06-03T12:00:00Z"
}
```

### 6.4. Worker path (ScheduledPostingService) — quota failure propagation

Worker gọi `_contentService.PublishAsync(...)`:
- Nếu quota hết → `publishResult.Success = false`, `publishResult.Message = "Post quota has been exceeded..."`
- Worker set `schedule.LastError = publishResult.Message`
- Worker tạo notification với `message = schedule.LastError`
- → Notification message sẽ là "Post quota has been exceeded for the current subscription."

**Không cần sửa BE**: message đã đủ rõ.

## 8. Frontend: Quota hooks (bổ sung post quota)

### 8.1. `use-quota.ts` — bổ sung post quota helpers

```typescript
// src/features/quota/hooks/use-quota.ts
export function usePostQuota() {
  const { activeProfileId } = useActiveProfile();

  return useQuery<QuotaSummary>({
    queryKey: ["quota", activeProfileId],
    queryFn: () => getQuotaSummary(activeProfileId!),
    enabled: !!activeProfileId,
    staleTime: 30_000,
    refetchOnMount: true,
    retry: false,
  });
}

export function isPostQuotaExceeded(remaining: number): boolean {
  return remaining <= 0;
}

export function isPostQuotaLow(remaining: number, limit: number): boolean {
  if (limit <= 0) return true;
  return (remaining / limit) <= 0.2;
}

export function getPostQuotaHealthColor(remaining: number, limit: number): string {
  if (limit <= 0) return "gray";
  const ratio = remaining / limit;
  if (ratio > 0.5) return "green";
  if (ratio > 0.2) return "yellow";
  if (ratio > 0) return "red";
  return "gray";
}
```

### 8.2. `use-quota-error-handler.ts` — bổ sung post quota handler

```typescript
// src/features/quota/hooks/use-quota-error-handler.ts
export function useQuotaErrorHandler() {
  const { toast } = useToast();
  const router = useRouter();

  const handlePostQuotaError = (error: any, onClose?: () => void) => {
    const apiError = error?.response?.data?.error;
    if (apiError?.errorCode === QUOTA_ERROR_CODES.POST_QUOTA_EXCEEDED) {
      toast({
        variant: "destructive",
        title: "Đã hết quota đăng bài",
        description:
          "Bạn đã sử dụng hết số bài đăng trong tháng. Vui lòng nâng cấp gói để tiếp tục đăng bài.",
        action: (
          <button
            onClick={() => {
              if (onClose) onClose();
              router.push("/payment");
            }}
            className="rounded bg-primary px-3 py-1.5 text-sm font-medium text-primary-foreground"
          >
            Nâng cấp gói
          </button>
        ),
        duration: 8000,
      });
      return true;
    }
    return false;
  };

  return { handlePostQuotaError, handleQuotaError: handlePostQuotaError };
}
```

### 9.1. `PostQuotaBanner.tsx` — header trên content pages

```tsx
// src/features/quota/components/PostQuotaBanner.tsx
"use client";

import { usePromptQuota } from "../hooks/use-quota"; // dùng chung query
import Link from "next/link";

export function PostQuotaBanner() {
  const { data, isLoading } = usePromptQuota();

  if (isLoading) return <div className="h-8 w-52 animate-pulse rounded bg-muted" />;
  if (!data) return null;

  const { postRemaining, postQuotaLimit } = data;
  if (postQuotaLimit === 0 && postRemaining === 0) {
    return (
      <div className="flex items-center gap-2 rounded-lg border border-gray-300 bg-gray-50 px-4 py-2 text-sm text-gray-500">
        <span>📋 Bài đăng: không bao gồm trong gói {data.planName}</span>
        <Link href="/payment" className="ml-auto font-medium underline underline-offset-2">
          Nâng cấp gói →
        </Link>
      </div>
    );
  }

  const ratio = postRemaining / postQuotaLimit;
  let bgColor = "bg-green-100 text-green-800 border-green-300";
  let label = `Bài đăng: ${postRemaining} / ${postQuotaLimit} còn lại tháng này`;
  if (ratio <= 0.2 && ratio > 0) {
    bgColor = "bg-yellow-100 text-yellow-800 border-yellow-300";
    label = `Bài đăng: ${postRemaining} / ${postQuotaLimit} — sắp hết quota`;
  }
  if (ratio <= 0) {
    bgColor = "bg-red-100 text-red-800 border-red-300";
    label = `Bài đăng: ${postRemaining} / ${postQuotaLimit} — đã hết quota`;
  }

  return (
    <div className={`flex items-center gap-2 rounded-lg border px-4 py-2 text-sm ${bgColor}`}>
      <span className="font-medium">{label}</span>
      {(ratio <= 0.2 || ratio <= 0) && (
        <Link href="/payment" className="ml-auto font-semibold underline underline-offset-2">
          {ratio <= 0 ? "Nâng cấp gói →" : "Xem gói"}
        </Link>
      )}
    </div>
  );
}
```

```tsx
import { usePromptQuota, isPostQuotaExceeded } from "@/features/quota/hooks/use-quota";
import { Tooltip, TooltipContent, TooltipTrigger } from "@/components/ui/tooltip";
```

## 10. Luồng xử lý

### 10.1. Luồng chính: Content List → Publish Now → hết quota

```
User vào /content
  → PostQuotaBanner hiển thị "Bài đăng: 0/10 — đã hết quota" (đỏ)
  → Mỗi content card có ContentQuotaBadge "Hết quota" (đỏ)
  → User click "Publish Now" trên 1 content
  → PublishButtonWithQuota disabled + tooltip "Đã hết quota..."
  → User không thể mở Publish Modal
  → User click badge/link "Nâng cấp gói →" → navigate /payment
```

### 10.2. Luồng phụ: Content Detail → Schedule → hết quota

```
User vào /content/{id}
  → PostQuotaBanner hiển thị "Bài đăng: 0/10 — đã hết quota"
  → Nút "Publish Now" và "Schedule" đều disabled
  → User vẫn click Schedule (nếu FE không disable)
    → ScheduleModal mở ra
    → ScheduleModalQuotaWarning hiển thị warning đỏ
    → User vẫn có thể tạo schedule (không block cứng)
    → Worker sẽ fail khi execute → notification "Post quota has been exceeded..."
```

### 10.3. Luồng phụ: Multi-page publish → 1 page hết quota

```
User chọn 3 pages → click Publish
  → Page 1: success
  → Page 2: 403 POST_QUOTA_EXCEEDED
    → Modal đánh dấu Page 2 = "❌ Hết quota đăng bài"
    → Các page khác vẫn xử lý tiếp
  → Page 3: success
  → Kết thúc: toast "Đã đăng lên 2/3 pages. 1 page thất bại (hết quota)."
  → Content status = Published (vì có page thành công)
```

### 10.4. Luồng phụ: Scheduled publish → quota hết khi worker chạy

```
Worker quét schedule đến hạn
  → ContentService.PublishAsync → quota check fail
  → PublishResult.Success = false, Message = "Post quota has been exceeded..."
  → Worker set schedule.Status = Failed, LastError = message
  → Worker tạo notification SystemUpdate với message = message
  → User nhận notification: "Post quota has been exceeded for the current subscription."
```

| State | Badge |
|---|---|
| Hết quota | 🔴 `rounded-full bg-red-100 text-red-700`: "Hết quota" |
| Sắp hết (<=20%) | 🟡 `rounded-full bg-yellow-100 text-yellow-700`: "X bài còn" |

### 12.6. Publish Modal — quota error state

Khi nhận 403 POST_QUOTA_EXCEEDED trong lúc publish:
- Giữ nguyên modal mở.
- Page bị fail đánh dấu "❌ Hết quota đăng bài" (khác với fail Facebook API "❌ Lỗi Facebook").
- Nếu tất cả pages fail vì quota: hiển thị banner "Tất cả pages đều hết quota" + nút "Nâng cấp gói".
- Nếu partial: toast + modal tiếp tục cho retry các page khác.

## 13. Ghi chú quan trọng

1. **US-34 đã có error handling reactive** (khi publish fail → modal show "Hết quota" + "View Plan"). US-50 bổ sung **proactive blocking** (disable nút trước khi click) + **quota indicator** trên content pages.
2. **Schedule không bị block cứng** khi hết quota — user vẫn có thể tạo schedule (vì worker sẽ check quota khi execute). Nhưng FE cảnh báo rõ rằng schedule sẽ fail.
3. **Post quota là monthly** (khác prompt quota là daily). `windowStart/End` từ `QuotaSummaryDto` cho biết chu kỳ.
4. **Post quota consumed khi publish thành công** — BE increment counter, FE không cần handle.
5. **Schedule worker không decrement counter** khi success — BE `QuotaService` tự count từ DB.
6. **Sau publish thành công**, FE có thể optimistic update: `queryClient.setQueryData(["quota", profileId], old => old ? { ...old, postRemaining: old.postRemaining - 1 } : old)`.
7. **Dùng chung `usePromptQuota` (tên không chính xác, nhưng queryKey chung)** — hook này lấy full `QuotaSummaryDto`. Nếu cần refactor, đổi tên thành `useQuotaSummary`. Hiện tại giữ tên để đồng bộ với US-49.
8. **Nếu profile chưa có active subscription**: `GET /api/quota/profile/{profileId}` → 404. FE xem như `postQuotaLimit = 0`, `postRemaining = 0`, hiển thị "Vui lòng đăng ký gói" + link `/payment`.

## 17. So sánh US-34 vs US-50

| Khía cạnh | US-34 (existing) | US-50 (bổ sung) |
|---|---|---|
| **Cách tiếp cận** | Reactive — xử lý lỗi sau khi publish fail | Proactive — chặn trước khi user click |
| **Publish button** | Enabled, disable sau khi click | Disabled từ đầu nếu hết quota |
| **Schedule button** | Không đề cập | Disabled + tooltip + warning trong modal |
| **Quota indicator** | Không có | PostQuotaBanner + ContentQuotaBadge |
| **Multi-page quota** | Generic error "Hết quota" | Error state riêng "❌ Hết quota" cho từng page |
| **Worker notification** | Không đề cập | Notification message đã rõ "Post quota has been exceeded..." |
| **Optimistic update** | Không có | Có thể thêm sau publish success |
