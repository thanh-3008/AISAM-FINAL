# US-43 - Xem dashboard tổng quan MVP

## 1. User Story

**Là** người dùng,
**tôi muốn** xem dashboard summary theo profile để theo dõi tổng quan content, posts và scheduling,
**để** có thể nắm bắt nhanh tình hình hoạt động marketing và điều hướng đến các module chi tiết.

---

## 2. Mục tiêu

Cung cấp trang `/dashboard` hiển thị summary metrics của profile đang active dưới dạng các thẻ (cards) trực quan: số content theo trạng thái, số bài đã publish, số schedule sắp tới/thất bại, số social integration active, số notification chưa đọc. Mỗi card có thể click để điều hướng đến trang chi tiết tương ứng. Dashboard là read-only, lấy dữ liệu từ một API duy nhất.

---

## 3. Phạm vi

### Trong phạm vi

- Trang `/dashboard` là trang landing sau khi login/chọn profile.
- Gọi `GET /api/dashboard/summary` → `DashboardSummaryDto`.
- Hiển thị các metric cards:
  - **Content**: Draft, Pending Approval, Published — 3 cards riêng.
  - **Posts**: tổng số post đã publish.
  - **Schedules**: upcoming schedules, failed schedules — 2 cards riêng.
  - **Social**: số integration đang active.
  - **Notifications**: số unread notifications.
- Mỗi card hiển thị: icon, label, số count, màu sắc riêng.
- Click card → navigate đến trang tương ứng:
  - Draft content → `/content?filter=draft`.
  - Pending Approval → `/content?filter=pending-approval`.
  - Published content → `/content?filter=published`.
  - Posts → `/posts`.
  - Upcoming schedules → `/schedules` (tab Pending).
  - Failed schedules → `/schedules` (tab Failed).
  - Active integrations → `/social`.
  - Unread notifications → `/notifications`.
- Loading skeleton (8 cards shimmer).
- Error state + nút "Thử lại".
- Refresh button (manual refetch).
- Auto-refresh khi tab focus (optional, dùng `refetchOnWindowFocus`).

### Ngoài phạm vi

- Charts, graphs, biểu đồ (deferred).
- Performance metrics (reach, impressions, engagement): post-MVP.
- Analytics breakdown theo kênh/brand: post-MVP.
- Dashboard tùy chỉnh (user configurable): deferred.
- So sánh theo thời gian (week-over-week, month-over-month): deferred.
- Export dashboard data: deferred.

## 4. Actor

- **Chính:** Người dùng đã đăng nhập, có active profile.
- **Phụ:** Backend API (`DashboardController.GetSummary`), React Query cache.

---

## 5. Tiền điều kiện

- Người dùng đã đăng nhập và có JWT token hợp lệ.
- Người dùng đã chọn active profile (`X-Profile-Id` header).
- Backend `GET /api/dashboard/summary` đã triển khai (Phase D).
- Có ít nhất một số dữ liệu trong DB (content, posts, schedules, integrations, notifications) để dashboard có ý nghĩa.

---

## 6. Luồng nghiệp vụ chính

### 6.1 Xem Dashboard

1. Người dùng login hoặc chọn profile → redirect đến `/dashboard`.
2. Frontend gọi `GET /api/dashboard/summary`.
3. Hiển thị 8 metric cards trong grid layout (4 cột desktop, 2 cột tablet, 1 cột mobile).
4. Mỗi card hiển thị:
   - Icon đặc trưng (màu sắc riêng).
   - Count (số lớn, font bold).
   - Label (mô tả ngắn).
   - Toàn bộ card là clickable → navigate đến trang chi tiết.

### 6.2 Click card

1. Click Draft Content card → `/content?filter=draft`.
2. Click Pending Approval card → `/content?filter=pending-approval`.
3. Click Published Content card → `/content?filter=published`.
4. Click Posts card → `/posts`.
5. Click Upcoming Schedules card → `/schedules?tab=pending`.
6. Click Failed Schedules card → `/schedules?tab=failed`.
7. Click Active Integrations card → `/social`.
8. Click Notifications card → `/notifications`.

### 6.3 Refresh

1. Nút refresh (icon) ở góc phải header → refetch dashboard data.
2. `refetchOnWindowFocus` = true (tự động refetch khi user quay lại tab).

## 7. Luồng ngoại lệ

| Mã | Trường hợp | Kết quả mong đợi |
| --- | --- | --- |
| EX-01 | API dashboard lỗi/500 | Error banner + nút "Thử lại". |
| EX-02 | Tất cả metrics = 0 | Cards hiển thị số 0, vẫn clickable (đi đến empty state của trang đó). |
| EX-03 | Chưa có active profile | Redirect đến trang chọn profile. |
| EX-04 | API timeout | Toast lỗi + giữ nguyên dữ liệu cũ (nếu có). |

## 8. Quy tắc nghiệp vụ

| Mã | Quy tắc |
| --- | --- |
| BR-01 | Dashboard summary chỉ tính data của profile đang active (`X-Profile-Id`). |
| BR-02 | Tất cả metrics là read-only aggregate counts từ DB. |
| BR-03 | `DraftContentCount`: content `Status = Draft`. |
| BR-04 | `PendingApprovalContentCount`: content `Status = PendingApproval`. |
| BR-05 | `PublishedContentCount`: content `Status = Published`. |
| BR-06 | `PublishedPostCount`: tổng Post records (không filter status). |
| BR-07 | `UpcomingScheduleCount`: schedule `Status = Pending` AND `ScheduledAt > now`. |
| BR-08 | `FailedScheduleCount`: schedule `Status = Failed`. |
| BR-09 | `ActiveSocialIntegrationCount`: integration `IsDeleted = false AND IsActive = true`. |
| BR-10 | `UnreadNotificationCount`: notification `IsRead = false AND IsDeleted = false`. |

## 12. Acceptance Criteria

### AC-01 - Dashboard hiển thị 8 metric cards

**Given** người dùng vào `/dashboard`
**When** trang load
**Then** gọi `GET /api/dashboard/summary`
**And** hiển thị 8 cards: Draft Content, Pending Approval, Published Content, Published Posts, Upcoming Schedules, Failed Schedules, Active Integrations, Unread Notifications.

### AC-02 - Mỗi card hiển thị count + label

**Given** dashboard đã load
**Then** mỗi card hiển thị icon, count (số lớn), label (mô tả).

### AC-03 - Click card navigate

**Given** dashboard đã load
**When** click "Draft Content" card
**Then** navigate đến `/content?filter=draft`.

### AC-04 - Refresh button

**Given** dashboard đã load
**When** click refresh button
**Then** refetch dashboard data.

### AC-05 - Loading skeleton

**Given** API đang xử lý
**Then** hiển thị 8 skeleton cards.

### AC-06 - Error state

**Given** API trả lỗi
**Then** hiển thị error banner + nút "Thử lại".

### AC-07 - All zero

**Given** chưa có dữ liệu
**Then** cards hiển thị số 0, vẫn clickable.

### AC-08 - Auto-refresh trên window focus

**Given** user rời tab và quay lại
**Then** dashboard tự động refetch (nếu có `refetchOnWindowFocus`).

```tsx
// features/dashboard/components/metric-card.tsx
import Link from "next/link";
import type { MetricCardConfig } from "@/features/dashboard/types/dashboard";

function MetricCard({
  config,
  count,
}: {
  config: MetricCardConfig;
  count: number;
}) {
  return (
    <Link
      href={config.route}
      className="group flex flex-col gap-2 rounded-2xl border bg-card p-5 shadow-sm transition-all hover:shadow-md hover:-translate-y-0.5"
    >
      {/* Icon */}
      <div
        className="flex h-10 w-10 items-center justify-center rounded-xl"
        style={{ backgroundColor: `${config.color}18` }}
      >
        {renderIconByName(config.icon, `h-5 w-5`, config.color)}
      </div>

      {/* Count */}
      <p className="text-3xl font-bold" style={{ color: config.color }}>
        {count}
      </p>

      {/* Label */}
      <p className="text-xs font-medium text-muted-foreground">
        {config.label}
      </p>

      {/* Bottom indicator bar */}
      <div
        className="h-1 w-full rounded-full opacity-60 transition-all group-hover:opacity-100"
        style={{ backgroundColor: config.color }}
      />
    </Link>
  );
}

function renderIconByName(name: string, className: string, color?: string) {
  const icons: Record<string, React.ComponentType<{ className?: string; style?: React.CSSProperties }>> = {
    FileText: FileText, Clock: Clock, CheckCircle: CheckCircle,
    Send: Send, CalendarClock: CalendarClock, AlertTriangle: AlertTriangle,
    Link: Link, Bell: Bell,
  };
  const Icon = icons[name] ?? FileText;
  return <Icon className={className} style={color ? { color } : undefined} />;
}
```

**DashboardPage:**

```tsx
// features/dashboard/components/dashboard-page.tsx
"use client";

import { useDashboardSummary } from "@/features/dashboard/hooks/use-dashboard-summary";
import { MetricCard } from "@/features/dashboard/components/metric-card";
import { DashboardSkeleton } from "@/features/dashboard/components/dashboard-skeleton";
import { METRIC_CARDS } from "@/features/dashboard/types/dashboard";

export function DashboardPage() {
  const { data, isLoading, isError, refetch, isRefetching } = useDashboardSummary();

  return (
    <section className="space-y-6">
      {/* Header */}
      <div className="flex items-center justify-between">
        <div>
          <h1 className="text-3xl font-semibold">📊 Dashboard</h1>
          <p className="mt-1 text-sm text-muted-foreground">
            Tổng quan hoạt động marketing
          </p>
        </div>
        <button
          onClick={() => refetch()}
          disabled={isRefetching}
          className="rounded-full p-2 transition-colors hover:bg-muted disabled:opacity-50"
          title="Refresh"
        >
          <RefreshCw className={`h-5 w-5 ${isRefetching ? "animate-spin" : ""}`} />
        </button>
      </div>

      {/* Error state */}
      {isError && (
        <div className="flex items-center gap-3 rounded-xl border border-destructive/20 bg-destructive/5 p-4 text-sm text-destructive">
          <AlertCircle className="h-5 w-5 shrink-0" />
          <span className="flex-1">Không thể tải dashboard.</span>
          <button
            onClick={() => refetch()}
            className="font-medium underline hover:no-underline"
          >
            Thử lại
          </button>
        </div>
      )}

      {/* Loading skeleton */}
      {isLoading && <DashboardSkeleton />}

      {/* Cards grid */}
      {!isLoading && !isError && data && (
        <div className="grid grid-cols-1 gap-4 sm:grid-cols-2 lg:grid-cols-4">
          {METRIC_CARDS.map((config) => (
            <MetricCard
              key={config.key}
              config={config}
              count={data[config.key]}
            />
          ))}
        </div>
      )}
    </section>
  );
}
```
